# 4777: Make every hooks.js verb refuse an undeclared flag, starting with reconcile

Origin: reflect light from #4773

Defer-reason: tangential

## Current State

`plugin/bin/hooks.js`'s unknown-flag guard (#1012) is opt-in per verb: only verbs listed in `KNOWN_FLAGS` refuse an undeclared `--*` argument. Every other verb silently ignores one and runs for real. #4773 closed this for `archive-run` after `archive-run --dry-run` archived and committed a run.

The same hazard remains on the other unlisted verbs. `reconcile` is the sharpest case: its usage is `reconcile [--dry-run] [--json] [--mcp-reachable] [--checks <c1,c2,...>]`, so a typo such as `--dryrun` or `--check` runs a full reconcile pass. That pass archives run dirs, reaps worktrees and commits in the main checkout.

Probe (origin/main at 79f3c3c84): `git grep -n -F -e "  reconcile: [" origin/main -- plugin/bin/hooks.js` exits 1, with no match. The control `git grep -n -F -e "  'close-run': ['--run']," origin/main -- plugin/bin/hooks.js` matches line 173, so the pattern shape is sound. Other unlisted verbs that accept flags: `resolve-run-dir`, `sweep-shadow`, `adopt-run-dir`, `check-resume-freshness`, `check-staged-inventory`, `check-session-residue`, `check-sibling-sessions`.

## Deliverables

- Give every `VERBS` verb that accepts flags a `KNOWN_FLAGS` entry (with `VALUE_FLAGS` for value-taking flags), so an undeclared `--*` argument prints the verb's usage line and exits before it runs. Mutating verbs come first: `reconcile`, `adopt-run-dir`, `sweep-shadow`, `resolve-run-dir --create`.
- Or invert the default: make the guard apply to every `VERBS` verb, with an explicit opt-out list for any verb that must stay lenient. Then a new verb cannot forget to register.
- Update the comment above `KNOWN_FLAGS` and `.claude/skills/hooks-js-verb-registration/SKILL.md` rows 2 and 8 to match.
- One CLI spawn test per newly strict mutating verb: an undeclared flag prints usage, exits 0 and changes nothing.

## Acceptance Criteria

- `node plugin/bin/hooks.js reconcile --dryrun` prints `claude-tweaks: usage: reconcile [--dry-run] [--json] [--mcp-reachable] [--checks <c1,c2,...>]`, exits 0 and runs no reconcile check. A spawn test pins this and goes red with the verb's entry removed.
- Every existing call in `plugin/` to a newly strict verb passes only declared flags (checked by grep in the PR).
- `git grep -n -F -e "  reconcile: [" -- plugin/bin/hooks.js` matches; it does not match on origin/main at 79f3c3c84.

## Release Note

A mistyped flag on any plugin run-management command now stops with a usage message instead of running the command as if the flag were absent.
