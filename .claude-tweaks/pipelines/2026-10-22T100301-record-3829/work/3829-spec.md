## Current State

The "Worktree shell constraint" guidance (the dispatch context-pack template, mirrored in `_shared/subagent-dispatch-core.md`) lists specific refused compound-Bash shapes — quoted JSON with a VCS command name, a for/while loop variable, a glob, an API call inside `if RAW=$(...)`, `sed -i` on a variable path, `cat "$P/..."` — but omits "a `git`/`gh` command whose output is piped or substituted into a second command." `plugin/skills/wrap-up/ceremony-derivation.md` itself prescribes exactly that shape as its canonical one-liner (`git diff --numstat "$(git merge-base HEAD origin/main)" | node -e "..."`), so a session following that file's own documented invocation verbatim hits the harness's worktree-isolation guard anyway, discovering the gap by trial rather than by the guidance warning it up front.

**Evidence:** this run's `friction-events.js` output recorded a `wd-guard-refusal` event at the exact command above, refused with "too complex to verify that it stays inside the worktree," during this wrap-up run's own Phase 1 ceremony-derivation step. Four more `wd-guard-refusal` events fired earlier in the same run's lifecycle (build/PR-setup phase, an adhoc-standalone run dir) for other compound shapes (`eval`, a heredoc redirect, `curl | head`), suggesting the avoid-list's enumeration is incomplete more broadly, not just for this one shape.
**Cost this session:** low — one extra tool round-trip to split the command and re-run; no blocked work, no incorrect result.

## Deliverables
