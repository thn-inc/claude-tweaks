# 3034: blast-radius: isTestPath ignores the stories/ QA directory, so story-only diffs never derive fast-lane ceremony

Surface: infra

## Current State

`isTestPath` (`plugin/bin/lib/issues/blast-radius.js:24`) recognizes test surface through two regexes only: `TEST_PATH_RE` (`:21`, a `test/` or `tests/` path segment) and `TEST_SUFFIX_RE` (`:22`, `.test.`/`.spec.` js/ts suffixes, `_test.go`, `test_*.py`/`*_test.py`). `classifyDiffFiles` (`:93`) stamps `isTest` from it, and that classification feeds both `blastRadiusSummary` (merge-check's blast-radius input) and `computeDiffFacts` (`plugin/bin/lib/dispatch/ceremony-derive.js:29`), whose `lowSurface` gate (`:53`, zero implementation files) narrows `standard` to `fast-lane` (#1545).

The plugin's own QA story files — `/claude-tweaks:stories` writes them to `stories/` by default (`plugin/skills/stories/SKILL.md:26`, overridable with `dir=<path>`) — match neither regex. A diff of only `stories/*.yaml` plus docs therefore classifies every story file as implementation: the reporter observed `{"fileCount":12,"testFiles":0,"docsFiles":3,"implFiles":9,"lowSurface":false}`, so the run kept `standard` ceremony (full-mode reflect, full registry pass), and merge-check's summary counted 567 story lines as implementation lines for a change with no runtime code.

The existing #1545 discrimination tests live in `tests/bin-lib/dispatch/ceremony-derive.test.js:13`; `tests/bin-lib/issues/blast-radius.test.js` covers `classifyDiffFiles`/`isTestPath`.

## Deliverables

1. Extend `blast-radius.js`'s test-path recognition so a YAML file under a `stories/` path segment (`(^|/)stories/` with a `.yaml`/`.yml` extension) classifies `isTest: true`, and update the convention comment above the regexes to list it.
2. Add `blast-radius.test.js` cases: `stories/app-customer.yaml` and `qa/stories/x.yml` are test paths; `stories/readme.md`, `src/stories.js`, and `src/history/stories.ts` are not.
3. Add `ceremony-derive.test.js` discrimination cases next to the #1545 one: a story file plus a docs file is `lowSurface: true` / `fast-lane`; a story file plus one production source file is `lowSurface: false`.

## Acceptance Criteria

- `computeDiffFacts` over `[stories/a.yaml, stories/b.yaml, docs/plan.md]` returns `testFiles: 2`, `implFiles: 0`, `lowSurface: true`, and the derivation yields `fast-lane` from `standard`.
- `computeDiffFacts` over `[stories/a.yaml, src/app.js]` returns `implFiles: 1`, `lowSurface: false`.
- `isTestPath('stories/readme.md')`, `isTestPath('src/stories.js')`, and `isTestPath('src/history/stories.ts')` are all `false` (only YAML under a `stories/` segment qualifies).
- Every pre-existing `blast-radius.test.js` and `ceremony-derive.test.js` case still passes.
- The new story cases fail against the current regexes and pass with the change (verified by reverting the regex edit).

## Release Note

Count QA story YAML files as test surface, so story-only changes get the lighter fast-lane ceremony and an accurate merge-check blast radius.

## Technical Approach

Add a third alternation (or a separate `STORY_PATH_RE`) to `isTestPath` rather than special-casing `computeDiffFacts` — `isTestPath` is the single classification point both `blastRadiusSummary` and `computeDiffFacts` read, so fixing it there corrects the merge-check line counts and the ceremony derivation together. Restrict the match to `.yaml`/`.yml` under a `stories/` segment: the stories schema is YAML, and a bare `stories/` directory match would misclassify unrelated content (a CMS or docs site's `stories/` pages) in downstream projects.

### Key Files

- `plugin/bin/lib/issues/blast-radius.js` — add story-YAML recognition to `isTestPath` and its convention comment
- `tests/bin-lib/issues/blast-radius.test.js` — positive and negative `isTestPath` story cases
- `tests/bin-lib/dispatch/ceremony-derive.test.js` — story-plus-docs vs story-plus-source discrimination cases

## Gotchas

- A project that passes `/claude-tweaks:stories dir=<path>` to a directory not named `stories` is not covered by a path-segment match. Resolving the configured directory would need I/O this pure module does not do; the default-directory match covers the shipped convention, and a custom directory stays classified as before (no regression).
- `plugin/bin/lib/issues/initiative-budget.js:33` has its own independent `isTestPath`; leave it unchanged — it serves a different consumer and is out of scope here.
- Classifying story files as test surface only ever lowers ceremony and shifts merge-check line counts from implementation to test; merge-check still weighs review findings and diff content, so this is never a pass/fail gate on its own (`blast-radius.js` header).

## Original request

blast-radius: isTestPath ignores the stories/ QA directory, so story-only diffs never derive fast-lane ceremony

**Summary:** `isTestPath` in `bin/lib/issues/blast-radius.js` does not recognise the plugin's own `stories/` QA directory, so a diff of only story YAML is never low-surface and never derives the `fast-lane` ceremony.

**Kind:** Defect

**Affected component:** `bin/lib/issues/blast-radius.js` (`isTestPath`), consumed by `bin/lib/dispatch/ceremony-derive.js` (`computeDiffFacts`) and the merge-check blast-radius summary

**Repro steps:**
1. In any project using the plugin, make a branch whose only changes are edits to `stories/*.yaml`, the files `/claude-tweaks:stories` writes, plus a markdown plan/ledger file.
2. Run `computeDiffFacts` (`bin/lib/dispatch/ceremony-derive.js`) over the branch's `git diff --numstat`, as `wrap-up/ceremony-derivation.md` does on an auto-mode firing.
3. Observe the result: every `stories/*.yaml` path is classified `isTest: false`, and `implFiles` equals the story-file count.

**Expected vs. actual:**
Expected: QA story files count as test surface, so a story-only or story-plus-docs diff is `lowSurface: true` and the diff-derived default (#1545) narrows `standard` to `fast-lane`.
Actual: `{"fileCount":12,"testFiles":0,"docsFiles":3,"implFiles":9,"lowSurface":false}`. The run keeps `standard` and pays for a full-mode reflect and the full registry pass. The blast-radius summary also counts every story line as an implementation line, so merge-check sees a 567-line "implementation" diff for a change with no runtime code.

Cause: `isTestPath` only matches a `test/` or `tests/` path segment and language test-file suffixes (`.test.`/`.spec.` for js/ts, `_test.go`, `test_*.py`/`*_test.py`). The plugin's own QA story directory is test surface by construction, but the heuristic doesn't know about it.

Suggested fix: have `isTestPath`, or `computeDiffFacts`, treat the stories directory as test surface: `stories/**/*.yaml`, or whatever directory the stories skill resolves for the project. Add a discrimination test next to the #1545 one: a story file plus a docs file is low-surface, and a story file plus one production source file is not.

**Definition:** Clear
