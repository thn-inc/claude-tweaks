# 3456: Group identical fan-out rows in the skill load delta table

Origin: ledger resolve gate (#3307 wrap-up, ledger row 19)

Defer-reason: needs-human-decision

## Current State

`plugin/bin/load-delta.js` `renderText` prints one table row per changed skill entry point. In this corpus the closure is saturated: every `plugin` entry's closure is 1.19–2.11 MB and 88 files sit in every closure, so a one-row edit to any widely cited `_shared/*.md` file yields a 39-row table whose rows differ only in the Entry and absolute columns — ΔFloor 0 and the same ΔClosure on every row.

Observed live during #3307's own review (step 3j on its branch): 38 of 39 rows read `ΔFloor 0 · ΔClosure +347` from one added row in `_shared/integration-branch.md`; only `plugin:review` differed. The review summary carries the whole table verbatim (`plugin/skills/review/step3-skill-load-delta.md`).

## Deliverables

- `renderText` collapses rows that share identical (ΔFloor, ΔClosure, new-unresolved) into one row naming the entry count and listing the entries (or the first few plus a count), keeping rows that differ as individual rows.
- `--json` output is unchanged (consumers such as #3309/#3310 read per-entry rows).
- `plugin/skills/review/step3-skill-load-delta.md` and its verbatim-quote test updated for the grouped row shape.

## Acceptance Criteria

- A fixture where one `_shared/*.md` edit moves N ≥ 3 entries by the same ΔClosure renders those N entries as one row; an entry with a different delta stays its own row.
- `node plugin/bin/load-delta.js --json` output is byte-identical before and after the change on the same fixture.
- `tests/load-delta-cli.test.js`'s outcome-line quote test passes against the updated step file.

## Release Note

The review skill load delta collapses entries that moved by the same amount into one row, so a shared-file edit no longer produces a wall of identical rows.
