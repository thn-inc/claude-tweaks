# 3537: Migrate the four local-merge fences off eval of compose-subject --shell output

Origin: ledger resolve gate

Defer-reason: tangential

**Related:** #3544

## Current State

#3347 moved the pr-first `gh pr merge` fences off `eval "$SUBJECT_EXPORTS"` onto `compose-subject.js --title-out/--body-out` file mode, because shell-evaluating composed merge text garbled a squash commit (#3325). Four local-merge fences still `eval` the `--shell` output and pass it to `git merge --no-ff -m "$SUBJECT_TITLE\n\n$SUBJECT_BODY"`: `plugin/skills/_shared/local-merge-auto-finish.md`, `plugin/skills/wrap-up/auto-merge-short-circuit.md`, `plugin/skills/dispatch/settle-and-merge.md`, `plugin/skills/flow/worktree-merge.md`. They carry the same shell-interpretation fragility. #3347's AC2 covered `gh pr merge` only, and a garbled local merge message can be amended before push, so these were left unchanged. The pinning conformance suite is `tests/merge-subject-composer-conformance.test.js` (`LOCAL_COMPOSER_CALL`, `LOCAL_MERGE_FORM`).

## Deliverables

- [ ] Migrate the four local-merge fences to compose via `compose-subject.js --title-out/--body-out` and `git merge --no-ff {branch} -F {message-file}` (or an equivalent that never passes the text through shell parsing), keeping the `|| exit 1`-equivalent stop on a non-zero composer exit.
- [ ] Update `tests/merge-subject-composer-conformance.test.js` and the `docs/journeys/merge-a-record-with-a-conventional-subject-2251.md` local-merge forms to the new shape.
- [ ] Extend the eval sweep (`AC2.1/AC2.2`) so no fence in `plugin/skills/**` evals `compose-subject.js --shell` output at all, then retire `--shell` if nothing else uses it.

## Acceptance Criteria

- [ ] `node --test tests/merge-subject-composer-conformance.test.js tests/bin-lib/compose-subject.test.js` passes, and the composed bundles stay under the 51,200-byte ceiling (`tests/bin-lib/skill-audit/context-cost.test.js`).
