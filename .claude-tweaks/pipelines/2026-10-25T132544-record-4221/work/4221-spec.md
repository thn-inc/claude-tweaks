# 4221: Raise review-effort when the diff dwarfs the record's size label

Origin: reflect full from #4028

Defer-reason: tangential

## Current State

`review/review-effort-derivation.md` step 2 uses the record's `risk:*`/`size:*` labels whenever both exist; the diff heuristic (step 3) runs only when they are absent. #4028 carried `risk:low` / `size:medium`, which derives `low` (lenses 3b and 3c, one agent each), while its diff was 142 files and 5,733 lines including a 728-line PreToolUse hook that rewrites commands in every worktree session. The reviewer overrode the tier to `high` by hand and logged it. The tier's own ambiguity rule says ambiguity never resolves toward less scrutiny, but a label far below the measured diff is not treated as ambiguity.

## Deliverables
