# 3854: verify report.js git calls omit windowsHide, and the conformance scan cannot see injected-runner calls

Verified-as-of: c68d7dede

Origin: found by #3799's review (PR #3807), lens 3a, low-confidence staged finding

Defer-reason: tangential

## Current State

`plugin/bin/lib/verify/report.js` runs three git commands through an injected `execImpl` that defaults to `execFileSync`:
- `gitInfo()`: `git rev-parse HEAD` (line 18) and `git --no-optional-locks status --porcelain` (line 23), both with `{ encoding: 'utf8' }`;
- `gitDir()`: `git rev-parse --git-dir` (line 37), with `{ encoding: 'utf8', cwd }`.

None of them passes `windowsHide: true`. `bin/verify.js` calls `gitDir()` (imported as `resolveGitDir`) up to three times per run: the run's own git dir, #3799's `--cwd` guard, and `--stamp-status`. It also calls `gitInfo()` at the start and end of the run. On Windows, each of these calls can flash a console window.

`tests/windows-hide-spawn-conformance.test.js` only matches direct `execFileSync`/`spawn` call shapes. A call through an injected runner parameter (`execImpl(...)`) is invisible to it, so the scan passes while all three calls lack the option.

#3799's review lens found this while reviewing `verify.js`. It predates #3799, but #3799's guard added one more `gitDir()` call.

## Deliverables

- All three git calls in `report.js` pass `windowsHide: true`.
- The windowsHide conformance scan, or a targeted test beside it, matches a call through an injected runner whose default is `execFileSync`. A go-red self-test proves the matcher catches `report.js`'s call shape.

## Acceptance Criteria

- [ ] A unit test with a fake `execImpl` asserts `windowsHide: true` in the options of each of the three git calls (`gitInfo`'s two, `gitDir`'s one).
- [ ] Removing `windowsHide: true` from any one of the three calls makes the conformance check fail, shown by reverting it in a self-test or a fixture.
- [ ] `npm test` passes.

## Release Note

Running the verification runner on Windows no longer flashes console windows for its git checks.

## Technical Approach

### Key Files

- `plugin/bin/lib/verify/report.js` — add windowsHide: true to the three git calls
- `tests/windows-hide-spawn-conformance.test.js` — match calls through an injected runner that defaults to execFileSync, with a go-red self-test
