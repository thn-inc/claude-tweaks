## Current State

Production producers:

- `plugin/bin/release-local.js:340`: `listPlanFiles` returns `path.join('docs/superpowers/plans', f)`, a repo-relative ID, which on win32 is `docs\superpowers\plans\a.md` (`tests/bin-lib/release-local/cli.test.js:35`).

Test-side:
