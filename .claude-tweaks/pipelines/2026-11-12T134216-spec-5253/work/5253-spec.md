# 5253: context-gauge.js writes a handoff for a top-level run whose only remaining step is wrap-up

Origin: reflect full from #5216
Defer-reason: tangential

## Current State

`plugin/skills/flow/context-handoff.md` says a top-level run (one whose `run-state.json` is not `dispatched: true`) never hands off `wrap-up`. A subagent cannot call `AskUserQuestion`, so a child running `wrap-up` would strand the Review Console and the ledger resolve gate. With `wrap-up` the only step left, the run does not gauge at all.

The rule lives only in prose. `plugin/bin/context-gauge.js` accepts `--next-steps wrap-up` for a top-level run, and past the cap it writes `{run}/handoff.json` with `nextSteps: ["wrap-up"]` and increments `handoffCount`.

On #5216's run, a gauge call made after compaction (`--next-steps wrap-up`, context 445,119 tokens) wrote such a handoff. The agent had to recognise the rule break, ignore the handoff, and log the stray `handoff.json`. That file also spent one of the run's three handoffs (`HANDOFF_BOUND`).

Probe: `git grep -n -F -e "wrap-up" origin/main -- plugin/bin/context-gauge.js plugin/bin/lib/context-gauge` exits 1 (no match), and `git log -S "wrap-up" --oneline origin/main -- plugin/bin/context-gauge.js` prints nothing.

## Deliverables

- [ ] `context-gauge.js` refuses to write a handoff whose `nextSteps` contain `wrap-up` when the run is not bound `dispatched: true`. It prints `over` as measured with `handoff: null` and a `reason` naming the top-level wrap-up rule, and logs the SKIP the way its other non-null reasons are logged.
- [ ] A unit test covers both sides: a top-level run with `--next-steps wrap-up` past the cap writes no `handoff.json`, and a run bound `dispatched: true` with the same arguments still writes one.

## Acceptance Criteria

1. Past the cap, with `run-state.json` lacking `dispatched: true` and `--next-steps` including `wrap-up`, the gauge exits 0 with `handoff: null` and a non-null `reason`, and no `handoff.json` exists afterwards.
2. The same call against a run with `dispatched: true` writes `handoff.json` exactly as today.
3. `npm test` passes.

## Release Note

The pipeline's context gauge no longer hands wrap-up to a fresh agent in a run a human started, where the wrap-up console needs that session.
