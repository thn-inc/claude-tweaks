# 3737: Lens dispatch prompts should forbid shell-variable paths and cd-chains (9 harness refusals in one review)

**Related:** #3876, #3822

Origin: wrap-up reflect from #3682

## Current State

During #3682's /review (2026-10-20), 9 harness worktree-isolation refusals ("Refusing to run it") hit 5 of the 8 dispatched lens agents (one agent alone hit 5), each on a Bash command that built a path from a shell variable (W="..."; sed -n ... "$W/...") or chained `cd ... &&` with a heredoc, even though the dispatch prompt carried literal absolute paths and the Working Directory Discipline rule. `review/step3-lens-dispatch.md`'s dispatch rules tell agents to use `git -C <abs path>` and absolute arguments but never say "no shell variables for paths, one plain command per Bash call" — the constraint the harness actually enforces (`_shared/scratch-worktree.md` section 7).
