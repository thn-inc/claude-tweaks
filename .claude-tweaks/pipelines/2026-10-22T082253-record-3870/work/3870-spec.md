# 3870: log-decision.js rejects the "enum (note)" reversibility the skill-prose decision-log templates prescribe

Verified-as-of: bdc780eaa

Origin: reflect light from #3854

Defer-reason: tangential

## Current State

`plugin/bin/log-decision.js` validates `--reversibility` against the bare enum `high|med|low|n/a` (line 51: `--reversibility must be one of high|med|low|n/a`).

About 75 decision-log templates in `plugin/skills/**/*.md` prescribe a parenthetical note after the enum. Two examples:
- `flow/validation.md` Step 2.5: `Reversibility: low (divergence persists).`
- `flow/manifesto.md`'s design-critique row: `Reversibility: n/a (a policy read, not a code mutation).`

These templates write through `log-decision.js`, the sanctioned writer for a worktree-pinned session. An agent that passes the template's value verbatim gets a usage error, exit 2, and nothing is logged. It must notice the error and re-run, moving the note into `--text`. In #3854's run this happened twice: the Manifesto design-critique line and the Step 2.5 divergence line.

## Deliverables

- `log-decision.js` accepts a `--reversibility` value of an enum member optionally followed by one parenthesized note. Two examples: `low (divergence persists)` and `n/a (a policy read, not a code mutation)`.
- The written entry renders the value verbatim: `Reversibility: low (divergence persists).`
- A value whose leading token is not an enum member still fails with the existing usage error.
- `formatEntry` and the readers that parse `Reversibility:` (the Review Console and decision-log parsers) keep reading the leading enum token, unaffected by the trailing note.

## Acceptance Criteria

- [ ] `log-decision.js --reversibility "low (divergence persists)"` exits 0 and writes `Reversibility: low (divergence persists).`
- [ ] `log-decision.js --reversibility "bogus (x)"` and `--reversibility "lowish"` still exit 2 with the existing usage message.
- [ ] Every in-repo reader of `Reversibility:` in decisions.md is pinned to accept the trailing note. A test covers each one that parses the field.
- [ ] `npm test` passes.

## Release Note

Decision-log entries can carry a short reversibility note, such as "low (divergence persists)", as the skill templates already show.

## Technical Approach

### Key Files

- `plugin/bin/log-decision.js` — accept an enum value with one optional parenthesized note
