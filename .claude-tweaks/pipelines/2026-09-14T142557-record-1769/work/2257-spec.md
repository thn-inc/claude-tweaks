## Technical Approach

`git describe --contains {sha}` resolves purely from tag ancestry. `git describe --tags --contains --first-parent {sha}` restricted to first-parent ancestry returns at most one tag name in the normal case; a commit not yet contained in any tag returns non-zero, read as the literal string `unreleased`.

**Bootstrap version anchor.** `git log --diff-filter=A --format=%H -- .release-please-manifest.json` finds the commit that first introduced that file; the manifest's content at that revision is the anchor value.
