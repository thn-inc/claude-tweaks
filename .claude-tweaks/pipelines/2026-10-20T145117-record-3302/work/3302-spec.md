# 3302: review: the pre-dispatch untracked-file baseline cannot be written from a worktree-isolated session

Origin: reflect full from #2783

Defer-reason: tangential

## Current State

`plugin/skills/review/step3-lens-dispatch.md`'s "Pre-dispatch listing (scratch-sweep baseline)" step tells the reviewer to run `git status --porcelain --untracked-files=all > {ctx-dir}/pre-dispatch-status.txt` immediately after `build-review-context.js build` mints `{ctx-dir}`. The post-fan-out untracked-file sweep then diffs against that file.

Under `worktree-always`, `{ctx-dir}` is `{run}/review-ctx` in the main checkout, outside the reviewing session's worktree. In a worktree-isolated session, neither available path for that write works: the shell redirect into a shared-checkout path is a compound command the harness guard refuses, and the Write tool refuses with "Edit the worktree copy of this file instead of the shared-checkout path". Observed in #2783's review (2026-10-16): the reviewer had to keep the baseline in its own scratchpad, so the sweep's documented input file never existed.

`plugin/bin/build-review-context.js` already writes into `{ctx-dir}` (it creates `context.md` there), but it never captures this baseline itself.

## Deliverables

1. Make `build-review-context.js build` write `{ctx-dir}/pre-dispatch-status.txt` itself, using `git status --porcelain --untracked-files=all` run with the cwd set to the branch's worktree. Report its path in the printed JSON line (e.g. a `baselinePath` field).

2. Update `step3-lens-dispatch.md`'s Pre-dispatch listing paragraph and its Post-fan-out sweep paragraph to read the CLI-written file, and drop the hand-run redirect.

## Acceptance Criteria

- After `node plugin/bin/build-review-context.js build --base <ref> --branch HEAD --run <run-dir>`, `<run-dir>/review-ctx/pre-dispatch-status.txt` exists and matches `git status --porcelain --untracked-files=all` at that moment.

- `step3-lens-dispatch.md` no longer tells the reviewer to write any file under `{ctx-dir}` by hand.

- `npm test` passes.

## Release Note

Review's untracked-file sweep now works in worktree-isolated sessions: its baseline is captured automatically.
