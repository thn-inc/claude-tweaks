# 4173: _shared/pr-first-merge.md park comment writes its body to a fixed shared /tmp path

Origin: ledger resolve gate (wrap-up of #4065)

Defer-reason: pre-existing-outside-diff

## Current State

`plugin/skills/_shared/pr-first-merge.md` (Step 2.5's red path, the park comment, lines 253-254) composes the `Parked by merge-verification` comment body to a fixed shared `/tmp/park-comment-{n}.md` and posts it with `--body-file` on that path. `_shared/session-tmp-root.md` forbids fixed shared `/tmp` names: two sessions parking records that share an `{n}` clobber each other's body, so one record can receive the other's comment. The same hazard in `_shared/pr-run-comments.md` was fixed by #4065 (PR #4165), which resolves the paths through `bin/session-tmp-resolve.js` and substitutes the printed literals.

## Deliverables

- [ ] Resolve the park-comment body path through `node "${CLAUDE_PLUGIN_ROOT}/bin/session-tmp-resolve.js" PARK_COMMENT=park-comment-{n}.md` in `_shared/pr-first-merge.md` Step 2.5's red path, and use the printed literal path in both the `printf` redirect and the `--body-file` argument (a worktree session refuses a runtime variable path, `_shared/scratch-worktree.md` section 7).
- [ ] Add `_shared/pr-first-merge.md` to `tests/session-tmp-root-migration.test.js`'s `MIGRATED_FILES` and extend `_shared/session-tmp-root.md`'s consumer list; add a pin test that the park step names no literal `/tmp/park-comment-` path.
