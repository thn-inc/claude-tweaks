# 3604: Review medium tier: count cross-lens agreement as corroboration for unconfirmed findings

Origin: reflect full from #3258

Defer-reason: tangential

## Current State

/claude-tweaks:review confirms a lens finding only when both agents of that lens's reproduction pair report it (`step3-lens-dispatch.md`). Cross-lens agreement is used only at review-effort `high` and above, where Step 3.5's overlap detection runs. At `medium` (the default for risk:medium x size:medium records, e.g. record #3258) a defect that three different lens agents each reported independently (3a-B high, 3b-B low, 3c-A low: a superseded failed workflow run at the base sha marking a real PR failure inherited) stayed `unconfirmed` in every lens, because the partner agent of each lens missed it. It only reached a fix through the reviewing agent's manual Direct-verification override.

## Deliverables

At `medium` tier, after the per-lens reproduction pairs return, run `review-coordination.js detect-overlap` (or an equivalent cross-lens match on path +-5 lines and substance similarity) over the `unconfirmed` findings only, and treat a finding reported by two or more different lenses as corroborated: emit it `confirmed` with a log line naming the lenses. Keep `high`+ behavior (Step 3.5 debate) unchanged. Pin the new rule in the review prose conformance tests.

## Acceptance Criteria

A review at `medium` effort where two different lenses each have one agent reporting the same path/line and substance routes that finding as `confirmed` (not `unconfirmed`), with a decisions.md line naming both lenses. A finding reported by one lens only stays `unconfirmed`. The `low` tier single-read rule is unchanged.

## Release Note

Review at medium effort now treats a defect reported independently by two different lenses as confirmed instead of leaving it as a low-confidence finding.
