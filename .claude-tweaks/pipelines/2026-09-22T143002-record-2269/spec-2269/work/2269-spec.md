## Technical Approach

Mechanical text replacement for 4 of the 7 files (`simplify/SKILL.md`, `help/status-scan.md`,
`_shared/transcript-judge.md`, plus wording updates), matching the canonical trailing-line phrasing
#2265 establishes. Three files additionally need structural reordering, not just a wording swap:
`browse/SKILL.md`, `visual-review/page-mode.md`, and `visual-review/discover-mode.md` are all
Template A-shaped dispatch sites (status line then table/template, today), so each moves its
status-line instruction to describe a trailing position after the table/template instead; and
`feedback/session-evaluation.md`'s inlined output template literally has the enum positioned first
in the template block, so that block's own line order changes, not merely the prose describing it.
