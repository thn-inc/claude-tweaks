# 3058: Audit claude-tweaks configs for the thinkingdisabled rename

Surface: infra

## Current State

The audit the original request asks for has a known answer at shaping time: a repo-wide `git grep -i -E 'thinking_?disabled|between_tools'` returns zero hits. Nothing in `plugin/`, `docs/`, `tests/`, `evals/`, or the project's `.claude/` references either spelling.

claude-tweaks does not set a thinking mode anywhere. It controls models through two settings:

- Agent and routine frontmatter set `model:` and `effort:` only. `plugin/agents/qa-agent.md` uses `model: sonnet` and `effort: medium`. Every `plugin/skills/*/routine-template.yml` carries a `model:` line, for example `plugin/skills/specify/routine-template.yml:7` `model: claude-sonnet-5`.
- Subagent dispatches resolve a model profile through `plugin/bin/resolve-profile.js`. The profiles (`plugin/bin/lib/model-profiles/profiles.js:15-18`) carry `model` and `effort` fields only, and effort reaches the agent as a prompt line, not an API thinking setting (`profiles.js:27-29`).

The external change: Claude Sonnet 5.5 renames the no-upfront-thinking setting from `thinkingdisabled` to `between_tools` (source in the original request below).

`docs/skill-authoring.md`'s "Model-version prompting notes" section (line 215) is where this repo records per-model deltas that affect how skills are authored. It currently has a Fable 5.1 entry (line 233) and no Sonnet 5.5 entry.

## Deliverables

1. Re-run the zero-usage audit at build time (the grep above, repo-wide, both spellings) and record the result in this record's closing comment.
2. Add one short Sonnet 5.5 bullet to the "Model-version prompting notes" section of `docs/skill-authoring.md`. It should state the `thinkingdisabled` to `between_tools` rename, cite the migration guide, and say that claude-tweaks sets no thinking mode today (model and effort only), so nothing needs migrating. Any future agent, routine template, or profile that adds a thinking setting should use `between_tools` when targeting Sonnet 5.5.

## Acceptance Criteria

- The build-time grep for `thinkingdisabled` (case-insensitive, with and without an underscore) returns zero hits outside the new note.
- `docs/skill-authoring.md`'s Model-version prompting notes section carries a Sonnet 5.5 bullet naming both spellings and linking the migration guide.
- CLAUDE.md is unchanged. The note belongs in the model-version section, not the always-loaded file, which has a line budget.

## Release Note

No user-facing change. This records the Sonnet 5.5 thinking-setting rename in claude-tweaks' authoring notes; no configuration needed migrating.

If the build-time grep unexpectedly finds a usage, migrate it in the same change, scoped to settings that target `claude-sonnet-5-5`, and list it in the closing comment.

- Routine templates pin `claude-sonnet-5`, not `claude-sonnet-5-5`. Bumping their model is a separate decision, out of scope here.
