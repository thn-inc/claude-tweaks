# 3897: Add a read-side resolve-ledger verb so ledger readers stop restating the probe-and-fallback prose rule

Origin: reflect full from #3687
Defer-reason: tangential

## Current State

#3687 moved every ledger reader outside wrap-up onto `_shared/ledger-format.md`'s resolution rule: run `wrap-up-pack.js --print ledger --json {run-dir}/wrap-up-pack-ledger.json`, read `value.files`, treat `value.unattributedFiles` as other runs' ledgers, and take a glob fallback only for a reader with no probe result. Deletion already has a verb (`hooks.js delete-ledger`, resolving through `resolveLedgerPath`), so the delete path inherited ownership and fail-closed behaviour for free, while each reader carries a prose copy of the rule and its edge cases. The build and review of #3687 found six such edge cases in prose (probe failing with `records unresolved` while a run-dir `ledger.md` exists, `unattributedFiles` absent on the run-dir path, append versus flip behaviour on a probe failure, a stale Input table), and the conformance test can only scan sentences for the bare glob, with known escapes (`ALLOWED_RE`, other glob spellings). Evidence: review ledger rows 16-22 and the 3c/3f lens findings on `plugin/skills/ledger/SKILL.md` and `plugin/skills/_shared/ledger-format.md`. Cost this session: one review fix round plus a full-suite rerun.

## Deliverables

- [ ] Add a read-side verb (for example `hooks.js resolve-ledger --run <dir>`) that resolves through `bin/lib/wrap-up/ledger-write.js`'s `resolveLedgerPath` and prints this run's ledger path(s), the other runs' ledgers, and a closed set of reports (`found`, `none`, `ambiguous`, `unattributable`), exit 0 like `delete-ledger`
- [ ] Repoint `ledger/SKILL.md`, `review/code-mode-steps.md`, and `_shared/ledger-format.md`'s resolution rule at the verb, keeping the rule's one-paragraph statement and dropping the per-reader edge-case prose
- [ ] Extend `tests/ledger-reader-ownership-conformance.test.js` to pin that a this-run lookup names the verb, replacing the sentence-level glob scan where the verb now decides

## Acceptance Criteria

1. The verb returns the run-dir `ledger.md` when it exists, even when the ownership probe's records are unresolved.
2. The verb never returns an inherited `docs/plans/` ledger as this run's, and reports `unattributable` where `resolveLedgerPath` does.
3. No reader in `plugin/skills` restates the probe's `value.files` / `value.unattributedFiles` handling; each cites the rule.
4. `npm test` passes.

Ledger readers outside wrap-up resolve this run's ledger through one command instead of per-skill instructions.
