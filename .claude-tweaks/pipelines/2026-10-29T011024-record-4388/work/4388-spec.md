Origin: windows-regression.yml post-merge check on 3ad36593f (PR #4335, #4133)

## Current State

The post-merge Windows check on 3ad36593f (run 40288495705, base 9aaf50f45) attributes two new failures in `tests/test-impact-tracer.test.js`: "AC1.1: a require records its candidates up to the one it resolves to, minus those under an earlier probe" and "AC1.1: a require resolves the way Node does — paths option, package.json main, bare node_modules lookups". #4133 added both tests in that commit. Both fail with `Cannot find module 'D:aclaude-tweaksclaude-tweakstoolstest-impacttracer.js'`.

That error is the NODE_OPTIONS backslash class. At 3ad36593f the test's `traceEnv` built `` `--require "${TRACER}"` `` from a native path (`tests/test-impact-tracer.test.js:39` at 9aaf50f45). Node's NODE_OPTIONS parser treats `\` inside double quotes as an escape, so on win32 the preload path loses its backslashes and the tracer never loads. Every traced test in the file failed the same way on Windows before 3ad36593f, as #4134's absorbed #4254 section records. Baseline adjudication counts only these two as new because they did not exist at the base.

**Probed at shaping time (2026-10-26) against `origin/main`: already fixed, not yet confirmed on Windows.** PR #4316 (#4134, merged 2026-10-26T10:51:30Z as 7e9b02af4, 4 commits after 3ad36593f) did three things:

- It added `tools/test-impact/node-options.js`'s `requireOption(p, pathImpl)`, which forward-slashes the path before quoting it.
- It switched `traceEnv` (`tests/test-impact-tracer.test.js:40` on main) and both fixture preloads (`:242`, `:311`) to it.
- It pinned the win32 branch in `tests/test-impact-cli.test.js:38` with `path.win32`.

The two failing tests are now at `:183` and `:203` on main and go through `traceEnv`, so the fix covers them. #4316's own Windows proof (runs 40210345387, 40212335250 on 2026-10-25) ran on a branch based before 3ad36593f, so it never executed these two tests. The post-merge Windows run on 7e9b02af4 (40310659583) was still in progress at shaping time.
