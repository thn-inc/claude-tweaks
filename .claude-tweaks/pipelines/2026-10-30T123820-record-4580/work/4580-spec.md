# 4580: Rebind the run PR body when a resumed run reuses a still-open PR

Origin: reflect full from #3903

Defer-reason: tangential

**Related:** #4588

## Current State

A resumed run that adopts a prior attempt's branch and finds its draft PR still OPEN reuses that PR without rebinding its body, so the body keeps naming the prior run. `bin/pr-checklist.js` refuses every phase-checklist update on a body naming another run (exit 4), so the resumed run's checklist stays frozen until someone rewrites the body by hand.

Observed in run `2026-10-30T063836-record-3903` (record #3903, PR #4541): `decisions.md` shows `reusing open PR #4541` (build, 07:45:10), then `PR checklist refresh: refused on PR #4541 — run marker mismatch (body names run 2026-10-28T231420-record-3903)` (08:11:33), then a manual rebind at build Common Step 7 (08:12:08). The build phase exit wrote nothing.

Probe on `origin/main` (fetched this session): `git grep -n -F -e 'Rebind a retry' origin/main -- plugin/skills/_shared/pr-early-run-lifecycle.md` matches only the CLOSED/reopen branch (`pr-early-run-lifecycle.md:115`, #3887). The OPEN-reuse bullet (`:92-97`) has no rebind, and `git log -S 'rebound reused' origin/main` over that file and `plugin/skills/build` returns nothing. `plugin/bin/lib/flow/pr-early-open.js` rebinds only after `gh pr reopen` (lines 163-191); its two reuse returns (lines 110 and 156-159) do not.

## Deliverables

- `plugin/bin/lib/flow/pr-early-open.js`: on both reuse outcomes (the recorded PR still open, and an OPEN PR found by head branch), when the PR body names a run other than the current one, rebind it exactly as the reopen branch does (compose this run's body, `gh pr edit --body-file`, log `rebound reused PR #{n} to run {run-id}`; a failed rebind is a logged `SKIP` degrade, never a stop).

- `plugin/skills/_shared/pr-early-run-lifecycle.md`: the OPEN-reuse bullet states the rebind and its log line, mirroring the `Rebind a retry (#3887)` paragraph, and says when it applies (the run adopted a prior attempt, or the body names another run).

- `tests/bin-lib/flow/pr-early-open.test.js`: a case per reuse path asserting the rebind call and the log line, and a case where the body already names this run and no edit is made.

## Acceptance Criteria

- Run `pr-early-open` against a fake `gh` whose OPEN PR body names run A while the current run is B: the PR body is rewritten to name B before the first push, and `decisions.md` carries `rebound reused PR #{n} to run B`.

- The same run with a body that already names B makes no `gh pr edit` call.

- After a rebind, `node bin/pr-checklist.js --run {run-dir} --phase build --fixes {n}` exits 0 with `action: written` instead of exit 4.

- A failing `gh pr edit` logs the `SKIP` degrade line and still returns the reused PR, recorded.

## Release Note

A resumed run that reuses a still-open draft PR now rebinds the PR body to the new run, so the phase checklist updates at every phase exit instead of being refused until a manual rewrite.

## Technical Approach

### Key Files

- `plugin/bin/lib/flow/pr-early-open.js` — rebind on both reuse outcomes
- `plugin/skills/_shared/pr-early-run-lifecycle.md` — state the rebind in the OPEN-reuse bullet
- `tests/bin-lib/flow/pr-early-open.test.js` — cover the two reuse paths
