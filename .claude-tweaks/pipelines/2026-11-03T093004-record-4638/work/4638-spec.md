## Acceptance Criteria

A scoped run at the integration tip runs the suites its changed paths map to, or reports that it verified nothing; it never stamps verifiedHead from zero suites over a non-empty delta.
- [ ] A delta whose changed paths all map to no suite (bookkeeping-only) is exempt: its `none` run still stamps, as before.

## Release Note

A verification run whose changed files map to tests can no longer report the tree as verified without running them.
