## Technical Approach

Wait for (or trigger) a `/claude-tweaks:specify` decomposition-mode run that produces 2 or more
`ceremony:standard` sub-issue records — `ceremony-check` (`assess-agent-autonomy/ceremony-check.md`)
resolves the tier per sub-issue during that run's own Step 3, so the tier isn't knowable until the
run happens. Once such a run occurs, inspect that session's stored transcript for the Step 5
red-team dispatch (`specify/red-team.md`'s Parallel dispatch section): locate the `Agent` tool_use
blocks for each dispatched persona and group them by the assistant message id each block belongs
to. Confirm the number of distinct assistant message ids covering all persona dispatches for a
given sub-issue is ≤ the number of sub-issues in that batch. Use the same read-only transcript
inspection method `transcript-payload-verification` documents for reading this session's own
locally-stored transcript, rather than instrumenting or modifying `red-team.md` itself.

If the count exceeds the bound, file a defect issue against `red-team.md`'s dispatch prose
(quoting the transcript grouping that violates the rule) instead of editing the file directly from
this record — this record's own deliverable is the observation, not the fix.
