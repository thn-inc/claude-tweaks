# #2346 — Plugin commit call sites have no bounded git index.lock retry

Materialized from GitHub issue #2346 (labels: ready, risk:low, size:low, type:bug, auto:build, auto:merge, priority:medium, ceremony:standard, by:reflect, shaped:headless). Related to #2330 (same file-overlap group — `archive-merged.js`). An existing open draft PR #2403 already targets both #2330 and #2346 from a prior, apparently-stalled run (`worktree-record-2330-2346`, phases build/test/review/polish/wrap-up all checked as of 2026-09-14) — this run's claim-registry check found the prior claim already released (tombstoned as "swept: stale claim"), so this is a fresh, independent re-implementation in this run's own worktree/branch, not a continuation of PR #2403.

## Deliverables

- A shared bounded retry for index-lock contention — `bin/lib/git-retry.js` exporting `withIndexLockRetry(gitRunner, { attempts, waitMs, sleep })`, modeled on `bin/lib/feedback/file-feedback.js`'s `withTransientRetry`: retry **only** on a stderr signature naming `index.lock` (`Unable to create … index.lock` / `another git process seems to be running`), bounded (~15 attempts at 2s), injectable `sleep`, never unlinking a lock file.
- Route every plugin commit call site through it: `bin/lib/reconcile/archive-merged.js`, `bin/lib/release/run.js`, `bin/release-local.js`.
- Cite the rule once where skill prose instructs a hand-written `git commit`.

## Acceptance Criteria

1. `withIndexLockRetry` retries on an `index.lock` stderr signature and does NOT retry on any other git failure (fake-runner tests both directions).
2. The helper never unlinks a lock file (asserted directly).
3. Retries are bounded — a fake runner that always fails on `index.lock` exits after the configured attempt count with the original error; injected `sleep` makes the test instant.
4. Each of the three named commit call sites routes through the helper (grep proves no direct `['commit', …]` call bypasses it); `npm test` passes.

## Non-Goals

- Replacing `file-lock.js`'s directory mutex (different resource).
- Changing what commits contain or when they run.

## Key Files

- `plugin/bin/lib/git-retry.js` — new file.
- `plugin/bin/lib/reconcile/archive-merged.js`, `plugin/bin/lib/release/run.js`, `plugin/bin/release-local.js` — route commit calls through the retry.
- A skill/`_shared/*.md` file with hand-written `git commit` prose — add one citation.
