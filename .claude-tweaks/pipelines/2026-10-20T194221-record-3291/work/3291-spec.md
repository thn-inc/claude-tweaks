# 3291: Give tidy's release Backfill findings a routing row in step-6-auto

Defer-reason: pre-existing-outside-diff

## Current State

`plugin/skills/tidy/scan-procedures.md` collects every `kind: release` residue finding as `[git] {subject} — {evidence} — Backfill`. Since #2882 there are two flavors: `remedy: auto` (a `v*` tag with no CHANGELOG heading) and `remedy: record` (a CHANGELOG heading with no local or remote tag, where tagging released history is a human call).

`plugin/skills/tidy/step-6-auto.md`'s routing table, which gives every recommendation an auto-apply tier per aggressiveness level (`conservative` / `moderate` / `aggressive`), has no **Backfill** row. Neither release flavor has a stated tier, so the step's own rule applies: "a finding class that keeps staging needs a routing row". Found by the journeys curation judge in the #2882 wrap-up and confirmed by grep: the only `Backfill` occurrence in `plugin/skills/tidy/` is the scan-procedures line.

## Deliverables

- A **Backfill** row (or two, one per remedy) in `step-6-auto.md`'s routing table. The `remedy: record` flavor never auto-applies at any tier, because creating or pushing a tag is an outward-facing write. The `remedy: auto` flavor gets an explicit tier for adding the missing CHANGELOG heading.
- `scan-procedures.md`'s release paragraph points at that row instead of carrying the disposition inline, keeping the file within its `tests/release-lifecycle-byte-budget.test.js` bound.
- A conformance test pins that every `— {Action}` verb `scan-procedures.md` emits has a matching routing row in `step-6-auto.md`.

## Acceptance Criteria

- [ ] `step-6-auto.md` states a tier for both release-finding flavors at all three aggressiveness levels.
- [ ] The heading-with-no-tag flavor is never Auto-apply at any tier.
- [ ] The new conformance test fails when a scan action verb has no routing row (checked by temporarily deleting the Backfill row).

## Release Note

`/claude-tweaks:tidy` now states how it routes release tag/CHANGELOG mismatches at each aggressiveness level, and never auto-tags released history.
