## Gotchas

- Use a non-markdown extension: markdown is stubbed at any size (`build.js:288`, #3713), so a `.md` fixture never reaches the byte cap and cannot discriminate `:287`.
- `PER_FILE_CAP_BYTES / 2 + 1` characters of a 2-byte character is `PER_FILE_CAP_BYTES + 2` bytes — over the cap by bytes, under it by characters. Check the fixture's character count is below the cap so the test cannot pass on a character-count implementation.
- `'é'` must be the precomposed U+00E9 (2 bytes in UTF-8), not `e` plus a combining accent; use `'é'` in source to be explicit.
