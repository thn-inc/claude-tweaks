# 3330: candidates-experiment-cleanup.js requires candidates-dead-code before focus-generators (circular-require hazard)

Surface: backend

**Related:** #2869, #3026, #3380

## Current State

`plugin/bin/lib/code-health/candidates-experiment-cleanup.js:60-61` requires `./candidates-dead-code` before `./focus-generators` — the order `.claude/skills/code-health-focus-vertical/SKILL.md` pitfall 1 forbids, and the same shape #2908 fixed in `candidates-security-hardening.js`. Verified 2026-10-17: `node -e "require('./plugin/bin/lib/code-health/candidates-experiment-cleanup')"` prints four `Accessing non-existent property ... inside circular dependency` warnings (`listTrackedSourceFiles`, `isGlobDiscoveredTestFile`, `extractModuleExports`, `escapeRegExp`), leaving sibling verticals' shared helpers bound to `undefined` in that process. `candidates-prelaunch.js:69-70` and `candidates-abstraction-police.js:69-75` already use the correct order (`./focus-generators` first).

## Deliverables

1. In `candidates-experiment-cleanup.js`, move `const { registerGenerator } = require('./focus-generators');` above `const { listTrackedSourceFiles } = require('./candidates-dead-code');`, matching the two sibling verticals.
2. Add a regression test in `tests/bin-lib/code-health/candidates-experiment-cleanup.test.js` that requires the module in a fresh `node` child process and asserts stderr carries no `circular dependency` warning — proven red against the current order before the swap.

## Acceptance Criteria

- `node -e "require('./plugin/bin/lib/code-health/candidates-experiment-cleanup')"` prints no circular-dependency warning.
- The new test fails on the pre-swap order and passes after it.
- `node --test tests/bin-lib/code-health/` passes.

## Release Note

Fixed a module load-order hazard in the experiment-cleanup code-health check.

## Technical Approach

Two-line reorder plus one child-process test (a fresh process is required — an in-process `require` would hit the module cache and miss the warning). No behavior change beyond load order.

### Key Files

- `plugin/bin/lib/code-health/candidates-experiment-cleanup.js` — swap the two require lines
- `tests/bin-lib/code-health/candidates-experiment-cleanup.test.js` — add the fresh-process no-circular-warning test

## Gotchas

- Node's circular-dependency warning is emitted only on the first load in a process; the test must spawn a child process, not reuse the test runner's module cache.
