# 3198: archive-run silently overwrites an already-archived run directory (decisions.md, events.jsonl, run-state.json)

Origin: /claude-tweaks:dispatch close-out of #3119 (PR #3181), 2026-10-16

Defer-reason: tangential

## Current State

`archiveRunDir` (`plugin/bin/lib/reconcile/archive-merged.js`, ~line 771) computes `archiveDirPreexisted` but uses it only on refusal paths. On the success path it `renameSync`s every non-`work/` entry into `archive/{runId}/`, silently overwriting any same-named file already there.

`close-run` (`bin/hooks.js`) and `bin/release-claim.js` both write into a run-dir path that no longer exists (recreating it) instead of refusing — unlike `log-decision.js`, which refuses with `run dir does not exist`.

Observed 2026-10-16 closing out #3119 (PR #3181): a concurrent unlocked `reconcile` archived `2026-10-15T184334-record-3119` mid-sequence; `release-claim.js` then wrote a 1-entry `decisions.md` into a recreated run dir at the old path, `close-run` added a fresh `run-state.json`/`events.jsonl`, and `hooks.js archive-run` moved all three over the real archived copies. The ~50-entry decision log was replaced by a stub (partially rebuilt from subagent transcripts); `events.jsonl` was lost (gitignored, no snapshot).

## Deliverables

- `archiveRunDir` never overwrites an existing destination entry: when `archive/{runId}/{entry}` already exists it refuses (new refusal reason) or, for append-only logs (`decisions.md`, `events.jsonl`), appends instead of replacing.
- `close-run` and `release-claim.js` refuse to recreate an absent run dir: when the path is missing but `archive/{runId}/` exists, resolve to the archive twin or skip the local write with a warning, matching `log-decision.js`.
- A regression test covering archive -> recreate stub -> `archive-run` that asserts the original archived `decisions.md` content survives.

## Acceptance Criteria

- Running `hooks.js archive-run --run X` when `archive/X/decisions.md` already exists leaves its original lines intact (byte-for-byte prefix preserved).
- `close-run --run X` against an already-archived run creates no files at the old path.
- `release-claim.js N --run X` against an already-archived run creates no files at the old path, and still releases the claim and posts the comment.
- New tests fail on the pre-fix code (verified by reverting) and pass after.

## Release Note

A pipeline run decision log can no longer be silently overwritten when two cleanup paths archive the same run.
