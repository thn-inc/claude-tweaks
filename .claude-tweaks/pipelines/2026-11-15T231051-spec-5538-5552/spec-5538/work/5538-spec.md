# 5538: Move the two test-only skill-audit parsers to tests/helpers

Surface: infra
Risk-flags: none

## Overview

`plugin/bin/lib/skill-audit/argument-hint.js` and `plugin/bin/lib/skill-audit/option-description.js` ship in the plugin payload, but only files under `tests/` import them. They are maintainer tooling: parsers that conformance suites use to check skill frontmatter and `AskUserQuestion` option text. This record moves both to `tests/helpers/`, where the repository keeps shared test code, so users stop installing them.

This is part of unit 1.4 of the 2026-11-15 audit simplification design, which chose to move the two modules rather than delete them: the suites that use them are live gates.

**Complexity:** Low
**Estimated tasks:** 3

## Non-Goals

- Changing what either module parses or what any suite asserts.
- Moving other `skill-audit` modules. `context-cost`, `harness-cost`, `budgets`, `load`, `plugin-root-reader` and `transcript-load` are required by plugin code; `bloat.js` and `rail.js` are run by skill prose through `node -e`.
- Renaming the test files that use the helpers.

## Prerequisites

None.
