## Technical Approach

The history comments are replaced, not just deleted, because of the merge behaviour described in Current State. One `Last bump:` line that every bump rewrites keeps the textual conflict between concurrent bumps at a cost of one line instead of several hundred. The full history stays reachable with `git log -L` on the assertion.

The history that goes with the deleted comments is dropped on purpose: `git log -L` on the assertion line returns the commits that changed the number, whose subjects name the record, but a reworded row (which changes no count) and the explanatory text of each entry are no longer recorded anywhere. That loss is accepted. `docs/donts.md:133` and `docs/incident-log.md:629` state the recompute rule, not a comment mandate, and stay untouched.

For the number-list tests the order is: add the five cases to the scaffold test, see them pass, then delete from the CLI files. That way no behaviour is untested between two commits.
