# 3665: Widen the claim-log-only class so degraded Step 2.8 mints (SKIP lines, paraphrased claims) stay unadopted

Origin: ledger resolve gate (#3363 final-review Minor 2)

Defer-reason: genuinely-larger

## Current State

#3363 made hook fallback attribution (`isUnadoptedMint`, `plugin/bin/lib/hooks/context.js`) and `/flow` preflight adoption (`decisionsHasContent`, `plugin/bin/lib/flow/preflight.js`) treat a run dir whose `decisions.md` holds only the canonical Step 2.8 claim line as an unadopted mint. Both readers share `classifyDecisions` (`plugin/bin/lib/log-decision/claim-log.js`), which returns `claim-log-only` only for an exactly canonical claim line. Step 2.8 can also write a `SKIP` bookkeeping line (`plugin/skills/flow/claim-targets.md` lines 117 and 219: the file-overlap skip and the degraded `bot:in-progress` projection), and a model may paraphrase the claim (#3012). Such a file classifies `content`, so the mint reads as adopted and the #3337 contamination (a sibling session's events landing in the mint) and the preflight case-3 misadoption return for those degraded runs. Surfaced by #3363's final whole-branch review (Minor 2) and ruled out of scope there because widening the shared classifier touches the preflight and hook readers together.

## Deliverables

- [ ] Widen the claim-log-only class in `classifyDecisions` so a recognised Step 2.8 bookkeeping line (the two `SKIP` shapes in `claim-targets.md`) and `paraphrasedClaimNumbers` claim lines count as claim-log lines, keeping every unrecognised line `content` (fail closed).

- [ ] Confirm both readers (`isUnadoptedMint` in `plugin/bin/lib/hooks/context.js`, `decisionsHasContent` in `plugin/bin/lib/flow/preflight.js`) pick the widened class up without a second copy of the shape check, and that `verify-run-bookends.js` and the `pre-tool-use.js` claim-log readers are unaffected.

## Acceptance Criteria

- [ ] A `tests/hooks-run-attribution.test.js` case: a mint whose `decisions.md` holds the canonical claim line plus a Step 2.8 `SKIP` line (overlap skip shape) and no `run-state.json` is not selected by fallback attribution.

- [ ] A case for the degraded `bot:in-progress` projection `SKIP` line and one for a paraphrased claim line, each asserting the same.

- [ ] A `tests/bin-lib/flow/preflight.test.js` case: the same files beside fallback-only `events.jsonl` resolve to adoption case 2, not case 3.

- [ ] A file with any line outside the widened class (a Manifesto or build line) still classifies `content`; `npm test` passes.

## Release Note

A run that hit a degraded Step 2.8 claim path no longer absorbs other sessions' hook events or gets misread as an in-flight run at preflight.

## Technical Approach

### Key Files

- `plugin/bin/lib/log-decision/claim-log.js` — widen classifyDecisions' claim-log-only class
- `plugin/bin/lib/hooks/context.js` — isUnadoptedMint reader (no new shape check)
- `plugin/bin/lib/flow/preflight.js` — decisionsHasContent reader (no new shape check)
- `tests/hooks-run-attribution.test.js` — SKIP and paraphrase mint cases
- `tests/bin-lib/flow/preflight.test.js` — SKIP and paraphrase case-2 adoption
