# 4387: reconcile archive-merged strands tracked work/ specs when the local integration branch is behind origin

Origin: dispatch close-out session 2026-10-26 (PRs #4276, #4302, #4319, #4334, #4354)

Defer-reason: tangential

## Current State

`plugin/bin/lib/reconcile/archive-merged.js`'s `localHasMerge` (the #1130 guard against #657) checks the merge commit against `refs/heads/{integration}`. When the local ref lacks it, the guard falls back to `origin/{integration}` (#2565).

That fallback also fires when the local integration branch exists but is behind. In that case the tracked `work/{n}-spec.md` is not in the main checkout yet. The sweep moves the run dir's gitignored half into `archive/` and has nothing to `git mv`.

Once main fast-forwards, the spec reappears at `.claude-tweaks/pipelines/{run}/work/` as a state-less dir. `archive-run` refuses it (no readable run-state.json). The orphaned-mint sweep only takes it after a 24 h TTL.

Observed 2026-10-26: the main checkout was dirty and 19 commits behind origin. Four stranded specs (runs for #3988/#3987/#3980/#3759) were the dirt that blocked mirror-ff. In that state, the merges of PRs #4276/#4302/#4319/#4334/#4354 stranded five more specs the same way, a self-perpetuating loop.

Both sets were archived by hand in 7b39e4683 and 9aaf50f45.

## Deliverables

1. Make the archive decision require the merge in the checkout the `git mv` runs against. Accept the local integration ref, or HEAD when that is the integration branch. When only `origin/{integration}` has it while the local ref exists and is behind, skip and retry on a later pass instead of archiving the untracked half.
2. Keep #2565's case working: a main checkout parked on another branch, or with no local integration ref.
3. Add a regression test in `tests/bin-lib/reconcile/archive-merged.test.js`. It uses a local integration branch behind an origin that holds the merge, and asserts that nothing is moved and the reason is a retryable skip.

## Acceptance Criteria

- [ ] With a local integration branch behind the merge and origin holding it, reconcile leaves the run dir in place and reports a retryable skip.
- [ ] After the local branch fast-forwards, the same pass archives the run dir and `git mv`s `work/` in one commit.
- [ ] #2565's no-local-ref and parked-checkout cases still archive.

## Release Note

Reconcile no longer half-archives a merged run while the main checkout is behind, so its spec file is never left stranded.
