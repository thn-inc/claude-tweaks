# 4012: release: Step 3's review-tree check fails whenever local main carries unpushed reconcile archive commits

**Related:** #3396, #3721, #3898

Origin: /claude-tweaks:release run 2026-10-24 (Step 3 review-tree stop)

Defer-reason: tangential

## Current State

`/claude-tweaks:release` Step 3 (`plugin/skills/release/SKILL.md`, the "Invoke it from `$RUN_ROOT`, standing at the fetched tip" paragraph) requires `git -C "$RUN_ROOT" rev-parse HEAD` to equal `origin/{branch}` exactly. Anything else stops the run before the console with `stopped before the console: review tree is not origin/{branch}` and outcome `failed`.

Reconcile's archival path (`plugin/bin/lib/reconcile/archive-merged.js`) commits `[reconcile] archive run …` renames to the main checkout's local `main` and never pushes them. So any archival that happens between pushes makes local `main` diverge from `origin/main`, and the next release fails at Step 3. Those commits only move files under `.claude-tweaks/pipelines/`, which never ships.

Observed 2026-10-24: local `main` was 8 commits ahead (all `[reconcile] archive run`) and 48 behind, and the release stopped. Recovering by hand took three steps. First, move aside two untracked sweep run dirs that `origin/main` had since started tracking, because they blocked the rebase. Second, `pull --rebase`, which dropped 4 of the 8 commits as already upstream. Third, a bare `git push origin main`. The 2026-10-21 release run had hit the same divergence and also worked around it by hand.

## Deliverables

1. Step 3's review-tree check accepts a main checkout that is 0 commits behind `origin/{branch}` and whose tree differs from it only under `.claude-tweaks/pipelines/` (`git diff --quiet origin/{branch} HEAD -- ':!.claude-tweaks/pipelines'`). A checkout that is behind, or differs anywhere outside run dirs, still stops the run exactly as today.
2. When the check does stop the run, the stop line names the ahead/behind counts and the paste-ready recovery commands (`git -C "$RUN_ROOT" pull --rebase origin {branch}`, then a bare `git push origin {branch}`). *(As built: the recovery is chosen by the first failed clause. Behind or diverged prints this pair verbatim. A wrong branch prints `(on {current})` and `git -C "$RUN_ROOT" switch {branch}`. A checkout 0 behind but with changes outside run dirs lists them (`diff --name-only … -- ':!.claude-tweaks/pipelines'`) and says they need a PR, with no push command, because pasting the pair there would push unreviewed work to `{branch}`. The fetch is part of the check's `&&` chain, and a failed fetch stops the run with git's stderr verbatim. The ruling is staged as `spec-4012/staged/sdd-ruling-1.md`.)*
3. Step 3's log line records both `HEAD` and `origin/{branch}` shas whenever they differ, so the review's test-gate evidence can be traced to the tagged tip.

## Acceptance Criteria

- A release whose main checkout has only `[reconcile] archive run` commits ahead of `origin/{branch}`, and is 0 behind, passes Step 3's review-tree check and runs the whole-branch review.
- A checkout that is behind `origin/{branch}`, or whose tree differs from `origin/{branch}` at any path outside `.claude-tweaks/pipelines/`, still stops with `review tree is not origin/{branch}`, and the stop line includes the ahead/behind counts and the recovery commands.
- A conformance test pins the relaxed check's pathspec exclusion and the stop line's recovery commands in `release/SKILL.md`, and reverting the prose change turns it red.
- `npm test` passes.

## Release Note

`/claude-tweaks:release` no longer refuses to run just because local `main` carries unpushed run-archive commits, and when it does stop on a diverged checkout it prints the commands to fix it.
