# 4283: Windows: skill snippets splice CLAUDE_PLUGIN_ROOT into JS string literals, so a backslash root breaks require

Origin: #2767 class split — classification of windows-regression run 40169646104 (main 6a41ebe3a)

Defer-reason: genuinely-larger

**Related:** #2767, #4146 (this record takes its G part), #4134 (owns the test-impact tracer half of class G, the NODE_OPTIONS `--require` splice, including #4254), #3517, #3599

## Current State

Shipped skill prose splices `${CLAUDE_PLUGIN_ROOT}` into JavaScript source. The shell expands it inside `node -e "…"` strings and inside unquoted `node-eval-file.js` heredoc bodies, so it lands in a JS string literal. There, `\a`, `\_` and `\c` are eaten as escapes and `\u` is a SyntaxError. A Windows root such as `D:\a\claude-tweaks\…` therefore reaches `require` as `D:aclaude-tweaks…`. The failing evidence is `Cannot find module 'D:aclaude-tweaksclaude-tweaksplugin/bin/lib/issues/grant-maturation.js'`.

How far it reaches: `grep -rhoE "require\(['\"]\\$\{?CLAUDE_PLUGIN_ROOT" plugin/skills` finds 244 occurrences across 61 files. There are also non-`require` literals: `const path = '${CLAUDE_PLUGIN_ROOT}/CHANGELOG.md'` (`plugin/skills/init/bootstrap/version-check.md:58`) and `fs.readFileSync('${CLAUDE_PLUGIN_ROOT}…` (`plugin/skills/init/update-mode.md:64`). The failing tests run these sites:

- `plugin/skills/dispatch/grant-maturation-gate.md:32`, `:79`
- `plugin/skills/wrap-up/auto-merge-short-circuit.md:28`, `:56`, `:86`
- `plugin/skills/backlog/attention-mode.md:42`, `:58`, `:120`

Some snippets already pass values as data, for example `plugin/skills/wrap-up/auto-merge-short-circuit.md:192` and `plugin/skills/wrap-up/refused-proposals.md:16`, which read `process.argv[1]`. Five suites work around the splice by forward-slashing the root inside the test (`tests/dispatch-mcp-timestamp-alias.test.js:60-62` and four siblings), which hides the production shape.

`tests/comment-trust-conformance.test.js:483` also splices native temp paths for the `$ST_*` variables. Production prints those with `/` on win32 (`plugin/bin/session-tmp-resolve.js:26-27`, `formatPrintedPath`), so that half is test-only.

3 tests in 1 file fail on Windows (line numbers as of 988cc584d). The 18 failing `tests/test-impact-tracer.test.js` tests in the same class come from a different splice, NODE_OPTIONS `--require "<native path>"`. They are handed to #4134.

## Deliverables

- Remove every JS-literal splice of `${CLAUDE_PLUGIN_ROOT}` from `plugin/skills/**`. Pass the root as an argument after the script and read it from `process.argv`: `require(require('path').join(process.argv[1], 'bin/lib/x.js'))`. A `node-eval-file.js` heredoc body reads it from its own argv. Paths stay native, and nothing respells the plugin root.
- Add a conformance suite that scans `plugin/skills/**/*.md` for `${CLAUDE_PLUGIN_ROOT}` inside a quoted JS literal, in a `node -e` body or a `NODE_EVAL_EOF` heredoc. Give it a go-red self-test.
- `tests/comment-trust-conformance.test.js` passes the root to each snippet as argv. Its `$ST_*` stand-ins use the form `formatPrintedPath` prints.
- Drop the forward-slash workarounds in the five suites that carry them, so they run with a native root.

## Release Note

Windows: skill steps that load plugin modules through `node -e` no longer fail with `Cannot find module` when the plugin is installed under a backslash path.

## Gotchas

- ASSUMPTION — verify at build: Claude Code on Windows exposes `${CLAUDE_PLUGIN_ROOT}` to a skill's Bash commands as a native backslash path. If it already uses forward slashes, the prose change is still correct but has no user-visible effect, and the test fixes are needed either way.
- `node-eval-file.js` (lines 23-28) forbids any `$` in a heredoc body other than `${CLAUDE_PLUGIN_ROOT}`. Once the root moves to argv, the delimiter can be quoted (`<<'NODE_EVAL_EOF'`). Check each body for other expansions before quoting it.
- Conformance suites extract these snippets by anchored fence text (`snippetBody` in `tests/comment-trust-conformance.test.js`, line 255). Run the full suite.
- 61 prose files make a large diff. Consider splitting it into sub-issues by skill directory, with the conformance suite landing last.
