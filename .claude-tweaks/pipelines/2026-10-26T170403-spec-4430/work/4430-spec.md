# 4430: Windows: residue pipeline-runs probe reports its subject with backslashes

Origin: SDD ruling ratified at Review Console — #4396 (run 2026-10-26T131247-spec-4290-4285-4396, PR #4427)

Defer-reason: pre-existing-outside-diff

## Current State

`plugin/bin/lib/residue/probes/pipeline-runs.js:135` builds a clean pipeline-run finding's `subject` with `path.relative(root, dir)`. On win32 that subject carries `\` separators (`.claude-tweaks\pipelines\{run-id}`), while every other residue display ID — the artifacts probe since #4396 — is `/`-joined on every OS.

It is the last residue probe whose `subject` is a native path: a grep of every probe's `subject:` shows branches, forge, suite and release use non-path strings, worktrees uses git's own path, and artifacts now uses `/` literals (#4396). #4396's final review found this site; it was left out of #4396 because the file was outside that build's diff.

Nothing persists or compares residue finding ids across runs (#4396's AC2.1 search: `finding.js:14` defines the fingerprint, `render.js:25` reads `dispositions[f.id]` per render, `residue.js:159` passes no dispositions), so changing the subject needs no migration.

## Deliverables

- `pipeline-runs.js` emits `subject` through `shared-primitives.js`'s `relativeDisplayId(root, dir)` (with a `{ pathImpl }` option feeding only that call, per the windows-checkout-test-parity skill), keeping its fs paths native.
- A test in `tests/bin-lib/residue/` pins the `/`-joined subject and proves the call site goes through `relativeDisplayId` (a counting `relative`, since plain `path.win32` injection does not discriminate on a POSIX host).

## Acceptance Criteria

- AC1.1: a clean run dir's finding has `subject` `.claude-tweaks/pipelines/{run-id}` with `/` separators; reverting the site to `path.relative` turns the new test red.
- AC1.2: the residue suites pass on ubuntu, and a `windows-regression.yml` run on the branch lists no `tests/bin-lib/residue/` file in `failingFiles`.

## Release Note

Fixed: on Windows, the residue sweep now reports a leftover pipeline run directory with `/` separators, like every other residue finding.
