# 5562: Delete each run's plan at wrap-up in this repository: set superpowers-plans-retention to prune-after-wrapup

Surface: infra
Risk-flags: none

**Related:** #3813, #5331, #4330, #5044, #4881, #5563

## Current State

Each build writes its execution plan to `docs/superpowers/plans/` and commits it. The plan is read during the build and at wrap-up; after the merge nothing reads it. This repository leaves the policy key `superpowers-plans-retention` at its default, `keep-forever`, so every plan reaches `main` and `/claude-tweaks:tidy` later removes plans in bulk.

Measured on `origin/main` on 2026-11-15 (re-derive before relying on a number):

- `docs/superpowers/plans/`: 699 files added and 641 deleted in the last 30 days, the deletions in 11 commits (56, 111, 122 and 156 files in single commits). 79 files, 2.8 MB, are tracked now.
- `docs/plans/` (run ledgers): 72 files added and 32 deleted in 30 days, in 13 commits. 44 files, 357 KB, are tracked now.

The mechanism to stop this exists. `superpowers-plans-retention: prune-after-wrapup` makes `/claude-tweaks:wrap-up`'s cleanup (item 1 in `plugin/skills/wrap-up/cleanup-procedures.md`) delete the run's own plan after a citation check, and makes `/claude-tweaks:tidy` delete leftover plans whose record is closed without staging a bulk prune. With squash merges, a plan deleted on the run's branch never reaches `main`.

`docs/donts.md` (the rule tagged `[IL-36]`, which covers design-mode builds that skip `/claude-tweaks:specify`) and `docs/decisions/0007-historical-design-doc-archive-is-periodically-pruned.md` describe the present practice: keep each plan at wrap-up, prune the archive in bulk now and then.

Design: `docs/superpowers/specs/2026-11-15-process-efficiency-design.md`, Phase 8, unit 8.1 (branch `worktree-design-process-efficiency`).

## Technical Approach

This is a setting, a rule change and a cleanup. No new code is expected for plans.

The wrap-up packet's plan snapshot (`plugin/skills/wrap-up/SKILL.md`, the step that runs `git diff --name-only --diff-filter=AM "origin/{integration-branch}...HEAD" -- docs/superpowers/plans/`) reads the plan from the branch. Confirm in the reader table that it runs before cleanup item 1.

Runs that close without a wrap-up never reach cleanup item 1. Under `prune-after-wrapup`, `/claude-tweaks:tidy` deletes their plans once the record is closed. The later measurement shows how many that is.
