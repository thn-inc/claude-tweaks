# 4015: worktree-always redirect scan misses a redirect glued to a word (echo foo>x)

Origin: ledger resolve gate (run 2026-10-24T061121-record-3989, refs #3989)

Defer-reason: genuinely-larger

## Current State

`plugin/bin/lib/hooks/git-command.js`'s `REDIRECT_OP_RE` (`/^\d*(>>|>\||>)(.*)$/`) is anchored at the start of a token, so a redirect glued to a preceding word (`echo foo>x`, `cmd arg>file`) resolves no write target: `redirectWriteTargets` sees the single token `foo>x`, whose first character is not `>`. The `worktree-always` gate therefore does not see a write to `x`. Pre-existing since #3080; found by the #3989 build and left unchanged there (ledger item 9).

`tokenize` strips quotes (`"a>b"` and `a>b` both become the token `a>b`) and records only a `singleQuoted` flag, so loosening the regex alone would read a quoted argument such as `node -e "x>y"` as a redirect, which is the false-positive class #3989 removes.

## Deliverables

- Make the redirect scan resolve a redirect glued to a preceding unquoted word (`echo foo>x`, `cat a.txt>b.txt`) as a write target.

- Keep quoted `>` text (`"a>b"`, `'a>b'`) and heredoc bodies from resolving a target. This needs `tokenize` to carry a double-quoted flag beside `singleQuoted`, and every parser that reads tokens to keep working.

- Mirror the change in `bash-prefilter.js`'s `hasFileRedirection`, which shares the parser.

## Acceptance Criteria

- `fileWriteTargets("echo foo>x", cwd)` resolves `x`; the same text inside quotes (`echo "foo>x"`, `echo 'foo>x'`) resolves no target.

- `tests/hooks-gate-coverage.test.js` pins both shapes and goes red when the change is reverted.

- `tests/hooks-bash-prefilter.test.js`'s differential corpus lists the glued shape, and `npm run test:perf` still passes.

## Release Note

The worktree-always gate now sees a redirect glued to a word (`echo foo>x`), which it previously let through.

## Technical Approach

### Key Files

- `plugin/bin/lib/hooks/git-command.js` — tokenize quote flag; redirect scan for glued targets
- `plugin/bin/lib/hooks/bash-prefilter.js` — keep hasFileRedirection in step
- `tests/hooks-gate-coverage.test.js` — pin glued and quoted shapes
