# 3339: tidy Step 7.5: skip the scratch worktree when every approved Step 7 action is a forge-API write

# Reflect — staged finding 1

**Category:** tangential

Origin: reflect hindsight from #2727

Defer-reason: tangential

## Current State

`/claude-tweaks:tidy`'s Step 7.5 (`plugin/skills/tidy/step-7-5-worktree-always.md`) provisions a scratch worktree whenever `worktree-always: true` resolves — before Step 7 runs, regardless of what the approved Step 7 set actually contains. Under `work-backend: github-issues` an approved set can be entirely forge-API writes (closing stale issues, label edits, a Release Note fill) with no record-file edit, no `docs/REGISTRY.md` Fix-now edit, and nothing to commit.

#2727 stated the forge-API-only carve-out canonically in `_shared/worktree-setup.md`'s Adopt-or-create ("Forge-API-only invocations need no worktree") and pointed `tidy/scan-execution.md`'s scan batch at it, but deliberately left Step 7.5 alone (the record named only tidy's scan lanes). The whole-branch review of #2727 listed this under "Declined to judge": an all-`gh` Step 7 still pays the create → catch-up merge → teardown cycle the carve-out exists to remove.

## Deliverables

- Gate Step 7.5's scratch-worktree provisioning on the approved Step 7 set containing at least one working-tree write (a record-file delete/edit, a `docs/REGISTRY.md` edit, or anything that needs the tidy-up commit) — an all-forge-API approved set runs Step 7 from the main checkout with no worktree, citing `_shared/worktree-setup.md`'s "Forge-API-only invocations need no worktree" rather than restating it.
- Keep the provisioning unchanged for any set with a local write, and for `local-files` (every Step 7 mutation there is a tracked-file edit).

## Acceptance Criteria

- A github-issues `/claude-tweaks:tidy` run under `worktree-always: true` whose approved actions are all `gh` writes creates no worktree and leaves `git worktree list` unchanged.
- A run whose approved set includes any record-file or `docs/REGISTRY.md` edit still provisions Step 7.5's scratch worktree exactly as today.
- A conformance test pins Step 7.5's new provisioning condition and its citation of the canonical carve-out.

## Release Note

Let /claude-tweaks:tidy skip its scratch worktree when every approved action is a GitHub write.
