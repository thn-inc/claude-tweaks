# 5544: Remove the unused wrappers and the merged classifier branch from archive-merged.js

Surface: infra
Risk-flags: none

## Overview

`plugin/bin/lib/reconcile/archive-merged.js` (2,820 lines) exports five thin wrappers that no production code calls. Each is a one-expression call into `classifyRunDir` or `ownEventRecency`, kept, by its own comment, "for its direct unit tests". The classifier also has a `merged` branch that only one of those wrappers and a few unit tests reach; its comment says the production merged path "does not route through here — it calls decideArchiveCore … directly".

This record removes the five wrappers and the `merged` branch and points their tests at the functions production calls, `classifyRunDir` and `decideArchiveCore`. It is part of unit 1.5 of the 2026-11-15 audit simplification design.

The design named "five wrappers with no production caller". There are six thin wrappers in the file; the sixth, `isStructurallyStuck`, has a production caller and stays.

## Technical Approach

Repoint, then delete. Repointing on the unmodified source proves the tests exercise the same behaviour through the surviving functions before anything is removed. `decideArchive(a, b)` returns `{ action: 'archive' }` or `{ action: 'skip', reason }` (`archive-merged.js:585-589`), taking `reason` from the classifier's `evidence.skipReason`. `decideArchiveCore` returns the same two actions, but a skip can also carry a `hint` (for example `unknown-host`, `:478-480`), and the wrapper reaches the core only through `classifyRunDir`'s `if (prState !== undefined)` guard (`:2019`). So most repointed assertions move one for one, and any that `deepEqual` a skip object or pass an undefined `prState` take the core's shape; the pull request names each such test. Confirm by running them, not by reading.

The `merged` branch goes with `decideArchive` because nothing else reaches it. `decideArchiveCore` keeps the merged decision and is what `archiveMergedRun` calls.
