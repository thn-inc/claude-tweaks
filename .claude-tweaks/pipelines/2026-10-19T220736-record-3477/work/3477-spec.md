# 3477: Wrap-up ceremony derivation treats shipped skill prose as docs-only

Origin: reflect light from #3005

Defer-reason: tangential

## Current State

- `plugin/bin/lib/dispatch/ceremony-derive.js` `isDocsPath` classifies every `*.md` path as docs, so `computeDiffFacts` reports `implFiles: 0` / `lowSurface: true` for a diff whose only production content is skill and agent prompt prose (`plugin/skills/**/*.md`, `plugin/agents/*.md`).
- In this repo those markdown files are the shipped product (CLAUDE.md Stack table: "Content | Markdown (SKILL.md files …)"). Run `2026-10-17T194130-record-3005` (#3005: four `plugin/` prose files plus one test) derived `fast-lane` for `/claude-tweaks:wrap-up`: light-mode reflect, Skills registry cap 2 instead of 5, Docs cap 1 instead of 3.
- `tests/bin-lib/dispatch/ceremony-derive.test.js` pins the docs-only and test-plus-docs cases but has no case for plugin prose; no doc records the behavior as intended.
