# 3386: Persist SDD's final whole-branch review findings, reviewed commit and fix range to the run directory

Surface: backend

## Overview

Part of the "Build dispatch cost shape" decomposition (parent #3374, origin #3229). The record that decides `/flow`'s double whole-branch review (#3381) must compare SDD's final whole-branch review against `/claude-tweaks:review` on the same branches. Today SDD's final-review output does not survive the build: the final reviewer's findings come back as a reply to SDD's controller, the fix wave and scoped re-review leave only commits, and SDD's Finish step deletes its gitignored workspace (`rm -rf <workspace>`). `/build` already closes the same seam for ledger residue (`plugin/skills/build/dispatch.md`'s "Carry forward surviving SDD ledger residue before Finish" instruction, #1135). This record extends that pattern to the final review, so #3381's measurement has durable inputs, including the commit the final reviewer saw (needed to run `/review`'s lenses against the pre-fix-wave state).

**Complexity:** Low
**Estimated tasks:** 2-3

## Non-Goals

- Changing SDD's final review, fix wave or re-review in any way — this only asks SDD to write down what already happened, before Finish.
- Deciding anything about the double review (that is #3381).
- Capturing per-task review output.

## Current State

- `plugin/skills/build/dispatch.md` forwards several instructions into the `/superpowers:subagent-driven-development` invocation, including "Carry forward surviving SDD ledger residue before Finish" (copies `progress.md` deferred-minor/parked lines into the run ledger before the workspace is deleted), pinned by `tests/build-sdd-ledger-residue-carryforward.test.js`.

- Nothing writes the final reviewer's findings, the commit it reviewed, the fix range, or the re-review verdicts anywhere durable.
