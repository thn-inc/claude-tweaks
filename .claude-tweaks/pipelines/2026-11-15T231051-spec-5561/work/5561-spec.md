# 5561: Delete the evals harness and its workflow

Surface: infra
Risk-flags: none

## Overview

`evals/` is a separate Node project (102 tracked files, its own `package.json`) for running skill scenarios against a live model. It has had no commit since 2026-08-30. Its last recorded result is dated 2026-08-09. The only run of `.github/workflows/eval-benchmark.yml` that GitHub shows (2026-10-09, manual dispatch) failed at its scenario step. Its 15 test files never ran in root CI.

The maintainer decided on 2026-11-15 to delete the directory and the workflow and to record the decision. This record does that, and repairs everything outside `evals/` that points into it: about 25 files, including one root test that would fail and seven shipped skill and code files that cite eval files as evidence.

It is unit 1.10 of the 2026-11-15 audit simplification design.

No test replaces the scenario-level check that a live model respects the boundary; the decision record says so plainly. The shipped skill text stops naming a file that does not ship and never ran in CI.

Citations of scenario files as incident evidence keep the evidence sentence. The path is dropped because the file is gone; the incident log remains the record of what happened.
