# 3876: Tell review lens agents to write scratch probes as one plain Bash call each

**Related:** #3737, #3822

Origin: reflect full from #3809

Defer-reason: tangential

## Current State

`plugin/skills/review/step3-lens-dispatch.md`'s Scratch path paragraph tells a dispatched lens agent, under `worktree-always`, to create and delete its probe files "via Bash (`mkdir -p` + a redirect/heredoc, then `rm`), never `Write`/`Edit`". It does not say each of those is its own plain Bash call.

In #3809's /review, three lens-agent probes were refused by the harness worktree-isolation guard (`wd-guard-refusal`, reason `harness-worktree-isolation`, 07:12:04-07:12:23Z) because the agents chained them as `S="…/agent-scratch/3a-a" && mkdir -p "$S" && cat > "$S/probe.js" <<'EOF' …` — each refusal cost the agent a retry.

## Deliverables

In `plugin/skills/review/step3-lens-dispatch.md`'s Scratch path paragraph, say the scratch create/delete runs as separate plain Bash calls — one command per call, no `&&`/`;` chaining and no shell variable carried between calls (absolute paths each time) — citing `_shared/scratch-worktree.md` §7 for the guard shape.

## Acceptance Criteria

- [ ] `plugin/skills/review/step3-lens-dispatch.md`'s Scratch path paragraph states that each scratch create/delete is its own plain Bash call with no chaining, and cites `_shared/scratch-worktree.md` §7.
