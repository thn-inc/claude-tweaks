# 5239: Probe Grep and Glob for the implementer worker where it has no shell

Origin: reflect full from #5217

Defer-reason: tangential

## Current State

`plugin/bin/lib/driver/roles.js` (the headless worker launcher, #5217, PR #5235) gives the implementer role Bash only on the platforms where the sandbox was probed (`SANDBOX_PROBED_PLATFORMS`, today `darwin`). Everywhere else `toolsFor` drops Bash and the worker launches with Read, Write and Edit only.

On those platforms the worker can neither list nor search files, so its prompt has to name every file it is to work on (stated in the `roles.js` header). The reviewer and explorer roles already launch with Grep and Glob.

Grep and Glob were not probed under the implementer's flags (`--restricted`, the generated `--settings` file with `defaultMode: dontAsk`), so it is not known whether they stay inside the working directory there.

## Deliverables

- [ ] Probe Grep and Glob through the module's own launcher, under the implementer's flags, with no sandbox block in the generated settings: a search and a listing inside the working directory, a path argument outside it, an absolute pattern, and a link that points out of it. Record what ran, what was denied and what each call could reach.

- [ ] Record the results in the `roles.js` header with the CLI version, the platform, the date, the login kind and whether a TTY was attached.

- [ ] If the probe shows both tools stay inside the working directory, or are denied outside it, add them to the implementer's tool list and allow list where Bash is absent. Otherwise leave the tool list as it is and state why in the header.

- [ ] Pin the resulting tool list per platform in `tests/bin-lib/driver/roles.test.js`.

## Acceptance Criteria

1. The `plugin/bin/lib/driver/roles.js` header states the probe result for Grep and for Glob under the implementer's flags, with CLI version, platform and date.

2. `toolsFor('implementer', platform)` for a platform outside `SANDBOX_PROBED_PLATFORMS` returns the list the probe supports, and a test in `tests/bin-lib/driver/roles.test.js` pins it.

3. No Bash tool and no Bash allow rule is added for a platform outside `SANDBOX_PROBED_PLATFORMS`.

## Release Note

Lets the driver's implementer worker list and search files in its working directory on platforms where it has no shell.

## Technical Approach

### Key Files

- `plugin/bin/lib/driver/roles.js` — record the probe; add Grep and Glob to the implementer where Bash is absent, if the probe supports it
- `tests/bin-lib/driver/roles.test.js` — pin the implementer's tool list per platform
