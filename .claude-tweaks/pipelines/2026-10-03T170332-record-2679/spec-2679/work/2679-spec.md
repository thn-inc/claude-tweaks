# 2679: Add a practice: re-audit verification prompts on Claude model bumps

Surface: infra

## Current State

claude-tweaks' skills and CLAUDE.md guidance encode verification/self-check instructions written for older Claude model defaults. Anthropic's own April 23, 2026 postmortem documents that reasoning-effort defaults, response-length system-prompt instructions, and idle-session context-clearing behavior all swing coding quality independent of model weights — and that its own upgrade guidance for newer, higher-effort models is to remove old verification instructions rather than add more, since new models can over-verify and burn extra turns when stale instructions remain. No current claude-tweaks process re-checks skill/CLAUDE.md verification instructions when the underlying Claude model version changes.

## Deliverables

- A checklist step that, on a tracked model version bump, reviews existing verification/self-check instructions in skills and CLAUDE.md for redundancy with the new model's own built-in verification behavior.
- A short reference doc summarizing the effort/verbosity levers (reasoning effort, response-length prompt instructions, idle-session context-clearing) known to swing coding quality independent of model weights.

## Acceptance Criteria

- Running the review after a tracked model bump produces a keep/trim decision for each verification instruction in a sampled skill.
- The reference doc is linked from wherever CLAUDE.md guidance is authored.

## Release Note

Added a checklist for re-auditing verification instructions after a Claude model upgrade.

## Technical Approach

Add the checklist as a new practice referenced from wherever this repo already tracks maintenance practices tied to external events (comparable in shape to a release checklist item, but triggered by a model version bump rather than a code release). The reference doc is a short, standalone `docs/` file summarizing the three named levers (reasoning-effort defaults, response-length instructions, idle-session context-clearing) and citing the Anthropic postmortem as its source; link it from CLAUDE.md's own guidance-authoring section so a future skill author encounters it before adding a new verification instruction.

### Key Files

- `docs/` — new reference doc summarizing the effort/verbosity levers
- `CLAUDE.md` — link to the new reference doc from the guidance-authoring section; add the checklist-step practice reference

## Gotchas

- This creates a recurring, human-triggered practice, not an automated check — a "tracked model version bump" has no mechanized detection point in this repo today, so the checklist step needs a clear trigger (e.g. "run this the next time you update the model reference in CLAUDE.md's Environment section") rather than assuming automation will invoke it.
- Verify the cited Anthropic postmortem's actual content directly (not just via the secondary Medium-article citation) before writing the reference doc, since the reference doc will be treated as authoritative guidance for future skill authors.
