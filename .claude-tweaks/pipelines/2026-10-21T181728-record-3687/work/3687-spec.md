## Build alignment notes (Common Step 4.5, Beneficial deviations)

1. `wrap-up/auto-merge-short-circuit.md`'s ledger deletion does not read the probe's `value.files` itself; it runs `hooks.js delete-ledger --run "$RUN_DIR"` (the resolution rule's writer branch — `resolveLedgerPath`, ownership-aware and fail-closed) with `cleanup-procedures.md` Item 2's report handling. This gives one deletion mechanism across wrap-up, and it replaces the old `ls-files "docs/plans/*-record-{n}-ledger.md"` locate step, which never matched a topic-slug ledger at all.
2. `_shared/ledger-format.md`'s rule adds a writer clause beyond Deliverable 1: when a run dir resolves, a caller that flips or deletes ledger rows never takes the glob fallback on a probe failure (it fails closed); appends and no-run-dir callers take the fallback as written.
3. `/claude-tweaks:ledger resolve` honors an explicit `{feature-name}` first; with a run dir it uses this run's ledger, reports `No ledger found for this run` when there is none, and stops on a probe failure, never defaulting to another run's ledger.
