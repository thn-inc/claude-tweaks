# 4117: Inline component skills that end on an "Output ONLY these lines" render stall the calling pipeline: no return-to-caller instruction

**Related:** #3160, #4118

Origin: /claude-tweaks:flow #3898,#4012,#4041 Manifesto stall (run 2026-10-24T103516-spec-3898-4012-4041)

Defer-reason: tangential

## Current State

`/claude-tweaks:assess-agent-autonomy` is always invoked inline through the Skill tool from inside another skill's numbered procedure: `/flow`'s Manifesto ceremony-check fallback, `/specify` Step 3, `/backlog refine`, and `/dispatch`. Its mode files end on a bare render instruction. `ceremony-check.md` Step 3 and `grant-check.md` both say "Output ONLY these lines, no preamble", and `challenge/SKILL.md` uses the same phrasing. Nothing after that render tells the model the output is consumed by the caller and that the caller's procedure continues in the same turn.

Observed 2026-10-24 in `/claude-tweaks:flow #3898,#4012,#4041` (run 2026-10-24T103516-spec-3898-4012-4041). The Manifesto ran `ceremony-check #4041`, the model rendered the `CEREMONY:`/`RATIONALE:` block as its entire reply, and the turn ended mid-Manifesto, before `config.yml` was written. The maintainer reports that `/flow` "sometimes stops here". The preceding `ceremony-check #4012` call did not stall only because the model had already queued the next tool call in the same message.

`docs/skill-authoring.md`'s Component-skill contract rule (line ~113) covers suppressing `## Next Actions` when a parent invokes a skill, but says nothing about handing control back after the component's final output.

## Deliverables

1. Every inline-invoked component mode that ends on an output-only render (`assess-agent-autonomy`'s four mode files, `challenge/SKILL.md`'s framing-check mode, and any other the sweep finds) carries an explicit return-to-caller line right after the render template. The line says the output is consumed by the calling skill, and the caller's next step runs in the same turn, never as a turn end.
2. `docs/skill-authoring.md`'s Component-skill contract rule gains the matching convention: a component skill whose last step is a bare render must state that control returns to the caller.

## Acceptance Criteria

- A conformance test asserts every `plugin/skills/**/*.md` file containing "Output ONLY" also contains the return-to-caller line, and goes red when the line is removed from any one of them.
- `docs/skill-authoring.md` states the convention, pinned by the same or a sibling test.
- `npm test` passes.

## Release Note

`/claude-tweaks:flow` and other pipelines no longer stall after an inline ceremony, grant or framing check prints its verdict.

## Technical Approach

### Key Files

- `plugin/skills/assess-agent-autonomy/ceremony-check.md` — return-to-caller line after Render
- `plugin/skills/assess-agent-autonomy/grant-check.md` — return-to-caller line after Render
- `plugin/skills/challenge/SKILL.md` — return-to-caller line after the framing-check render
- `docs/skill-authoring.md` — Component-skill contract: return-to-caller convention
