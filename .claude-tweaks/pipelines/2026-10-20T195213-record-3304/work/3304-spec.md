Origin: ledger resolve gate

Defer-reason: genuinely-larger

## Current State

#2783 added `plugin/bin/lib/hooks/post-tool-use-failure.js`. It recognizes the harness's worktree-isolation refusal by Claude Code's own message text: `HARNESS_ISOLATION_REFUSAL_RE = /This session is isolated in the worktree [\s\S]*?Refusing to run it/`, plus `bash-prefilter.js`'s `REFUSAL_SIGNATURE = 'Refusing to run it'`. Both were measured against Claude Code's behavior on 2026-10-16.

If Claude Code rewords that refusal, the hook stops logging refusals and nothing signals it: friction-events.js just returns fewer events. Claude Code is not an upstream in `tools/upstream-drift/manifest.yml` today, so no drift check covers this dependency.

- `npm test` passes.
