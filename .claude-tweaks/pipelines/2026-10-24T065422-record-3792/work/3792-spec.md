# 3792: Migrate the remaining git-text log-decision.js --text call sites to --text-file

Origin: ledger resolve gate (final whole-branch review of #3671, ledger item 1)

Defer-reason: genuinely-larger

## Current State

#3671 added `--text-file <path>` to `bin/log-decision.js` and `_shared/auto-decision-log.md`'s "Text from git or a user" rule: entry text that interpolates anything git or a user supplied (a file name, an error message) goes in a one-line file passed by `--text-file`, never in a double-quoted `--text`, because the shell expands `$(...)`, backticks and `$VAR` inside it. #3671 migrated only the two call sites that already carried escape prose. The final whole-branch review of #3671 found the other `log-decision.js --text "..."` call sites interpolate the same kind of text with no escaping at all, so they now contradict the rule: `flow/multispec-parallel-waves.md` (~line 36 `{stderr reason}`, ~58 `{reason}`, ~62 `{paths}`, ~141 `{reason}`), `tidy/release-note-repair.md` (~86 `{stderr reason}`), `dispatch/two-call-gate.md` (~9 `{message}`), `_shared/pr-check-gate.md` (~76 `{: reason}`), `_shared/git-discipline.md` (~162 `{integration-branch}`), and `flow/steps-and-gates.md`'s first #3014 log call (~62, the note carrying `pr.value.conflictNote`, which names the integration branch). Line numbers are approximate; grep for `log-decision.js` in each file.
