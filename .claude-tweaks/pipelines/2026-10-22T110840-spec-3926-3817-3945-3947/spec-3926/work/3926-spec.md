# 3926: Review Console SECTION_MAP has no prefix for staged/wrap-up-reflect-insights.md, so every wrap-up leaves it unresolved

Origin: wrap-up leftover routing from #3679 (run 2026-10-21T225455-record-3679)

Defer-reason: pre-existing-outside-diff

## Current State

`reflect/full-mode.md` (Step 3, `--source wrap-up`) stages the insight table as `{run-dir}/staged/wrap-up-reflect-insights.md`, and `wrap-up/review-console.md` "On approval" step 10 names that file as the terminal decision that applies its rows. `SECTION_MAP` in `bin/lib/console/resolve.js` has no prefix that matches `wrap-up-reflect-insights` (`wrap-up-skill`, `wrap-up-doc`, `wrap-up-claude-md`, `wrap-up-adr`, `wrap-up-journey`, `wrap-up-memory`, `wrap-up-upstream`, and `reflect-` all miss it), so `classifyStagedItem` returns Pending review with reason `unmapped-prefix`.

Observed on run `2026-10-21T225455-record-3679` (PR #3918): `console-resolve.js --policy console-auto` resolved the file to `pending (unmapped-prefix)` and listed it under "Needs a human", although every row of its table was a "Don't capture". `stage-item.js` printed the same warning when the file was staged. An unattended run therefore always ends with one item no human has reviewed.

## Deliverables

- [ ] Pin the mapping in `tests/bin-lib/console/resolve.test.js`, which already checks `CANONICAL_PREFIXES` against `SECTION_MAP`
