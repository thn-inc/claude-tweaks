# 3817: Review lens dispatch has no documented path for a Task-subagent reviewer at medium effort and above

Origin: reflect full from #3665

Defer-reason: tangential

## Current State

`plugin/skills/review/step3-lens-dispatch.md` exempts a reviewing Task-tool subagent from lens dispatch at the `low` tier only (the "Low-tier single-read dispatch" paragraph: skip the Task-tool dispatch and apply the Direct-verification override). The `medium` and above path ("Parallel execution (conditional)" and "Reproduction dispatch") prescribes reproduction-pair Task dispatch with no counterpart, while `dispatch/task-prompt.md`'s Async-wait discipline tells a dispatched reviewer never to end its turn waiting on a nested dispatch.

A dispatched `/review` at `medium`+ therefore has no documented path: it either dispatches pairs and risks the stall the task prompt forbids, or degrades ad hoc. #3665's dispatched review (effort `medium`) judged lenses 3a/3b/3c/3f directly from the raw diff and logged its own `SKIP` line. No finding could reach `confirmed` through pair agreement, and the only coverage caveat was the one that run wrote by hand.

## Deliverables

- [ ] State the subagent-reviewer degrade for every tier in `step3-lens-dispatch.md`: when the reviewer is itself a Task-tool subagent, lenses in scope are judged directly (Direct-verification), findings enter `confirmed` only through that independent source read, and the run logs a `SKIP` degrade-trace line with a fixed shape.
- [ ] Carry a one-line coverage caveat into the review summary and the PR verdict comment whenever the degrade ran, mirroring the existing partner-death caveat.
- [ ] Pin the paragraph with a conformance test beside the neighbouring `step3-lens-dispatch.md` pins.

## Acceptance Criteria

- [ ] `step3-lens-dispatch.md` names the degrade for `medium`, `high`, `xhigh` and `max`, not only `low`.
- [ ] The degrade's `decisions.md` line shape and the summary caveat are stated once and pinned by a test that fails when the paragraph is removed.
- [ ] `npm test` passes.

## Release Note

A review run by a dispatched agent at medium effort or above now has a documented no-wait path and a visible coverage caveat.

### Key Files

- `plugin/skills/review/step3-lens-dispatch.md` — state the subagent-reviewer degrade for every tier
- `plugin/skills/dispatch/task-prompt.md` — cross-reference the degrade from the Async-wait discipline item
