# 4369: Make the merge gate and near-duplicate Current State reader skip fenced headings

**Related:** #4169, #4350, #4351

## Current State

Two more record-body readers scan `## ` / `#` heading lines without skipping fenced blocks — the defect class #4169 fixed in `extractSection` and `sectionText`, left out of its plan's consumer enumeration (which searched for those two function names only).

`mergeStateDemands` (`plugin/bin/lib/preflight-records/merge-gate.js`, ~line 37) toggles its in-section state on every `## ` line. A fenced `## …` line inside Deliverables ends the section, so a later "actually merged #N" demand is missed and the record is not deferred; a fenced `## Prerequisites` opens a section that is not the record's own. Probe at v6.155.1 and pre-#4169: a demand after a fenced `## not heading` line returns `[]`.

`extractCurrentStateAnchors` (`plugin/bin/lib/issues/near-duplicate.js`, ~lines 119-133) stops at the first heading line with no fence skip, so a fenced shell `# comment` inside Current State drops every later anchor and near-duplicate detection misses duplicates. Its suite has no fence fixture. Found by the post-release review of #4169 (review-87, review-88).

## Deliverables

- [ ] `mergeStateDemands` ignores heading lines inside fenced blocks (shared `fencedLineRanges`)

- [ ] `extractCurrentStateAnchors` ignores heading lines inside fenced blocks

- [ ] tests in each module's suite with a fenced heading inside the section under scan

## Acceptance Criteria

1. `mergeStateDemands` finds an "actually merged #N" demand that follows a fenced `## …` line inside Deliverables.

2. A fenced `## Prerequisites` heading does not open a Prerequisites section for `mergeStateDemands`.

3. `extractCurrentStateAnchors` keeps anchors that follow a fenced `# comment` line inside Current State.

4. `npm test` passes.

## Release Note

Records that quote code or markdown in their Deliverables or Current State no longer confuse merge-order checks or duplicate detection.

## Technical Approach

### Key Files

- `plugin/bin/lib/preflight-records/merge-gate.js` — section toggle skips fenced lines
- `plugin/bin/lib/issues/near-duplicate.js` — Current State scan skips fenced lines
