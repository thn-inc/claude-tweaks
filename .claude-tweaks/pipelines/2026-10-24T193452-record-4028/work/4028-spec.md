# 4028: Stop worktree-isolation refusals: emit only guard-accepted command forms (~5k refused calls in 14 days)

Evidence: 14-day transcript analysis of this repo (176 main sessions, 5,599 subagent transcripts, 132 archived timing.json files, ~286k tool calls), 2026-10-24.

## Current State

In 14 days, 4,990 Bash and 94 Write tool calls (~34 per pipeline) were refused by Claude Code's worktree-isolation guard: "this command is too complex to verify that it stays inside the worktree" and "this command names git in a form too complex to verify". Each refusal wastes a model turn at p50 276k context, plus a retry turn.

Observed shapes include compound `cd … &&`, `eval "$(…)"` (#3190), heredoc input to `node-eval-file.js` (seen in #3968's build), and `P=…; node $P/...` prefixes. Related: #3822, #3819, #3190.

## Deliverables

1. A `tools/` script that classifies refusals from transcripts by command shape and, where traceable, by the skill fence the command came from.
2. Rewrite each refusing fenced snippet under `plugin/skills/**` into a guard-accepted form (single plain command, absolute paths, scratchpad node script for multi-step work), per `_shared/scratch-worktree.md`.
3. A conformance scan over fenced bash blocks in `plugin/skills/**` that rejects the known-refused shapes. *(As built: four more refused shapes were live-verified during the build and gained `_shared/scratch-worktree.md` §7 rows and detectors: gh with a runtime-computed input, a "git" substring plus a redirect to a variable path, `git -C "$VAR"`/`$(…)`, and node script text naming git. Their ~70 existing fences sit in the scan's stale-checked ratchet allowlist pending #4217.)*
4. A recorded premise probe: does a plugin PreToolUse `updatedInput` rewrite run before the harness isolation check? If yes, add rewrites for the residual model-composed shapes; if no, record the observed behavior.

## Acceptance Criteria

- [ ] Guard refusals per pipeline fall by at least 90% from the ~34 baseline over 10 runs.
- [ ] The conformance scan fails on a fixture containing each banned shape and passes on the migrated corpus.
- [ ] The probe outcome is written to `docs/` with the observed behavior.
