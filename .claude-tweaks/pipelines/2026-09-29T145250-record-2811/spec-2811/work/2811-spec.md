# 2811: Doc staleness: plugin-structure — Commands

**Doc:** plugin-structure | **Section:** Commands | **Category:** staleness | **Misleads:** human engineer + coding agent | **Classification:** additive | **Confidence:** high

Verified-as-of: 9fd5ddd62cd64e1b1b498b04141075997556983e

## Current State

Running `node plugin/bin/verify.js` with no arguments prints the CLI's live usage line, which includes `[--cwd <dir>]`. `plugin/bin/lib/verify/args.js` confirms this is a real, implemented flag (`VALUE_FLAGS` includes `--cwd`; a dedicated `UsageError` fires when `--cwd` is combined with `--stamp-status`/`--changed-files`). The doc's verify.js line in `## Commands` otherwise enumerates every flag exhaustively (`--cmd`, `--json`, `--log-dir`, `--count-stamp`, `--no-stamp`, `--git-dir`, `--run`, `--scope`, `--base`, `--integration-branch`, `--stamp-status`, `--changed-files`) but never mentions `--cwd`, so a reader or agent treating this dense Reference-genre line as the CLI's exhaustive signature would not discover the flag exists.

## Deliverables

**Current:**
```
[--no-stamp] [--git-dir <dir>] [--run <dir>] [--scope <path> [--base <ref>] [--integration-branch <name>]] | --stamp-status [--git-dir <dir>] | --changed-files [--base <ref>] [--integration-branch <name>]
```

**Proposed:**
```
[--no-stamp] [--git-dir <dir>] [--run <dir>] [--cwd <dir>] [--scope <path> [--base <ref>] [--integration-branch <name>]] | --stamp-status [--git-dir <dir>] | --changed-files [--base <ref>] [--integration-branch <name>]
```

## Acceptance Criteria

The `verify.js` command-reference line in `## Commands` must list the `--cwd <dir>` flag in its bracketed flag signature: `plugin/bin/lib/verify/args.js` implements it (it is in `VALUE_FLAGS`, and is refused when combined with `--stamp-status`/`--changed-files`), and running `node plugin/bin/verify.js` (no args) prints the live usage string with `[--cwd <dir>]` present, but the doc's exhaustive flag list omits it entirely.
