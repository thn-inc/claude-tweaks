# 3366: near-duplicate finder: generic skill-name anchors (/flow, /claude-tweaks:dispatch) trigger the specify absorb refusal on unrelated records

**Related:** #3335 #1944

Origin: /claude-tweaks:specify shaping of #3335

Defer-reason: tangential

## Current State

`plugin/bin/lib/issues/near-duplicate.js`'s body-anchor signal (`extractCurrentStateAnchors`) collects every backtick span in `## Current State` except those `isGenericAnchor` rejects. Skill-name spans such as `/flow` and `/claude-tweaks:dispatch` pass that filter, so any two records that mention the same skill score a `body-anchor-overlap` hit. `plugin/skills/specify/shaping-mode.md`'s Near-duplicate candidate check then refuses to shape a record when any candidate, even a score-1 match on this signal alone, is `ready` with an open linked PR or `bot:in-progress`.

Observed shaping #3335 (2026-10-17): 29 candidates out of 151 open records, 27 of them score-1 `body-anchor-overlap` only. #3002 (`verify.js` stamp chunking) and #3048 (QA story selection) matched only on `/flow` and `/claude-tweaks:dispatch`. Both are `ready` with open PR #3332, so the procedure would have refused #3335 and posted an "Absorb into #3002" decision. The refusal was overridden by hand. The procedure also contradicts itself: "the finder never blocks shaping on its own signal alone" versus "the one automatic refusal the finder's signal authorizes on its own".

## Deliverables

1. `isGenericAnchor` rejects skill-name anchors: a span matching `^/[a-z0-9:-]+$` (a slash command such as `/flow` or `/claude-tweaks:dispatch`).
2. `shaping-mode.md`'s automatic absorb refusal requires a candidate scoring at least 2 signals; a score-1 candidate is surfaced in the table and the `**Related:**` line only. The "never blocks shaping on its own signal alone" sentence is reconciled with the refusal rule.
3. Regression tests in the near-duplicate suite: two records sharing only `/flow` and `/claude-tweaks:dispatch` anchors produce no `body-anchor-overlap` signal, and a real file-path anchor still does.

## Acceptance Criteria

1. `findNearDuplicates` returns no `body-anchor-overlap` signal for a pair whose only shared Current State anchors are slash-command names.
2. A pair sharing a repo file-path anchor (for example `plugin/skills/dispatch/task-prompt.md`) still yields `body-anchor-overlap`.
3. `shaping-mode.md`'s refusal paragraph names the minimum score of 2, and a prose-conformance assertion pins it.
4. `npm test` passes.

## Release Note

Shaping a record no longer proposes absorbing it into an unrelated record that merely mentions the same skill.
