# 3167: verify --baseline misclassifies base failures as attributable on macOS: base worktree path is not realpath-resolved

**Related:** #3155, #3153, #3156, #3130

Verified-as-of: 0af440d7642a1ba30c9c0af43c24560b90d03b04

## Current State

`plugin/bin/lib/verify/baseline.js:59` creates the `--baseline` scratch worktree with `fs.mkdtempSync(path.join(os.tmpdir(), 'ct-verify-base-'))`. On macOS `os.tmpdir()` returns `/var/folders/...`, a symlink to `/private/var/folders/...`. node `--test` reports every TAP `location:` and stack frame under the real path `/private/var/folders/...`.

`extract.js`'s `relativize(file, cwd)` strips the cwd prefix by plain string compare. Called with `cwd: baseDir` (`baseline.js:283-288`), the `/var/...` prefix never matches the `/private/var/...` path, so the base run's failing file is never recognized as the same file. Every file that also fails at the base commit is classified `attributable`, and `--baseline` exits 1.

Reproduced 2026-10-15 from a detached `origin/main` checkout at a path with no space: `node --test tests/bin-lib/verify/cli.test.js` fails 4 of 86 — `#3043 AC1`, `#3043 I3`, the baseline-in-isolation CAVEAT case, and the verify-event case. A hand-built fixture shows the base log's `location:` line under `/private/var/folders/.../ct-verify-base-*/wt/` while the adjudicator reports `0 also fail at base ... 1 attributable`. Linux CI is green because Linux `/tmp` is not a symlink.

Consequence: on macOS, local `npm test` is red for everyone, and every dispatched build's test gate fails on these tests regardless of its own diff (#3130 failed this way on 2026-10-15).

## Deliverables

- Resolve the base worktree directory to its real path (`fs.realpathSync`) at creation in `plugin/bin/lib/verify/baseline.js`, so every later `cwd: baseDir` compare uses the same form node prints. Check `headDir` the same way, since it is also fed to `relativize`.

- Add a regression test to `tests/bin-lib/verify/baseline.test.js` that pins the realpath behavior without depending on the host OS. For example, create the base dir through a symlinked parent and assert a base-failing file is classified `baseline`.

### Key Files

- `plugin/bin/lib/verify/baseline.js` — realpath the base (and head) dir before relativizing
- `tests/bin-lib/verify/baseline.test.js` — symlinked-tmpdir regression case
