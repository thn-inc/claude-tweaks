# 4069: reflect's integration-branch probe reads a failed fetch or git grep error as "content absent"

Origin: /claude-tweaks:release v6.152.0 release-gate review (staged/review-17.md, run 2026-10-21T194624-release-standalone)

Defer-reason: tangential

## Current State

`plugin/skills/reflect/SKILL.md:185`'s probe runs `git fetch origin {integration-branch}`, then `git grep`/`git log -S` against `origin/{integration-branch}`. The only "probe could not run" cases it names are no origin and a file outside the repo. A failed fetch leaves a stale ref, and a no-match against it reads as "absent", which is the #3817 failure the probe exists to prevent. `git grep` exit 1 (no match) and 128 (error) are not separated.

The same line splices `{phrase}` into single quotes without escaping or `-e`, and leaves the branch unquoted (3b-A, medium). Found by the v6.152.0 release-gate review (3c reproduction pair, both agents) at 9d8132196.

## Deliverables

1. A failed fetch, or `git grep`/`git log` exiting other than 0/1, is reported as "probe could not run", never as "absent".
2. `{phrase}` is passed with `-e` and safe quoting; the branch is quoted.
