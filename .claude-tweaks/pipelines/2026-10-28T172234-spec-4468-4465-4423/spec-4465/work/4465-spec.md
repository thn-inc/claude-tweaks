# 4465: tidy: Step 4 auto-deletes plans of closed records, contradicting superpowers-plans-retention (keep-forever default) and ADR-0007's recent-work cutoff

**Related:** #3109

Origin: /claude-tweaks:tidy close-out 2026-10-27 (run 2026-10-27T055458-tidy-standalone)

Defer-reason: tangential

## Current State

`/claude-tweaks:tidy` Step 4 (`scan-procedures.md`) classifies a plan whose related record is closed as Delete, and `step-6-auto.md` auto-applies that at the default `moderate` tier. `/claude-tweaks:wrap-up` reads `superpowers-plans-retention`, whose default is `keep-forever` (`_shared/policy-schema.md`), and this repo's policy.yml does not set it. ADR-0007 allows pruning the plan archive only as a deliberate maintenance action with explicit direction and a cutoff that keeps recent work (about a week).

## Deliverables

Approach: Make tidy's plan rule read `superpowers-plans-retention` the same way wrap-up's cleanup item 1 does: `keep-forever` (the default) means a closed record's plan is Keep (or, past an age cutoff, a Stage-tier bulk-prune proposal per ADR-0007); `prune-after-wrapup` keeps today's auto-delete; `ask` stages it.

1. Tidy Step 4 resolves `superpowers-plans-retention` and routes plan findings by it.

## Acceptance Criteria

- With `superpowers-plans-retention` unset, a tidy run at `moderate` deletes no plan created within the cutoff.
