# 3461: Share the transcript and plugin-root reader helpers duplicated across the skill-audit CLIs

Origin: #3309 SDD Task 1 ruling (ledger row 38); second deliverable folded in from #3309's review hindsight (reflect-3309-1)

Defer-reason: out-of-scope

## Current State

`plugin/bin/lib/skill-audit/transcript-load.js` (#3309) carries copies of two pieces of `plugin/bin/lib/timing/transcript.js`'s unexported internals:
- `resultBytes(content)`: the tool_result byte rule.
- The stat-then-reject block in `readUsage`, with the same `transcript not readable ({code}): {path}` and `(EISDIR)` error strings.

#3309's spec listed `timing/transcript.js` as "not modified", so the copies stayed, with a comment naming their source. If either file changes its byte rule or error format, the two can drift.

`plugin/bin/skill-load-report.js`'s `closureIndex` likewise carries a near-verbatim copy of `plugin/bin/load-delta.js`'s `headSide` plugin-root reader (the realpath-contained `readFile` plus the `listSkillMds` walk feeding `entryPointLoads`). That copy has already drifted: it lacks `headSide`'s ENOENT/ENOTDIR catch on `listSkillMds`.

## Deliverables

- Export `resultBytes` and a `statTranscriptOrThrow(fsImpl, path)` helper from `timing/transcript.js`, or move both into a small shared module, and have both readers import them.
- Leave `readUsage`'s exported contract and behavior unchanged.
- Extract a `pluginRootReader(rootAbs)` helper returning `{ readFile, listSkillMds }` with `headSide`'s exact semantics (ENOENT/ENOTDIR catch included) into `plugin/bin/lib/skill-audit/`, and have both `load-delta.js` and `skill-load-report.js` import it.

## Acceptance Criteria

1. `transcript-load.js` contains no copy of `resultBytes` or the stat-error strings; `git grep -n "transcript not readable" -- plugin/bin` lists one definition site.
2. `tests/bin-lib/timing/transcript.test.js` and `tests/bin-lib/skill-audit/transcript-load.test.js` pass unchanged.
3. `skill-load-report.js` holds no copy of the plugin-root reader; a plugin root deleted between the `skills/` check and the index build degrades the way `load-delta.js` does instead of throwing.

## Release Note

No user-visible change; internal cleanup of transcript readers.
