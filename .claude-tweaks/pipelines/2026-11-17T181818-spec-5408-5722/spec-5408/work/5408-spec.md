# 5408: Fail closed when the MCP verified-open-deps file omits an unresolved dependency in dispatch's queue pull

Origin: spec #5230 review (3e)

Defer-reason: needs-human-decision

**Related:** #5311

## Current State

refs #5230. Since #5230, `plugin/skills/dispatch/mcp-transport.md` Step 2 (around line 83) has the agent work out which dependency numbers to verify open and write them to the `--verified-open-deps` file, where the retained script printed the list from Node. `plugin/bin/lib/dispatch/queue-pull.js` computes the unresolved-dependency set on the files transport too but never checks the agent-written file against it: a number the agent leaves out reads as closed, so the record it blocks stays eligible and can be dispatched while its blocker is open. The #5230 review tiebreak confirmed this at medium. Two fixes are possible and they differ in behavior: fail closed (treat an unresolved number missing from the file as open, with one Warning line), or take open state from the `--dep-freshness` entries the agent already writes. Which one is a design call, and either changes MCP-path behavior the retained `queue-pull-script.md` parity oracle does not have.

Related: #5311 covers the neighbouring case — a missing or malformed verified-open-deps file (and a failed per-dependency view on gh). This record covers a well-formed file that leaves a number out. Both touch the same pass in `queue-pull.js`, so build them together or one after the other.

## Deliverables

- Choose fail-closed or dep-freshness-derived open state for an unresolved dependency the verified-open file omits.
- Implement it in `plugin/bin/lib/dispatch/queue-pull.js`, mirror it into the retained `queue-pull-script.md` while it still exists, and state the rule in `mcp-transport.md` Step 2.
- Add a files-transport fixture whose verified-open file omits an open blocker.

## Acceptance Criteria

1. On `--transport files`, a record whose unresolved `Blocked by #N` dependency is missing from the `--verified-open-deps` file is not in `dispatch-groups.json`, and stderr carries one line naming #N.
2. The new fixture in `tests/bin-lib/dispatch/queue-pull.test.js` fails with the check removed.
3. `npm test` passes.

## Release Note

Dispatch no longer treats a dependency as closed on a gh-absent firing just because the agent left it out of the verified-open list.
