# 4135: Pin that the committed verify-scope.json stays readable by the previous release's declaration reader

# Reflect — staged finding 2

**Category:** tangential

Origin: reflect full from #4024
Defer-reason: tangential

## Current State

#4024 added the `impact` rule kind to `.claude-tweaks/verify-scope.json`. The full suite passed with a committed declaration that the previous release's `plugin/bin/lib/verify/declaration.js` rejects outright (a rule without `suites`), which makes `verify.js --scope` exit 2 for every run of the installed build until a release ships. Nothing in the suite ran the previous reader over the committed file; review caught it by reading the diff and confirmed it by running the base reader by hand. CLAUDE.md requires committed-config contract changes to stay readable by the installed build, but no test enforces it.

## Deliverables

- A conformance test that loads `declaration.js` as of the latest release tag (`git show v{latest}:plugin/bin/lib/verify/declaration.js`, with its `../issues/blast-radius` dependency) and asserts it parses this repo's committed `.claude-tweaks/verify-scope.json` with `ok: true`.
- The test skips with a stated reason when no release tag is reachable (a shallow clone) and never reads the network.

## Acceptance Criteria

- [ ] Committing a rule shape the previous release's reader rejects (for example an `impact: true` rule with no `suites`) makes the test fail, naming the reader's own error text.
- [ ] A declaration the previous reader accepts passes it.
- [ ] A shallow clone with no release tag skips the test with its reason rather than failing.

## Release Note

Changes to the committed verify-scope declaration are now checked against the previous release's reader, so a new rule shape cannot break verification for installed builds.

## Technical Approach

### Key Files

- `tests/verify-scope-declaration.test.js` — where this repo's declaration is already pinned
- `plugin/bin/lib/verify/declaration.js` — the reader whose previous release is loaded
- `.claude-tweaks/verify-scope.json` — the committed file under test
