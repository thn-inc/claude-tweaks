# 4289: Windows: tests expect native paths where git prints forward-slash paths (#3064 calibration class)

## Current State

Git for Windows prints paths with forward slashes. `rev-parse --show-toplevel` and `worktree list --porcelain` print `D:/a/_temp/…`, and `ls-files` and `status` print repo-relative `a/b/c`. These tests build their expected value with the native `path.join`, which gives `D:\a\_temp\…` and `a\b\c`, so the comparison fails on win32 only. Under the #3064 calibration, git's own spelling is the correct value and the test is what needs fixing.

- `tests/bin-lib/verify/baseline.test.js:913`: `realGit.listWorktrees` output does not `includes(normalWt)`, a native path.
- `tests/hooks-git-exec.test.js:13`, `:114`, `:264`: `runGit`/`runGitAsync` return `D:/a/_temp/ct-wtd-…`, and the test expects the native temp dir.
- `tests/run-integrity.test.js:176`: `worktreePathForBranch` returns the porcelain path `D:/…/.claude/worktrees/feat`.
- `tests/teardown-gate.test.js:550`: the `wd-foreign-teardown` event's `path` carries `D:/…/wt`.
- `tests/tidy-residue-markers.test.js:305`, `:344`: git-listed `.claude-tweaks/pipelines/…/decisions.md` against a `path.join` expectation.

Excluded on purpose: `tests/bin-lib/verify/cli.test.js:3425` (#4222) and `tests/reconcile.test.js:488` (#3982).

8 tests in 5 files fail on Windows (line numbers as of 988cc584d).
