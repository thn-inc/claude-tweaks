# 3846: Decide and move the routine templates off the claude-sonnet-5 model pin

**Related:** #3056 (the /prompt-audit run that surfaced this)

Origin: #3056 /prompt-audit comparison (run 2026-10-21T001740-record-3056)

Defer-reason: tangential

## Current State

Every shipped routine template pins `model: claude-sonnet-5` — the previous Sonnet generation (Sonnet 5.5 has shipped; `docs/skill-authoring.md`'s Model-version prompting notes already cover its migration guide). Re-verified at `origin/main` 36fff7a2f: `plugin/skills/{harness-health,specify,release,backlog,journey-health,docs-health,tidy}/routine-template.yml:7`, `plugin/skills/dispatch/routine-template.yml:12`, `plugin/skills/code-health/routine-template.yml:14`, plus the examples in `plugin/skills/_shared/routine-template-schema.md:20` and `plugin/skills/_shared/routine-diagnostic-probe.md:39`.

`model` is a significant field for `skills/routine/record-freshness.md`'s comparison (`routine-template-schema.md`'s record table), and that schema's Anti-Patterns require a `template_version` bump on any template field change. Moving the pin therefore makes every already-instantiated routine report Drifted until its owner runs `/claude-tweaks:routine update` — a contract change under CLAUDE.md's expand-contract rule. `tests/routine-template-parser.test.js` and `tests/routine-record-freshness.test.js` pin their own fixture strings, not the shipped YAML.

## Deliverables

1. Decide the target: `claude-sonnet-5-5`, or a family alias if the routine API accepts one (which would stop this recurring at every release). Record the decision in the PR description.
2. Update every shipped template's `model:` and bump each template's `template_version`.
3. Update the two `_shared` examples to the chosen value.
4. State in the release note that existing routines report Drifted until `/claude-tweaks:routine update` is run.

## Acceptance Criteria

- `grep -rnE '^model: "?claude-sonnet-5"?$' plugin/skills --include=*.yml` returns no hit (or only the deliberately chosen value, if the decision is to keep it, with the reason recorded).
- Every changed template's `template_version` is incremented.
- `npm test` passes, including the routine template and record-freshness suites.

## Release Note

Scheduled routines now default to the current Sonnet model; run /claude-tweaks:routine update on existing routines to pick it up.
