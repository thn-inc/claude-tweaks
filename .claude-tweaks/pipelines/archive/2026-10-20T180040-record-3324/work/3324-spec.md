# 3324: Extend #2719's concurrent-grant-divergence logging to flag-back rows

Origin: ledger resolve gate
Defer-reason: genuinely-larger

## Current State

#2719 (refine-mode.md Step 5 / refine-closing-summary.md) made a grant row's pre-write reverify
log *why* it was skipped when a concurrent write already granted the record differently — naming
both this run's discarded `RECOMMEND_MERGE` verdict and the live grant that won the race, instead
of the generic `AUTO … skipped … (what changed)` line.

The same race exists on flag-back rows: when this run's grant-check computed `RECOMMEND_BUILD:
false` (or downgraded the row), and a concurrent actor granted the record anyway, the pre-write
reverify currently drops the flag-back write with the same generic skip line — it does not
distinguish "a concurrent actor disagreed with this run's own recommendation" from any other
reason a flag-back row might be dropped. This was flagged during #2719's own whole-branch review
as a related but larger class of disagreement than that record's grant-row-only Technical
Approach covered.

## Deliverables

- Extend `refine-mode.md` Step 5's flag-back reverify branch to compare the flag-back row's own
  `RECOMMEND_BUILD` verdict (and rationale) against the live grant state, the same way the grant
  row's comparison (#2719) already does for `RECOMMEND_MERGE`.
- Add the distinguishable skip-line template(s) to `refine-closing-summary.md`'s template list,
  mirroring the grant-row "agreed"/"DIVERGED" shape.

## Acceptance Criteria

- A flag-back row dropped by the pre-write reverify because a concurrent write granted the
  record logs whether that concurrent grant agreed with or diverged from this run's own
  `RECOMMEND_BUILD` verdict, distinguishably from the existing generic skip line.
- `decisions.md` lets a human find every such flag-back divergence from one sweep, the same way
  `refine-closing-summary.md`'s Concurrent-grant comparison section already does for grant rows.

## Release Note

Flag-back rows now log the same concurrent-grant-divergence detail grant rows do when a concurrent actor's decision disagrees with this run's own recommendation.
