# 3592: Add an empty-value probe check to plan authoring — run every substituted command once with its resolver's empty value

Origin: reflect light from #3572

Defer-reason: tangential

## Current State

`plugin/skills/build/plan-authoring-checks.md`'s **Derived-value probe check** has an author run a pinned command with the value the code's resolver actually returns on this machine. Nothing asks for a probe with that resolver's degenerate output: an empty string, a missing value, a detached-HEAD branch name.

#3572's plan probed `gh pr list --head {current-branch} --state merged` on three real branches (a squash-merged one returned 1, open ones 0) and its git check on five refs. None of them was empty. On a detached HEAD `{current-branch}` is empty, and `gh pr list --head "" --state merged --json number --jq length` prints `30` with exit 0: an empty `--head` drops the filter, so a clean detached worktree read as merged. The SDD task review missed it too. Only review lens 3c caught it, and it was fixed in a review round (373ae7a00).

## Deliverables

- Add an "Empty-value probe check (extends the Derived-value probe check)" paragraph to `plugin/skills/build/plan-authoring-checks.md`: one bold lead, the rule, one clause of why, and #3572 as the incident. When a plan has an agent substitute a runtime-resolved value into a command (a branch name, a ref, a path, an id), run that command once with the value the resolver returns in its degenerate case — empty or unset — and record what it does; a filter that silently drops on an empty value widens the query instead of failing.

- Pin the paragraph with a small prose test that follows `tests/absence-grep-control-check-prose.test.js`, read through `readText`.

## Acceptance Criteria

- `grep -nF "Empty-value probe check" plugin/skills/build/plan-authoring-checks.md` prints exactly one line, and that paragraph names #3572.

- The new pin fails against the pre-change file and passes after.

- `npm test` passes in full.

## Release Note

Plan authoring now asks for one probe of each substituted command with an empty value, so a filter that drops on an empty input is caught before build.
