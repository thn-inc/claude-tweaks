# 4169: Skip fenced code blocks when the shared section parsers look for record headings

Origin: build final whole-branch review of #3946 (Task 4 review finding)

Defer-reason: tangential

## Current State

The shared section parsers `extractSection` (`plugin/bin/lib/issues/record.js`) and `sectionText` (`plugin/bin/lib/issues/materialize-format.js`) find `## Heading` lines without skipping fenced code blocks. A record body that quotes markdown inside a fence therefore has its quoted headings read as the record's own sections.

#3946 made this reachable routinely: `plugin/bin/shadow-dup-proposal.js` files a divergent or collision `.shadow-dup` staged copy as a `needs:definition` record whose `## Current State` quotes the copy verbatim in a fence, and staged `leftover-*.md` copies are themselves spec-shaped. A review probe of a leftover-shaped copy found `extractSection(body, 'Deliverables')` returning the copy's deliverable, `extractSection(body, 'Acceptance Criteria')` returning the copy's AC (a heading the record does not have), `Current State` cut off at the copy's first heading, and `shapeGate(body)` returning `{"ok":true}` — the shape gate passing an Open-Question record on the copy's Acceptance Criteria. No consumer parses such a record before `/claude-tweaks:specify` rewrites it today, so nothing misfires yet.

## Deliverables

- [ ] `extractSection` and `sectionText` skip headings inside fenced code blocks (backtick and tilde fences of any length, matching the fence-length rule `fenceFor` writes), reusing the fence detection `stripCodeSpans` already has where it fits.
- [ ] Tests with a body that quotes a spec-shaped markdown document inside a fence: the record's own sections are extracted, the quoted ones are not, and `shapeGate` judges the record's own shape.

## Acceptance Criteria

1. For a body whose `## Current State` contains a fenced block holding `## Deliverables` and `## Acceptance Criteria` headings, `extractSection(body, 'Acceptance Criteria')` returns null/empty when the record itself has no such section, and `extractSection(body, 'Current State')` returns the whole section including the fenced block.
2. `shapeGate` on a `shadow-dup-proposal.js` proposal for a spec-shaped copy reports the record's own shape (Open Question, not Acceptance Criteria).
3. Every existing caller's tests still pass (`npm test`).

## Release Note

Records that quote a markdown document no longer have the quoted headings mistaken for their own sections.

## Technical Approach

### Key Files

- `plugin/bin/lib/issues/record.js` — extractSection skips fenced regions
- `plugin/bin/lib/issues/materialize-format.js` — sectionText skips fenced regions
