# 2796: Evaluate the Mods catalog (aitmpl.com) for claude-tweaks distribution

Surface: infra

## Current State

claude-tweaks currently distributes via its own marketplace (`README.md`: `/plugin marketplace add thn-inc/claude-tweaks-marketplace` then `/plugin install claude-tweaks@claude-tweaks-marketplace`). Claude Code Templates (the Mods catalog at aitmpl.com) now installs function-hook plugins with one command from a live catalog — a different distribution surface this project doesn't currently participate in.

## Deliverables

Investigate the Mods catalog's listing mechanism and decide one of two outcomes:
1. List claude-tweaks in the Mods catalog alongside its existing marketplace distribution (a lighter-weight addition — participate in an existing catalog rather than building new infrastructure), or
2. Determine that participation isn't worthwhile (licensing terms, catalog scope mismatch, maintenance burden) and document why, so the question doesn't get silently re-raised later without the answer already on record.

## Acceptance Criteria

- The Mods catalog's actual listing requirements (submission process, format, any terms) are investigated and stated, not assumed.
- A decision is made and recorded: either claude-tweaks is listed in the catalog (with the listing itself as evidence), or a documented reason states why not — in `README.md` or a relevant docs file.
- If listed, installing claude-tweaks via the catalog's one-command flow is verified to actually work end-to-end, not just submitted and assumed functional.

## Release Note

No user-visible change: evaluated listing claude-tweaks in the Mods catalog alongside its own marketplace.

## Technical Approach

Research the Mods catalog (aitmpl.com) directly — its submission mechanism, what metadata it requires from a plugin, and whether it wraps the existing marketplace install path or requires a separate distribution format. This is investigation-first: the record intentionally doesn't presuppose which of the two Deliverable outcomes is correct.

### Key Files

- `README.md` — where the distribution instructions live today, and where a catalog listing (or the documented decision not to pursue one) would be noted
- `plugin/.claude-plugin/plugin.json` — the plugin manifest a catalog listing would likely reference

## Gotchas

- Don't assume the catalog requires new distribution infrastructure — it may simply wrap the existing `/plugin marketplace add` + `/plugin install` flow with a friendlier one-command UX, in which case listing might be nearly free. Investigate before assuming either direction is more work.
- If listing requires ongoing maintenance (keeping catalog metadata in sync with plugin.json/version bumps), factor that recurring cost into the decision, not just the one-time listing effort.
