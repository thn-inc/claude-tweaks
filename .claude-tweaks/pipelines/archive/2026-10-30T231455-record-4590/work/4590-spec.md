# 4590: Treat a renumbered journey step and an extended Origin line as extensions in the artifact-overwrite check

# Reflect — staged finding 1

**Category:** tangential

Origin: reflect full from #4484 (batch-scope pass, flow run 2026-10-28T172259-spec-4488-4484)

Defer-reason: tangential

## Current State

`plugin/bin/lib/flow/artifact-overwrite-check.js` lets a later spec's edit to an earlier spec's journey pass only through three extension tests: same-spec self-edit (blame `refs #N` match), list reflow (`- ` entries, count not shrinking), and step-markup reformat (`normalizeStepMarkup` equality per hunk). A hunk that fails all three trips the multi-spec artifact-overwrite HARD-GATE.

In flow run `2026-10-28T172259-spec-4488-4484`, #4484's commit 4706f21db inserted a new step 3 into #4488's `docs/journeys/route-a-review-finding-the-release-gate-can-see-4488.md` (24 insertions, 3 deletions). The two later step headings were renumbered with their text unchanged, and the `Origin:` bookkeeping line was rewritten to name both specs. A renumbered heading is not a list entry, and a step-markup reformat compares a deleted heading with its matching added heading, number included. The `Origin:` line is plain text, not a `- ` bullet. So no test matched: the check exited 1, the run stopped at the HARD-GATE, and the user ruled it an extension. No #4488 content was lost.

Integration-branch probe: `git grep -n -i -e 'renumber' origin/main -- plugin/bin/lib/flow/artifact-overwrite-check.js` exited 1 (no match) after `git fetch origin main`.

## Deliverables

- A fourth extension test, step renumber: a hunk whose deleted lines are numbered step headings, each reappearing among the hunk's added lines with identical normalized text under a different number, is an extension.

- A fifth extension test, reference-preserving bookkeeping line: a deleted `Origin:` line whose every `#N` reference is still present in its replacement line is an extension. A replacement that drops a reference stays an overwrite.

- The header comment's test list, and `plugin/skills/flow/multispec-artifact-namespacing.md` where it names the extension tests, updated to five.

## Acceptance Criteria

- [ ] A fixture where a later spec inserts a step ahead of two existing `### N.` steps (headings renumbered, text unchanged) reports `clean: true`.

- [ ] A fixture where a renumbered heading's text also changes still reports an overwrite.

- [ ] A fixture where the `Origin:` line gains a `#N` reference and keeps the existing one reports `clean: true`; a fixture that drops the existing reference reports an overwrite.

- [ ] Each new test goes red with its extension test removed.

## Release Note

A multi-spec `/claude-tweaks:flow` run no longer stops at the artifact-overwrite gate when a later spec inserts a journey step that renumbers an earlier spec's steps, or adds itself to a journey's Origin line.

## Technical Approach

### Key Files

- `plugin/bin/lib/flow/artifact-overwrite-check.js` — add the step-renumber and reference-preserving-line extension tests
- `tests/bin-lib/flow/artifact-overwrite-check.test.js` — fixtures and go-red tests for both
- `plugin/skills/flow/multispec-artifact-namespacing.md` — name the two new extension tests
