# 2981: Run design-wrapper doctor mode and /tidy Step 4.9 through the Impeccable engine

Surface: infra

## Overview

Run `design-wrapper`'s `doctor` mode through the engine's `doctor --json` verb, via `impeccable-engine.js run doctor`, instead of the retired `doctor.mjs`. Today `doctor` skips as unavailable for every user on Impeccable 4.2.2 or later, because its exact-pin resolver finds no `doctor.mjs`; `/tidy` Step 4.9's design-record scan, which calls `doctor`, therefore surfaces nothing on those installs.

The read-only guarantee is unchanged and now enforced in code: the engine module rejects `--fix`, so the mode can never edit `PRODUCT.md`. Before changing either consumer, this sub-issue captures one real `doctor --json` output and compares it field by field with what `doctor.md` and `/tidy` read today, because that comparison has not been made.

**Complexity:** Low
**Estimated tasks:** 4

## Non-Goals

- Layer 0, `explore`, the direction contract and the finish-reviewer dispatch (sibling sub-issues).

- Recording the shared contract fixtures under `tests/fixtures/impeccable-plugin/` (the closing sub-issue); this sub-issue keeps its one capture as evidence in the PR description and, if a test needs it, as a module-local fixture.
