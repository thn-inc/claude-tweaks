## Current State

Two of the three records in flow run spec-4468-4465-4423 shipped a shell-injection surface in skill prose, each caught only by `/claude-tweaks:review` lens 3b after the SDD whole-branch review had passed: #4465's tidy `record-decline` interpolated a human free-text `{why}` into a single-quoted `printf` (fixed in 5a3494874 — the payload is now a `Write`-produced file fed on stdin), and #4423's tidy Step 4.7 rendered an open PR's untrusted `### Resume` line as a paste command with an unconstrained tail (fixed in 48d8c550e — held to `pr-body.js`'s `composeResumeLine` shape with no shell metacharacters). refs #4465, refs #4423

`docs/skill-authoring.md` covers untrusted content in two other places only: "Passing untrusted content into an inline skill invocation" (fetched text steering an LLM turn) and the trusted-author rule for marker comments. Its shell-fence rules (quoting temp paths, guard-accepted shapes, `process.argv` over interpolation in `docs/donts.md`) are about correctness, not trust. Probes on origin/main (729a5ae5e..f0b6f24cb fetched): `git grep -n -i -F -e 'shell' origin/main -- docs/skill-authoring.md` matches only those correctness rules; `git grep -n -i -e 'interpolat' origin/main -- docs/skill-authoring.md docs/donts.md` matches only the `node -e` path rule.

## Deliverables

- A `docs/skill-authoring.md` section stating the rule: text the plugin did not write (a human's free-text answer, a PR/issue body or comment, a record field, a branch name) never reaches a shell command line or a rendered paste command by interpolation — pass it as a file (`Write`, then stdin or a path argument) or through `process.argv`, and render a command built from untrusted parts only when every part matches the composer's exact grammar, else a non-command fallback. Cite the two worked fixes above.
- A review lens 3b calibration line (`_shared/criteria-review-quality.md` or the lens's own row) naming "untrusted text interpolated into a shell or paste command" as a security finding to look for in skill prose.

## Acceptance Criteria

- Lens 3b's calibration names the untrusted-text-into-command class.
