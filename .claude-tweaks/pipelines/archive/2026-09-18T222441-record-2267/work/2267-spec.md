## Overview

Part of the 5-unit status-line migration decomposition (parent #2264, keystone #2265). This unit
covers the review skill family's 4 files, including `step3-lens-dispatch.md` — the file the
design doc names explicitly as carrying "the fullest `WRONG:`-example shape" (two examples plus a

swap.

**Complexity:** Medium

## Non-Goals

  #2265, which this unit is `Blocked by`.

  same decomposition.
- Editing `plugin/skills/review/step3-debate-and-refutation.md` line ~134 — that line is a
  consumer read of the status word (reading a prior agent's already-emitted status), not a
  producer instruction telling an agent where to put one, and is out of this migration's scope by
  the design doc's own line-item note.
- Changing the four status words themselves or the Template A/B/C content that follows the status
  line.
