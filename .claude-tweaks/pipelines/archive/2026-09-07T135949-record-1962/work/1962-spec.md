# 1962: dispatch Step 4 mint adopts a stale, non-archived run dir instead of minting fresh

Defer-reason: tangential

Origin: /claude-tweaks:dispatch --budget all drain, run 2026-09-05T090744-dispatch-standalone (14 groups attempted)

## Current State

`resolve-run-dir --spec-slug record-{n} --create` (bin/lib/hooks/run-dir-resolve.js, step 2 newestMatch) returns the newest existing directory matching the slug whenever one exists and is not archived, before the mkdir-only mint branch runs. dispatch/SKILL.md Step 4 calls exactly that shape and documents it as "mkdir only". Observed 3 times in one firing (records 1302, 733, 1442): each had a leftover run dir from a 2026-08-26/29 session whose PR had been closed unmerged on 2026-09-04 to re-dispatch, with status active/interrupted and a run-state.json pr object pointing at the closed PR. The reconciler's archive sweep skipped all three (reason no-branch), so they were never archived. Reused as-is, the new run would have inherited the closed PR number, an old config.yml, stale staged/ items and a foreign claim runId. Workaround used: close-run then archive-run on the stale dir, then re-mint.

## Deliverables

- [ ] Make Step 4's mint refuse to adopt a matching run dir whose run-state.json status is non-terminal-but-dead (interrupted, or active with no live worktree) or whose recorded PR is closed/merged: either a new `--fresh` flag on resolve-run-dir that skips step 2, or an archive-then-mint path in dispatch/SKILL.md Step 4 citing close-run and archive-run.
- [ ] Let the reconciler's archive sweep (bin/lib/reconcile/archive-merged.js decideArchive) archive a run whose PR is closed-unmerged and whose stamped worktree no longer exists, instead of skipping with no-branch forever.
- [ ] Test: a fixture with an existing `{ts}-record-1302` dir (status interrupted, pr closed) plus `--spec-slug record-1302 --create` yields a new directory, not the old one.

## Acceptance Criteria

1. Running dispatch Step 4 against a record with a stale non-archived run dir mints a fresh directory; the old one is archived or left untouched, never adopted.
2. The reconciler archives a closed-unmerged-PR run whose worktree is gone within one sweep.
3. `npm test` passes with the new fixture.
