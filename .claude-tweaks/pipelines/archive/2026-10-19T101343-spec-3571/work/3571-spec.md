# 3571: Add an absence-grep control check to plan authoring — run every "returns nothing" grep against the pre-change file first

Origin: reflect light from #3536

Defer-reason: tangential

## Current State

#3536's AC1.1 was `grep -rn "replace(/\\/\\*\[\\s\\S\]\*?\\*\\//g, '')" tests/` returns nothing. It was composed in #3464's reflect as an escaped JS string and never run. Under grep's BRE, `\[\s\S\]` is a literal `[`, a whitespace class, a non-whitespace class and a literal `]`, so it can never match the literal `[\s\S]` it targets. Run against the pre-change `tests/bin-lib/exit-code-conformance.test.js` it exits 1, exactly like the fixed tree. The criterion could never fail.

#3536's plan copied the grep verbatim into its Global Constraints and Task 2. Neither plan audit nor `build/plan-authoring-checks.md` caught it, because no check asks for a negative control on an absence assertion. The Task 2 implementer caught it at dispatch time, and the controller re-verified it with `grep -rnF`: a match at line 56 on the old file, none at HEAD.

## Deliverables

- Add an **Absence-grep control check** paragraph to `plugin/skills/build/plan-authoring-checks.md`, in the house shape: one bold lead, the rule, one clause of why, and #3536 as the incident. When a plan step or a pinned AC asserts that a grep (or any search) "returns nothing", run it once against a file or commit that still contains the target and confirm it matches. Prefer `grep -F` for literal code text.

- Add the same rule to the AC-composition guidance that `/claude-tweaks:specify` and reflect's `specShapedBody` callers follow, wherever that guidance tells an author to write a grep-shaped criterion.

## Acceptance Criteria

- `grep -nF "Absence-grep control check" plugin/skills/build/plan-authoring-checks.md` prints one line.

- The new paragraph names #3536 and the `grep -F` remedy.

- `npm test` passes, including any byte-pin or composed-ceiling test that covers `plan-authoring-checks.md`.

## Release Note

Plans now check that an "expect no matches" grep can actually match before relying on it.
