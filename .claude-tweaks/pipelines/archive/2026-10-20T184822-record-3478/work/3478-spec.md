# 3478: candidates-dead-code.js loads with circular-dependency warnings when required directly (hub cycle with focus-generators)

Origin: ledger resolve gate (spec-2977-3330 item #5, follow-up to #3330)

Defer-reason: genuinely-larger

## Current State

Requiring `plugin/bin/lib/code-health/candidates-dead-code.js` directly in a fresh process (`node -e "require('./plugin/bin/lib/code-health/candidates-dead-code')"`) prints 12 `Accessing non-existent property ... inside circular dependency` warnings (`listTrackedSourceFiles`, `isGlobDiscoveredTestFile`, `extractModuleExports`, `escapeRegExp`, repeated across the sibling verticals), verified at 5bff50b17. The cause is the hub shape: `candidates-dead-code.js` requires `./focus-generators` (line 110), whose tail (lines 44-51) requires all eight `candidates-*.js` verticals, each of which destructures helpers from `./candidates-dead-code` before that module's `module.exports` is populated. `.claude/skills/code-health-focus-vertical/SKILL.md` pitfall 1 prescribes a require order for the verticals, and dead-code is the module they import from, so the fix needs a design choice about where the shared helpers live. #2908 (security-hardening) and #3330 (experiment-cleanup) fixed the two verticals whose own order was reversed; the dead-code entry point itself was out of scope for both and is untouched.

## Deliverables

- [ ] Break the `candidates-dead-code` <-> `focus-generators` cycle at the source (for example, extract the helpers the verticals import from `candidates-dead-code` into a leaf module that has no `focus-generators` dependency, and repoint the verticals), rather than reordering requires again.

- [ ] Add a regression test that loads `candidates-dead-code.js` in a fresh child process and asserts stderr carries no `circular dependency` warning, proven red against the current tree.

## Acceptance Criteria

- `node -e "require('./plugin/bin/lib/code-health/candidates-dead-code')"` prints no circular-dependency warning.

- The new fresh-process test fails before the fix and passes after it.

- `node --test "tests/bin-lib/code-health/*.test.js"` passes.
