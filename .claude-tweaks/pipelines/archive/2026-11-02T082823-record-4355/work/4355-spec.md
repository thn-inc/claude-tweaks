# 4355: Windows: shadow-dup-proposal reads a staged symlink through to its target

Origin: ledger resolve gate (#4282 ledger row 6, final whole-branch review)

Defer-reason: pre-existing-outside-diff

## Current State

`plugin/bin/shadow-dup-proposal.js` `readNoFollow` (line 54) opens a staged copy and its anchor with `fs.constants.O_RDONLY | (fs.constants.O_NOFOLLOW || 0)`. The comment above it says a leaf symlink in `staged/` must never pull an outside file into a filed record. On Windows `fs.constants.O_NOFOLLOW` is undefined, so the flag falls back to `0`, the open follows the link, and the outside file's bytes are quoted verbatim into the record the console files.

This is the read-side twin of the write-side degrade #4282 fixed in `plugin/bin/release-local.js` `writeInsideRoot`. The #4282 final whole-branch review found it; it sat outside that build's diff, so it was left alone. No open issue covers it.

## Deliverables

- `readNoFollow` refuses a symlinked leaf on a platform without `O_NOFOLLOW`. It checks with `path-guard`'s `lstatType`, opens the file, then compares the `fstat` and `lstat` dev/ino of the opened fd (bigint), the same way `writeInsideRoot`'s fallback does. An unreadable leaf fails closed.

- The platform constants are injectable (`{ constants = fs.constants }`), so a Linux-runnable test can pin the fallback branch.

## Acceptance Criteria

- [ ] AC1: with injected constants lacking `O_NOFOLLOW`, `readNoFollow` on a symlinked leaf throws, and the caller reads that as an unreadable copy or a missing anchor, never as the target's bytes. The test fails when the fallback check is removed (mutation go-red).

- [ ] AC2: with injected constants lacking `O_NOFOLLOW`, a leaf swapped for a symlink between the lstat and the open is refused through the identity check (one-shot `fs.openSync` patch, as in `tests/bin-lib/release-local/cli.test.js`'s swap-race test).

- [ ] AC3: behavior on platforms that define `O_NOFOLLOW` is unchanged. The existing shadow-dup-proposal tests stay green and `npm test` passes.

## Release Note

On Windows, the Review Console no longer quotes a file from outside the repository into a filed record when a staged copy is a symlink.

## Technical Approach

### Key Files

- `plugin/bin/shadow-dup-proposal.js` — readNoFollow fallback for platforms without O_NOFOLLOW
- `plugin/bin/lib/path-guard/index.js` — reuse lstatType (no change expected)
