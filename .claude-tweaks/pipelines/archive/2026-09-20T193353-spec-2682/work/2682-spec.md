Surface: infra

## Overview

Once the pre-existing `#2670` (press) and `#2681` (auth) both ship, nothing in the plugin calls `agent-browser` anymore. This unit deletes `plugin/skills/browse/agent-browser-reference.md`, removes `agent-browser` from the cloud Setup script generator and from `CLAUDE.md`, and sweeps the repo for any remaining live-invocation mentions. `#2537` and `#1768` — both of which asked to fix defects inside the vendored `agent-browser` CLI that no code path here exercises anymore post-migration — were already closed as moot during this decomposition's own specify closeout, ahead of this record's build.

**Complexity:** Low
**Estimated tasks:** 5 (plus one already-satisfied historical bullet — see Deliverables)

## Non-Goals

- Fixing the `agent-browser` defects `#2537`/`#1768` originally asked for (synthetic-locator-click dispatch bug, screenshot `os error 35` self-heal gap) — investigation found neither is reachable from any code path this repo still calls, so the resolution is removing the dependency, not patching the vendored CLI.
- Editing comparison/historical prose that merely mentions `agent-browser` by name without invoking it (e.g. "unlike agent-browser, which..." in `browse/SKILL.md` or `_shared/browser-detection.md`) — that prose stays as historical context; only a live-invocation mention is in scope. A **live invocation** is any occurrence inside an executable code fence (a shell command, a documented CLI example meant to be run as-is) or an actual install/call site (`npm install -g agent-browser`, a script that shells out to it); a commented-out line, a conditionally-unreachable branch, or prose describing what the tool used to do is historical, not live.
- Migrating the `press` story action — already covered end-to-end by the pre-existing `#2670`.
