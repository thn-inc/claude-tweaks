# 6101: Map or document the gh-absent issue-comment edit in the GitHub write transport

Origin: ledger resolve gate

Defer-reason: needs-verification

## Current State

`plugin/skills/_shared/github-write-transport.md` maps each `gh` issue write to a GitHub MCP call for a `gh`-absent session (a cloud Routine sandbox), but it has no row for editing an existing issue comment.

Two flows edit a comment: `plugin/skills/specify/planning-answer.md`'s Write step (c) prepends `**Resolved:**` to the planning-hold comment, and `plugin/skills/specify/shaping-mode-stamping.md` resolves a live `needs:decision` comment the same way. With `gh` absent, both stop at that edit. #6059's review fix d0c05f836 made the planning answer path refuse before its first write when `gh` is absent rather than writing part-way.

Whether the GitHub MCP server exposes an issue-comment update tool was not probed: the #6059 session had no GitHub MCP server loaded (ledger row 12 of docs/plans/2026-11-22-specify-planning-answer-ledger.md, Defer-reason needs-verification).

## Deliverables

Probe the GitHub MCP server (the one claude.ai/code cloud sessions and Routines load) for a tool that updates an existing issue comment, and record the probe command and its output.

If one exists: add its row to `_shared/github-write-transport.md`'s mapping, and drop planning-answer.md's gh-absent refusal so both comment-editing flows run with `gh` absent.

If none exists: state the no-MCP stop beside the mapping's other no-equivalent notes, naming both flows, so the refusal is a documented degrade and not an unexplained gap.

## Acceptance Criteria

`_shared/github-write-transport.md` either has an issue-comment edit row naming the MCP tool, or a paragraph stating there is none and naming `specify/planning-answer.md` and `specify/shaping-mode-stamping.md` as the flows that stop.

The record's PR quotes the probe's command and output.

## Release Note

Cloud sessions without the gh CLI know whether they can resolve a decision comment, instead of stopping at an undocumented gap.

## Technical Approach

### Key Files

- `plugin/skills/_shared/github-write-transport.md` — add the issue-comment edit row, or the documented no-MCP stop
- `plugin/skills/specify/planning-answer.md` — drop the gh-absent refusal if an MCP edit exists
- `plugin/skills/specify/shaping-mode-stamping.md` — name the MCP edit, or the documented stop
