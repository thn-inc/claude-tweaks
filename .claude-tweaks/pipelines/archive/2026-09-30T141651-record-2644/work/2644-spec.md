# 2644: Audit skill-authoring guidance for Claude Fable 5.1 prompting deltas

Surface: infra

## Current State
claude-tweaks skills are themselves prompts for Claude models, but Anthropic's own official documentation lists behavioral differences for Claude Fable 5.1 vs. 5 (effort-level selection, needing explicit asks for user-facing progress updates, batching independent tool calls, formatting, safeguard false positives, subagent and vision handling) that can silently change how existing skills behave. No skill or CLAUDE.md guidance currently references model-version-specific prompting quirks; skills are written once and assumed stable across model upgrades. Several of the documented deltas (progress-update prompts, tool-call batching) already show up piecemeal in some skill bodies but aren't tracked as a reusable checklist.

## Deliverables
1. Add a short "model-version prompting notes" section or policy row to claude-tweaks' skill-authoring guidance (`docs/skill-authoring.md`, or a cross-reference in `superpowers:writing-skills` if that's where the canonical authoring checklist lives) summarizing the Fable 5.1 deltas that matter for skill instructions: tool-call batching, progress-update prompts, effort-level selection, formatting, safeguard false positives, and subagent/vision handling.
2. Cross-check a sample of existing skills against the documented differences and flag any relying on now-changed default behavior (or confirm none are affected).
3. Link the source doc (Anthropic's Fable 5.1 prompting guide) from the new guidance section so future model version bumps get the same treatment.

## Acceptance Criteria
1. The skill-authoring guidance names at least the tool-call-batching, progress-update, and effort-level differences, each with a one-line note on what changed and what a skill author should check for.
2. At least one example skill from the sample cross-check is shown updated against the checklist, or explicitly confirmed unaffected with the reasoning stated.
3. The guidance states this checklist applies whenever a new Claude model version ships, not only for Fable 5.1 — i.e., it's framed as a durable process addition, not a one-off note tied to a single model version.
4. The source doc (https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5-1) is linked from the new guidance.

## Release Note

Updated internal skill-authoring guidance with Claude Fable 5.1 prompting notes (no user-visible change).
