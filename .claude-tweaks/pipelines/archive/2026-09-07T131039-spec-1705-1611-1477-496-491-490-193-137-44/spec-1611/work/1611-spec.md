## Acceptance Criteria

1. Each of the 6 listed files' own summary/report format states the routing count and this run's digest comment URL (or that `specs/digest.md` was appended, under `work-backend: local-files`) when it routed at least one below-floor finding to the shared digest this run, per `materiality-floor.md`'s Summary surfacing section.
2. A zero-routing run states the count as `0` rather than omitting the line.
3. A test pins each of the 6 files' citation.
4. `npm test` passes.

## Technical Approach

Mirror the pattern already shipped in review/step3-routing.md (the first of the 6 adopters, wired in the 2026-09-04 release, commit 4a5622d04) into the remaining 5 listed files: wrap-up/residue-sweep.md, wrap-up/leftover-routing.md, reflect/full-mode.md, reflect/hindsight-mode.md, and visual-review/browser-review.md. Each file's own summary/report step reads the digest routing outcome it already computes for materiality-floor.md's throttle line and additionally states the routing count and this run's digest comment URL (or, under work-backend: local-files, that specs/digest.md was appended) whenever at least one finding routed below floor this run; a zero-routing run states the count as 0 rather than omitting the line, matching materiality-floor.md's Summary surfacing section. Extend tests/materiality-floor-conformance.test.js (or add a sibling suite) to pin each of the 6 files' citation of the Summary surfacing section, the same way the suite already pins the four health sweeps.

### Key Files

- plugin/skills/wrap-up/residue-sweep.md - add Summary surfacing to its own report
- plugin/skills/wrap-up/leftover-routing.md - add Summary surfacing when a leftover section routes below floor
- plugin/skills/reflect/full-mode.md - add Summary surfacing to its insight-routing summary

- plugin/skills/visual-review/browser-review.md - add Summary surfacing to its own summary

- tests/materiality-floor-conformance.test.js - extend to pin all 6 files' citation

## Gotchas

- review/step3-routing.md may already satisfy its own Deliverables bullet (commit 4a5622d04 landed 2026-09-04, after this record was parked) - re-verify live at build time rather than assuming the checklist is still fully open; if already done, mark that bullet complete and scope the build to the remaining 5.
- The zero-routing case (state the count as 0) is easy to skip by accident since it means adding a line to the common "nothing to report" path in each file, not just the routing branch - the existing four-health-sweep implementations are the reference for how that line reads on a clean run.
