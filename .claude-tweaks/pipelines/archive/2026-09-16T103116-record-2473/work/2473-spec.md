# 2473: console-resolve.js's SECTION_MAP classifies every reflect-*.md as a Queue write regardless of Category

Surface: infra

## Current State

`reflect/SKILL.md`'s Auto mode routing table sends a reflect finding to one of four destinations
by category (Safety regression / Convention drift / Tangential idea / Pattern observation), and
the file is explicit that only `Category: tangential` becomes a Queue-writes record proposal —
"omitted for `convention`/`observation` findings (those are never Queue writes)." But
`bin/lib/console/resolve.js`'s `SECTION_MAP` classifies staged files by filename prefix alone:
`/^(reflect|digest-promotion|leftover|...)(-|\b)/` routes every `reflect-*.md` file into
`SECTIONS.QUEUE`, with no read of the file's own `**Category:**` field. `SECTION_STANCES[QUEUE]`
resolves to `apply`, and the "On approval" step for a `Q#` item is "create the record — reading
`Title:`/`Type:`/`Labels:` and the body from the item's staged file" — fields a non-tangential
reflect finding's staged file never carries, by the same SKILL.md's own contract.

Reproduced live in this run (`2026-09-14T182541-record-1800`, wrap-up for #1800):
`staged/reflect-1.md` is a `Category: observation` finding (no Title:/Type:/Labels: header, per
contract) with `**Files:** general (test suite infrastructure)`. `console-resolve.js --policy
console-auto` classified it into "Queue writes" and resolved it `AUTO-RESOLVED: apply` — the same
resolution a genuine tangential idea gets. Executing that resolution literally would attempt
`gh issue create` against a file with no `Title:`/`Type:`/`Labels:` fields to read, either
erroring or filing a malformed issue with fields guessed from the wrong shape.

## Deliverables

- [ ] `classifyStagedItem` (or its caller) reads the staged file's `**Category:**` field for any
      `reflect-*`/`digest-promotion-*`/`leftover-*` (any prefix in the same `SECTION_MAP` bucket
      that reflect's own contract distinguishes by category) match, and routes non-tangential
      categories to a section whose stance doesn't attempt record creation — most naturally
      `SECTIONS.PENDING` (the same "surface for a human, no auto-file" treatment `review-*`
      findings already get), not `SECTIONS.QUEUE`.
- [ ] A regression test pinning that a `Category: observation`/`Category: convention` staged
      reflect file resolves to something other than `apply`-as-Queue-write, alongside an existing
      `Category: tangential` file still resolving to `apply`-as-Queue-write as today.

## Acceptance Criteria

1. `console-resolve.js --policy console-auto` on a fixture `staged/reflect-N.md` carrying
   `**Category:** observation` and no `Title:`/`Type:`/`Labels:` header does not classify it into
   "Queue writes" / resolution `apply`.
2. The same CLI on a fixture `staged/reflect-N.md` carrying `**Category:** tangential` and a
   `Title:`/`Type:`/`Labels:` header still classifies it into "Queue writes" / resolution `apply`,
   unchanged from today.
3. `npm test` green.
