# 2014: Make the multi-spec artifact-overwrite check distinguish an append-only shared journey from an overwrite

Defer-reason: pre-existing-outside-diff
Origin: /flow #1988-#1997 consolidated close (parent run 2026-09-06T110420)

## Current State

`flow/multispec-artifact-namespacing.md`'s completion check (#786) walks `git log --name-status --diff-filter=AM {base}..HEAD -- docs/journeys/ stories/` and HARD-GATEs when any path shows `A` in one commit and `M` in a later one — "a spec's journey/story artifact was silently overwritten by a later spec's write". In the #1988–#1997 run, `docs/journeys/compose-a-per-run-context-bundle-1988.md` was added by #1988 and then modified by #1989, #1991, #1992, #1993, #1995, and #1997 — each later spec appending its own numbered step and an Origin line to the one journey that documents the composer, by design (the journeys skill's own "extend the existing journey" guidance). `git log --numstat` over the range shows every cross-spec modification is append-only (0 deletions) and every commit with deletions (at most 2 lines) edits that spec's own step or the frontmatter file list. The check cannot tell this shape from an overwrite and fires on it, so the controller had to rule it manually with the numstat as evidence.

## Deliverables

- Extend the check: for each `A`-then-`M` path, read `git log --numstat` for the later commits; a later commit whose deletions on that path are zero (or confined to lines that commit itself added earlier — a same-spec edit, identified by the `refs #N` trailer matching the step's Origin line) is an extension, not an overwrite; only a later-spec commit that deletes lines it did not add trips the gate.
- State the rule in `flow/multispec-artifact-namespacing.md` next to the existing walk, with the run above as the worked example.
- A fixture test on the walk (a synthetic repo with an add-then-append history and an add-then-overwrite history) proving the gate fires only on the second.

## Acceptance Criteria

- The #1988–#1997 history (`4c6e76733..b247a02d3`, `docs/journeys/compose-a-per-run-context-bundle-1988.md`) passes the extended check with no manual ruling.
- A synthetic overwrite (a later spec's commit deleting an earlier spec's step lines) still HARD-GATEs.
- `npm test` green apart from the tracked baseline (#1900).
