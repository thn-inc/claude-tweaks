# 4704: friction-events.js unions every main-checkout session's ad-hoc run dir into one wrap-up's Friction lens

Origin: reflect full from /specify #4606 session

Defer-reason: tangential

## Current State

`plugin/bin/friction-events.js` unions this run's events with every ad-hoc run dir whose recorded `worktree` matches the current worktree path (`findRunsByWorktreePath(worktreePath, worktreePath, runDir)`, line 223 on origin/main). Since #2543, a session working in the main checkout mints an ad-hoc dir whose `worktree` is the main checkout root. So when the read runs from the main checkout, "same worktree" means every main-checkout session that ever stamped one.

Measured 2026-10-31 in this repo: `friction-events.js --run <this standalone wrap-up run>` run with cwd = main checkout returned 44 events from 17 ad-hoc dirs owned by other session ids (`run-state.json` `sessionId` ≠ this session's). One was another session's `AskUserQuestion` about #3508. The same command with any other cwd returned 0. 17 of the 110 ad-hoc dirs under `.claude-tweaks/pipelines/` record the main checkout as their `worktree`. A wrap-up's Friction lens therefore reports other sessions' denials and questions as this run's friction, and the inflated count can feed upstream-feedback filings.

## Deliverables

1. When the resolved worktree path is the main checkout (not a linked worktree), restrict the worktree-path union to ad-hoc dirs owned by the current session id. Keep today's path-only union for linked worktrees, where a path identifies one session's work.

2. Regression test: two ad-hoc dirs recording the main checkout root, one owned by the current session id and one by another; only the first one's events are returned.

## Acceptance Criteria

- With cwd = main checkout, `friction-events.js` returns no event from an ad-hoc dir whose `sessionId` differs from the current session's.

- An ad-hoc dir for a linked worktree is still unioned by path, as #2783/#1333 require.

- The new test is shown red against the current union.

## Release Note

Stop the Friction lens from counting other sessions' denials and questions as the current run's friction.

### Key Files

- `plugin/bin/lib/hooks/context.js` — only if the scoping belongs in findRunsByWorktreePath
- `tests/friction-events-cli.test.js` — main-checkout cross-session regression case
