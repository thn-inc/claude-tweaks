# 2590: Dispatch/materialize has no dedup check against an already-closed sibling PR that disproved a record's premise

Origin: reflect full mode from #2512
Defer-reason: tangential

## Current State

Record #2512 ("9 pre-existing npm test failures unrelated to any single record") was filed by
`ledger resolve gate` during #2462's wrap-up. Before this run, a prior worktree run had already
built out the identical investigation, reached the identical conclusion ("premise no longer
holds — all 9 originally-cited tests pass, full suite is 9127/9127 clean"), and opened PR #2560
stating exactly that — which was subsequently closed without merging, leaving #2512 open and
unauthorized-for-close. This run's own `/flow #2512 build,test` step then independently
re-ran the entire investigation from scratch (a ~75-115s full `npm test` invocation, twice more
across build/test/review), reaching the same conclusion again and opening a second PR (#2588) for
the same record. No step in `/claude-tweaks:flow`, `/claude-tweaks:dispatch`, or
`/claude-tweaks:build`'s materialize/pre-flight checks looks for a closed PR whose body already
states "record's premise no longer holds" for the same issue number before starting a fresh
full-pipeline investigation.

## Deliverables

Add a check (materialize.md's resolution step, or dispatch's own pre-flight) that greps closed
PRs referencing the target issue (`gh pr list --search "linked:issue-{n}" --state closed`, or a
body/title search for the issue number) for language indicating the same "premise already
resolved" conclusion, and surfaces it as a hint before re-running the full investigation — at
minimum logging a `SCANNED` decision citing the prior PR instead of silently redoing the same
work with no acknowledgment that a sibling attempt already reached the same finding.

## Acceptance Criteria

A record whose premise a closed sibling PR (referencing the same issue number) already disproved
is flagged at materialize or pre-flight time with a citation to that PR, before the pipeline
re-runs a fresh full-suite investigation from scratch.
