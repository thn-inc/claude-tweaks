# 4138: Close standalone run dirs on every exit, not only on success — beyond release

Origin: reflect hindsight from #3898

Defer-reason: tangential

## Current State

Observed in the 2026-10-24 release session: the 10-21 and 10-23 standalone sweep runs stayed unarchived until a hand-run `close-run`/`archive-run` (landed via PR #4075), and `2026-10-24T104015-backlog-standalone` was listed with status unknown at session start. #3898 found the same leak in `/claude-tweaks:release`: a standalone run dir carries no owning session, so session end never marks it `interrupted`, and an early exit that skips the skill's close-out leaves it `active` for the next resolution to adopt. Release now closes out on every exit (refs #3898); the other `resolve-run-dir --standalone {name} --create` callers were not audited.

## Deliverables

Enumerate every skill that mints a standalone run dir (`resolve-run-dir --standalone {name} --create`, `_shared/run-dir-resolution.md` step 4).

For each, confirm every exit after the mint runs `close-run` on a created directory (and archival where the skill archives), or add it, mirroring release Step 8's "Every exit runs the close-out" paragraph.

## Acceptance Criteria

Every standalone-minting skill states close-out on every exit after its mint, and a conformance test enumerates the minters and pins that statement for each.

`npm test` passes.

## Release Note

Standalone skill runs (sweep, backlog, tidy and others) close their run directory on every exit, not only on success.
