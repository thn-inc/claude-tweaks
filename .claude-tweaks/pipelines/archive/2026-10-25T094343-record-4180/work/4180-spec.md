# 4180: reconcile: make --dry-run write nothing, and record why an escalate or resolve failed

Verified-as-of: 9c5fa55f1b8eaf692656edfd07e42dc8c7fa6c6c

Origin: ledger row 11 from #2724

Defer-reason: genuinely-larger

## Current State

- `reconcile --dry-run` still writes on the non-exempt path. `trackResidue` (`plugin/bin/lib/reconcile/cache.js:243`) bumps failure counts and can call `escalateResidue`, which files, appends to or reopens GitHub issues. `commitCacheBatch` (`cache.js:152`) then writes the cache regardless of `dryRun`. Only #2724's new exempt clear (`trackStuckSkip` → `clearResidue`) and `pruneResidueFailures` (`archive-merged.js:2331`) check `dryRun`.
- Failures are swallowed across the family. `trackResidue`'s escalate catch, `pruneResidueFailures`'s resolve, and `trackStuckSkip`'s `clearResidue` call all drop a failed escalate or resolve result. `clearResidue` keeps an escalated entry on `resolution-failed` but records no reason, so a stuck resolve retries every pass with nothing to show why (ledger row 22 of run 2026-10-24T153132-spec-3997-2724).

## Deliverables

1. Thread `dryRun` through every `trackStuckSkip`/`trackArchiveResult` escalate path, `trackResidue`, and `commitCacheBatch`, so a dry run writes neither the cache nor GitHub. Report what it would have done instead.
2. Give the family one channel for swallowed escalate/resolve failures: record the failure reason on the cache entry (for example `lastResolveError`) and surface it in reconcile's JSON output and residue summary.
3. Tests for both, each red on the pre-change code.

## Acceptance Criteria

- `reconcile --dry-run` over a fixture with a past-threshold stuck path makes zero `gh` calls and leaves `reconcile-cache.json` byte-identical.
- A resolve that returns `resolution-failed` leaves its reason on the cache entry, and the reason appears in reconcile's JSON output.
- Non-dry-run behavior is unchanged: the existing reconcile suites pass.

## Release Note

`reconcile --dry-run` no longer writes the cache or GitHub, and failed escalations now say why.
