# 2762: Three pre-existing test failures observed on #2595's build+test run (Impeccable pin, console-execute pr-first wiring, PID/reconcile timing)

Surface: infra

## Current State
During `#2595`'s `build,test` pipeline run (2026-09-22, plugin 6.126.0), `npm test` reported 6 failing tests out of 9374, in files entirely outside that build's diff (which only touched `plugin/skills/review/step3-lens-dispatch.md`, `plugin/skills/review/step3-debate-and-refutation.md`, and `plugin/skills/_shared/subagent-output-contract.md`). Each failure reproduced consistently when the affected file was re-run in isolation (`node --test {file}`), ruling out machine-load flake per CLAUDE.md's tolerance note. Three distinct root causes across four files:

1. **`tests/impeccable-plugin-contract.test.js`** (3 failures: "the installed plugin matches the pinned version", "gatherSignals() executes cleanly and returns the documented shape", "the CLI entrypoint accepts no flags") — the installed Impeccable plugin resolves to version `4.3.1`, but the test suite's fixtures are pinned to `4.0.2`. The first failure's own error message states the remedy plainly: "Install 4.0.2, or re-pin deliberately by re-recording the fixtures against the new version." The other two failures are downstream of the same unresolved pin (`could not resolve an installed root at the pin`).
2. **`tests/console-execute.test.js`** (1 failure: "reconcile(): the console check is wired in and reachable via ALL_CHECKS on a pr-first project") — assertion "the console check must have run under pr-first" fails; the console check does not appear to be reachable via `ALL_CHECKS` under a `pr-first` integration-model project in this environment.
3. **`tests/bin-lib/visual-decide/cli.test.js`** (1 failure: "stop is stale-PID tolerant (dead PID -> already-stopped, exit 0)") — expects the stop command to treat a dead PID as already-stopped (exit 0); observed `false !== true`, suggesting the stale-PID detection path isn't triggering as expected in this sandbox.
4. **`tests/bin-lib/hooks/reconcile-background.test.js`** (1 failure: "reconcile-background: the same abandoned interrupted run IS archived when CLAUDE_TWEAKS_SESSION_ID is unset (control — unchanged fallback behavior, #1687 AC2)") — expected the original run dir to have been archived away; observed it was not (`true !== false` on "expected the original run dir to have been archived away").

None of these are related to #2595's scope (a documentation-only fix to the review Step 3 `SCRATCH:` dispatch lines and the Scratch rule in `subagent-output-contract.md`).

**Related:** #2531 (`impeccable-plugin-contract.test.js`'s version-pin test failing in a sandbox with a mismatched plugin cache) — same root symptom as this record's Deliverable 1 (Impeccable pin `4.0.2` vs. installed `4.3.1`), filed separately and already `ready`. Check #2531's resolution before duplicating that fix here — see Gotchas.
