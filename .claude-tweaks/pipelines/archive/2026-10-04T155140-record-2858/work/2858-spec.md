# 2858: Consolidate the multi-spec parent run-state fallback into one context.js helper

Origin: reflect hindsight from #2664

Defer-reason: tangential

## Current State

Four readers each carry their own copy of the multi-spec "per-spec run dir falls back to its parent for the shared worktree/PR stamps" rule:

- `plugin/bin/lib/wrap-up/pack.js` `resolveState` (#1930 review C1) — fills `worktree`/`pr` from the parent.
- `plugin/bin/lib/wrap-up/engine-verify.js` `resolvePrNumber` — reads the parent `run-state.json` when the per-spec one is absent (a different rule: whole-file fallback, not per-field).
- `plugin/bin/lib/pr-bookkeeping/precondition.js` `checkPrBookkeepingPrecondition` (#2664) — per-field fill of `worktree`/`pr`/`prExempt` plus the parent `decisions.md` degrade line.
- `plugin/skills/flow/multispec-review-console.md:88` — prose: reads `pr` on the parent `run-state.json`.

The three code copies already disagree on semantics (per-field fill vs whole-file fallback; `/^spec-/` basename gate in two, none in `resolvePrNumber`; `prExempt` honored in one). A fifth reader will copy whichever it finds first.

## Deliverables

1. One exported helper beside `readRunState` in `plugin/bin/lib/hooks/context.js` (e.g. `readRunStateWithParent(runDir)`) implementing the per-field fill for `worktree`/`pr`/`prExempt` behind the `/^spec-/` basename gate, returning `{ state, parentRunDir }`.
2. Migrate `pack.js` `resolveState`, `engine-verify.js` `resolvePrNumber`, and `precondition.js` to it; keep each call site's existing tests green.
3. `resolvePrNumber`'s whole-file fallback converges on the per-field rule (a per-spec `run-state.json` carrying only `status` must still find the parent PR) — add a test for that shape.

## Acceptance Criteria

- `grep -rn "path.dirname(runDir), 'run-state.json'" plugin/bin` returns no hits outside the new helper.
- A per-spec dir with a status-only `run-state.json` resolves the parent PR in all three consumers (one test each).
- `npm test` passes.

## Release Note

No user-visible change — internal consolidation of how multi-spec pipeline runs locate their shared worktree and PR.
