# 2982: Run design-wrapper explore mode's concept-seed through the Impeccable engine

Surface: infra

## Overview

Run `design-wrapper`'s `explore` mode's deal step through the engine's `concept-seed` verb, via `impeccable-engine.js run concept-seed`, instead of the retired `concept-seed.mjs`. Today `explore` skips as unavailable for every user on Impeccable 4.2.2 or later, because its exact-pin resolver finds no `concept-seed.mjs`.

The mode's division of labour is unchanged: upstream deals, this mode derives and renders. What is new is a documented network side effect — the engine's `concept-seed` contacts Impeccable's catalog service (observed reporting `source: api`) — and three run-time skip reasons: `exec-failed` (for example offline), `timeout` and `shape-mismatch`, alongside the engine module's resolve reasons. The merged engine module's exported reason list is authoritative if it differs from these names.
