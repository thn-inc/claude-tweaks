## Current State

PR #4148 (record #4067) adds `.github/workflows/test-perf.yml`, which runs `npm run test:perf` daily on a schedule and on `workflow_dispatch`, never on pull_request or push. GitHub only fires `schedule` and `workflow_dispatch` from a workflow file on the default branch, so the workflow could not be run on a real runner before merge. Its first real execution is therefore still outstanding after merge, and the budgets in `perf/` have never been observed passing on a ubuntu runner under Node 20.

## Deliverables

1. After PR #4148 merges, start the workflow once with `gh workflow run test-perf.yml` and watch the run to completion.
2. If a `perf/*.test.js` budget fails on the runner, decide per budget whether it is a real regression or a runner-speed assumption (never loosen a bound to get green), and file or fix accordingly.
