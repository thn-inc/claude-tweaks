# 1383: tidy: Yours-section rows need actionable commands, why-not-auto reasoning, and digest-rule compliance

## Current State

`/claude-tweaks:tidy`'s Step 6 report renders a "Yours ({N})" section for findings that need human judgment. Observed live on standalone-auto run `2026-08-24T134857-tidy-standalone`: (1) at least one Yours row shape carried no actionable command at all — the `github-pr-scan.md` "awaiting review" PR finding rendered as a bare summary sentence ("13 open PRs — nothing wrong beyond what's covered") with zero per-PR follow-up, which the report's own "No finding may be presented information-only" rule (step-6-auto.md) should have caught but doesn't cover this shape; (2) no Yours row states *why* its finding wasn't auto-applied — the reversibility/confidence-floor reasoning lives only in step-6-auto.md's routing table and never reaches the rendered report, so a reader can't tell whether a row is "needs judgment" vs "policy forbids auto for outward writes" vs "no mechanical fix exists"; (3) the digest rule (step-6-auto.md, "Digest" row) requires the chat digest to render "Yours group heads + counts, each followed by its batch or ref-less line" rather than pushing everything into report.md, but the executing session in the observed run collapsed the whole section into one prose paragraph plus a file attachment, so the user had to explicitly ask "what about the Yours section?" to get the actual content — friction on exactly the section meant to be the click-through surface.

## Deliverables

Audit every Yours-routing finding shape across `scan-procedures.md`, `step-1-records.md`, and `github-pr-scan.md`/`github-pr-scan-acceptance.md` for a genuine paste-ready command or an explicit `review`-group exemption; close the confirmed info-only gap in the "awaiting review" PR shape (give it a per-PR command, e.g. `gh pr view {n} --web`, or fold it into Clean instead of Yours if truly no action exists).

Add a one-clause "why not auto" reason to each Yours row's rendering, sourced from step-6-auto.md's own routing-table rationale column (e.g. "outward GitHub write, never auto per reversibility floor" / "judgment call, no mechanical fix") rather than re-derived per-render.

Strengthen the conformance scan / hard gate so a chat response omitting the Yours group heads+commands (falling back to a one-line summary plus file attachment only) fails the same way an omitted Approve section already does.

## Acceptance Criteria

A fresh `/tidy` standalone-auto run's chat digest renders every Yours group with its command (or stated review-only exemption) and a why-not-auto clause, with no follow-up question needed to see the content.

`skill-prose-conformance-tests` gains a case pinning "every Yours row carries a command or a stated review-only exemption."

The conformance scan rejects a rendered report/digest that omits the Yours group heads+commands the same way it already rejects an omitted Approve section.
