  scratchpad-write + subprocess cost even on the `standard` (default, every existing project)

`policy-schema.md` is currently 41,341 bytes — under the current 46080-byte ceiling with real
headroom, not the near-breach the original filing described. **The byte-ceiling-split deliverable
below is downgraded from a hard requirement to optional hygiene** for this reason.

## Technical Approach

For the capture wiring gap: mirror exactly how `/specify`'s three call sites invoke
`brainstorming-ceremony.md` (`resolve-policy.js --values design-ceremony` then
`compose-brainstorm-args.js`) at `capture/routing.md`'s `--route=brainstorm` invocation point —
this should be closer to a call-site addition than new logic, since the procedure itself already
exists and is shared. For the prose-conformance test: follow
`tests/ceremony-profile-roster.test.js`'s own pattern (grep the live skill-prose corpus for the
citation strings) rather than inventing a new test style. For the fast-lane collision: this is
the one deliverable requiring an actual decision — read both `ceremony-profile.md`'s roster and
`brainstorming-ceremony.md`'s existing workaround comment before choosing; a rename is a breaking
change to `#1886`'s own shipped AC1 and needs explicit sign-off, so default to the
accept-and-document path unless sign-off is actually sought and obtained.
