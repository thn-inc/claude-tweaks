# 1170: pr-early-run-lifecycle invokes merge-size-probe repo-relative — dead in every consumer install

Defer-reason: pre-existing-outside-diff
Surface: backend

## Current State

`plugin/skills/_shared/pr-early-run-lifecycle.md` (the pre-undraft merge-size step, ~line 242) invokes the merge-size probe repo-relative (`node plugin/bin/merge-size-probe.js`) instead of the `"${CLAUDE_PLUGIN_ROOT}/bin/..."` form the same file already uses at ~line 171. In any consumer project running the installed plugin there is no `plugin/` subtree, so the invocation fails with MODULE_NOT_FOUND — and the step's own degrade clause ("log a warning and continue") swallows it. The #641 merge-induced ceiling check therefore silently never executes anywhere except the claude-tweaks repo itself.

## Deliverables

- Switch the invocation to the `"${CLAUDE_PLUGIN_ROOT}/bin/merge-size-probe.js"` form.
- Sweep the same file (and skills citing it) for any other repo-relative `plugin/bin/` invocation.
- A conformance test that scans skill prose for `node plugin/bin/` invocations (the repo-relative form) and fails on any hit outside documented exemptions.

## Acceptance Criteria

- No `plugin/skills/**/*.md` instruction text invokes a bin via a repo-relative `plugin/bin/` path.
- The new conformance test goes red when the old line is restored.

## Technical Approach

Mechanical fix, mirroring the pattern the same file already uses correctly at ~line 171: replace `node plugin/bin/merge-size-probe.js` with `node "${CLAUDE_PLUGIN_ROOT}/bin/merge-size-probe.js"` at ~line 242. Sweep `plugin/skills/**/*.md` for the same repo-relative shape (`grep -rn 'node plugin/bin/' plugin/skills/`) and fix any other hits found. The conformance test lives alongside existing skill-prose conformance suites (per `skill-prose-conformance-tests` skill's own convention) and asserts no `plugin/skills/**/*.md` file contains the repo-relative `node plugin/bin/` pattern.

### Key Files

- `plugin/skills/_shared/pr-early-run-lifecycle.md` — the ~line 242 fix, and the ~line 171 correct-form precedent to mirror
- `tests/` — the new conformance test scanning skill prose for the repo-relative pattern

## Gotchas

- The bug is silent by design (the step's own degrade clause swallows the MODULE_NOT_FOUND and just logs a warning) — the new conformance test is the only thing that will ever catch a regression here, since the runtime failure itself produces no visible error in a normal pipeline run.
- Check for the same repo-relative pattern in skills that cite `pr-early-run-lifecycle.md` too, not just the file itself — a citing skill could have its own copy-pasted invocation.
