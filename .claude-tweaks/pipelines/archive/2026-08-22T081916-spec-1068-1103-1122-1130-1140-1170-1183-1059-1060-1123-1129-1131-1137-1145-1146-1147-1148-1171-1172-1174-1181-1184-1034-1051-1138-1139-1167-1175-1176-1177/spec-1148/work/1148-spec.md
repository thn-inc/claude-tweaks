# 1148: artifacts probe: reconcile report.json path docs, then age out loose first-level files if real

Defer-reason: genuinely-larger
Surface: backend

## Current State

`plugin/bin/lib/residue/probes/artifacts.js` (#1078) ages out only first-level *directories* under the three `.claude-tweaks/artifacts/` roots (`if (!entry.isDirectory()) continue;`) — a file written directly under e.g. `.claude-tweaks/artifacts/screenshots/qa/` is never flagged, no matter how old. Relatedly, `plugin/skills/help/context-flow.md:74` documents `/test` qa-mode outputs as `.claude-tweaks/artifacts/screenshots/qa/report.json` and `report.md` (loose first-level files — exactly the immortal case), while `plugin/skills/test/qa-procedures.md` and `plugin/skills/journey-health/SKILL.md:97` both place `report.json` inside a per-run directory. One of the two documented layouts is wrong. Found by #1078's final whole-branch review (M4); run ledger `docs/plans/2026-08-20-qa-artifact-retention-ledger.md` row 5.

## Deliverables

1. Resolve the documentation contradiction first: determine the real `/test` qa report location (per-run dir, per `qa-procedures.md`) and fix `help/context-flow.md:74` to match — or, if loose top-level reports are genuinely produced, document that layout consistently.
2. If (and only if) loose first-level files are a real producer output after 1: extend the probe's aged class to age them out with the same 30-day rule, with tests (aged loose file flagged, fresh kept).
3. If loose files turn out not to be a real layout: a one-line note in the probe's header comment stating the directories-only scan is deliberate because producers only write run/session subdirectories.

## Acceptance Criteria

- `context-flow.md`, `qa-procedures.md`, and `journey-health/SKILL.md` agree on the report path layout.
- Either the probe ages loose first-level files (with tests proving flag/keep both ways), or its header states the directories-only decision with the producer-layout rationale.
- `node --test tests/bin-lib/residue/*.test.js` and full `npm test` pass.

## Technical Approach

Documentation reconciliation first (it decides whether the code change exists at all), then the conditional probe extension mirroring the existing aged-class loop.

### Key Files

- `plugin/skills/help/context-flow.md` — report path cells
- `plugin/bin/lib/residue/probes/artifacts.js` — conditional aged-class extension or header note
- `tests/bin-lib/residue/artifacts.test.js` — conditional new cases

## Gotchas

- Do not weaken the legacy-root ownership discriminators while touching the probe — they are the C1 data-loss fix (see the module header and `docs/plans/2026-08-20-qa-artifact-retention-ledger.md` row 6).
