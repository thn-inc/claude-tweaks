# 1147: tidy scan-procedures: surface kind:pipeline-run findings to the Step 4.5 agent

Defer-reason: pre-existing-outside-diff
Surface: infra

## Current State

`plugin/skills/tidy/scan-procedures.md`'s Step 4.5 section runs `bin/residue.js --scope repo --no-suite --json` and then enumerates, paragraph by paragraph, which finding kinds the dispatched Git agent turns into candidates. It covers `kind: worktree`, `kind: branch`, and (since #1078) `kind: artifact` — but has never had a paragraph for `kind: pipeline-run`, even though `plugin/skills/tidy/step-6-auto.md` (the "These two rules cover interrupted/unreadable runs…" paragraph) asserts that "every `/tidy` Step 4.5 pass already reads" the `pipeline-run` finding. Per the subagent contract, agents only see what's in their prompt, and the dispatcher inlines the scan-procedures section — so un-archived clean-run findings from `bin/lib/residue/probes/pipeline-runs.js` are computed and then silently dropped by the scan agent. Found during #1078's final whole-branch review (the same gap it fixed for the new `artifact` kind); run ledger `docs/plans/2026-08-20-qa-artifact-retention-ledger.md` row 4.

## Deliverables

1. A `kind: pipeline-run` paragraph in `scan-procedures.md`'s Step 4.5 body, following the existing per-kind paragraph format, directing the agent to collect each such finding as a `[git]` candidate with its remedy (`auto` — the archival move documented in `wrap-up/cleanup-procedures.md` Section B).
2. Any per-kind enumeration adjacent to that section re-checked for completeness against `bin/residue.js`'s live probe list, so the next added kind doesn't repeat this gap (a sentence pointing at the probe list as the source of truth is acceptable in place of enumerating).

## Acceptance Criteria

- The Step 4.5 section names every finding kind `bin/residue.js` can emit under `--scope repo`, or explicitly points at the probe list as authoritative.
- `step-6-auto.md`'s "every /tidy Step 4.5 pass already reads" assertion is true after the edit.
- `npm test` passes.

## Technical Approach

Prose-only edit mirroring the `kind: artifact` paragraph #1078 added; verify against the live probe list in `plugin/bin/residue.js`.

### Key Files

- `plugin/skills/tidy/scan-procedures.md` — Step 4.5 per-kind paragraphs

## Gotchas

- The dispatcher inlines this section into the agent prompt — keep the paragraph self-contained (no references the agent can't resolve).
