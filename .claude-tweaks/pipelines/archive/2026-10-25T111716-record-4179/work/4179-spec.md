# 4179: reconcile: sweep main-checkout ad-hoc session dirs by session liveness instead of escalating them as stuck

Verified-as-of: 9c5fa55f1b8eaf692656edfd07e42dc8c7fa6c6c

Origin: ledger row 9 from #2724

Defer-reason: genuinely-larger

## Current State

- `stampAdHocRunDirForDenial` (`plugin/bin/lib/hooks/context.js`) mints an `-adhoc-standalone` run dir on a denial in the main checkout, keyed on the main checkout's own path. The `adhoc-superseded` sweep (`isAdHocStandaloneSuperseded`, `plugin/bin/lib/reconcile/archive-merged.js`) archives an ad-hoc dir only once its recorded worktree is no longer registered. The main checkout is always registered, so these dirs are never swept.
- Scale on 2026-10-24: 29 such dirs on disk in the main checkout's `.claude-tweaks/pipelines/`, 5 minted that day alone.
- Past the 7-day stuck TTL they escalate into the consolidated structurally-stuck record at `no-pr`/`no-branch`. #2724 (PR #4144) exempts linked-worktree ad-hoc dirs from that escalation, and deliberately not main-checkout ones, because nothing else would ever clean those up. Ledger row 8 of run 2026-10-24T153132-spec-3997-2724 closes two of them by hand.

## Deliverables

1. Sweep a main-checkout ad-hoc dir by session liveness instead of worktree registration: archive it once `plugin/bin/lib/run-liveness` reports its stamped session ended and a grace period has passed. Leave the 30-day TTL path for linked-worktree dirs unchanged.
2. Once (1) lands, extend `isAdHocIntrinsicSkip`'s exemption to main-checkout ad-hoc dirs, so they stop escalating into the consolidated record.
3. Until then, add one remedy line for a main-checkout ad-hoc dir to `structurallyStuckBody` (`plugin/bin/lib/reconcile/escalate-residue.js`) telling the reader how to close and archive it.
4. Update `docs/reconcile-checks.md`'s exemption paragraph to match.

## Acceptance Criteria

- A main-checkout ad-hoc dir whose stamped session is dead and past the grace period is archived by a reconcile pass (test with a fixture dir and a stubbed liveness probe).
- A main-checkout ad-hoc dir whose session is still live is left in place.
- A main-checkout ad-hoc dir no longer escalates at `no-branch`/`no-worktree`/`no-pr`; its escalated entry is resolved off the record the same way #2724 resolves linked-worktree ones.
- The new sweep test fails against the pre-change code.

## Release Note

Reconcile now cleans up the ad-hoc session directories a denial leaves in the main checkout, instead of escalating them as stuck runs.
