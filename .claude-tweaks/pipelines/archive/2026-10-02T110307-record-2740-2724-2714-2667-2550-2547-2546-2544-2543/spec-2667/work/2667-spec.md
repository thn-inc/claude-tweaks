# 2667: Add an AI-generated-design-tells checklist

Surface: infra

**Related:** #2655, #2692, #2706, #2707, #2709, #2765

## Current State

Two social-media Reels describe the same problem: AI-generated app and website design is instantly recognizable because it converges on the same visual tells.

Reel `DcrqbqZRVvC` (transcribed) lists them:

- purple-to-blue gradients and gradient hero text
- emoji in headings
- glassmorphism cards
- low-contrast dark mode
- three-icon-boxes-in-a-row layouts and badge-above-headline
- Lucide icons everywhere and untouched shadcn components
- scroll-triggered fade-ins, cursor-following elements, and hover-fade buttons
- inconsistent spacing
- em-dashes everywhere and generic buzzwords
- serif-italic accent words and the Space Grotesque + Instrument Serif font pairing
- grain texture overlays

Reel `DcjAVGRBmSC` (Showit) adds "gradient blobs, circle icons, bento grids, fake testimonials".

The blocker on hosting has cleared. #2655 landed (PR #2774) as `plugin/skills/visual-review/ux-heuristics-lens.md`: a criteria-only checklist table (`Heuristic | What it flags | Example violation`) invoked from `plugin/skills/visual-review/page-mode.md`'s Step 4 structured analysis, gated on `Surface: web/mobile/desktop`. It is listed in `plugin/skills/visual-review/SKILL.md`'s Page mode bullet and in `docs/plugin-structure.md`'s visual-review sub-file row. That is the hosting pattern this checklist follows.

No claude-tweaks skill enumerates these tells today. Impeccable's design critique (`impeccable:impeccable`, `impeccable-finish-reviewer`) judges overall quality against a chosen world, not a named list of AI-generated tells.

## Deliverables

1. `plugin/skills/visual-review/ai-design-tells-lens.md`: a criteria-only lens in the same shape as `ux-heuristics-lens.md` (intro, "When this lens applies", the checklist table, "Reporting a finding"). The table has one row per deduplicated tell from both Reels, with columns `Tell | Why it reads as generic | Swap it for`.
2. The lens states the source framing: fix a tell by swapping the generic pattern for something specific to the product (real photos, real numbers, real copy), not by polishing the same pattern. It also marks which rows are code-inspectable (gradients, the font pairing) and which need judgment (spacing, buzzwords), and notes that the list is time-bound and needs periodic refresh.
3. `page-mode.md` Step 4 applies this lens right after the UX heuristics lens, with findings reported as `Source = AI Design Tells` in the Step 6 table, under the same `Surface: web/mobile/desktop` gate.
4. `plugin/skills/visual-review/SKILL.md`'s Page mode bullet and `docs/plugin-structure.md`'s visual-review sub-file row list the new file.

## Acceptance Criteria

- `ai-design-tells-lens.md` has one row for every tell listed in Current State: each item from the first Reel's list, plus gradient blobs, circle icons, bento grids, and fake testimonials from the second, merged where they overlap.
- Every row's "Swap it for" cell names product-specific corrective content, not only "avoid this".
- The lens marks each row as code-inspectable or judgment, and states that it needs periodic refresh.
- `page-mode.md` Step 4 cites `ai-design-tells-lens.md` with the `Source = AI Design Tells` reporting label, gated on `Surface: web/mobile/desktop`.
- `visual-review/SKILL.md` and `docs/plugin-structure.md` both name the new file.
- The PR description records a manual dry run: the lens applied to a sample UI snippet with a purple-to-blue gradient hero and an emoji heading flags both tells by name, and applied to a snippet with none of the tells flags nothing.
- `npm test` passes, including the conformance suites that pin `docs/plugin-structure.md`'s sub-file table and `visual-review` prose.

## Gotchas

- Stay scoped to named AI-generated tells. Usability belongs to `ux-heuristics-lens.md` and overall quality to Impeccable, so a row that duplicates either should be cut or reframed as a tell.
- Check `page-mode.md`'s size against any byte ceiling a conformance test pins before adding the paragraph. The lens content itself belongs in the new file, not in `page-mode.md`.
- Some rows (inconsistent spacing, buzzwords) are judgment calls. Mark them rather than implying the whole list is mechanically detectable.
