# 1580: set-config.js: batch-write mode for a full Manifesto config.yml in one call

# Reflect — staged finding 3

**Category:** tangential

Origin: reflect light from #1410
Defer-reason: tangential

## Current State

`bin/set-config.js` only accepts `--run <dir> --key <lever> --value <value>` — one config.yml
lever per invocation. Recovering this run's inherited-but-uninitialized `PIPELINE_RUN_DIR`
(`flow/steps-and-gates.md`'s case-3 recovery path) required computing all 13 canonical Manifesto
levers and writing them one at a time — 13 sequential `node bin/set-config.js` calls to produce
one `config.yml`. Every from-scratch Manifesto run (Step 3's normal, non-recovery path) pays the
same per-lever cost; this session's recovery path just made it visible as 13 back-to-back calls in
one place.

## Deliverables

- `set-config.js` gains a batch mode (e.g. `--run <dir> --from-json <path>` or `--set
  key=value,key=value,...`) that writes every lever in one invocation, validating the full set
  against the canonical lever list before writing any of them (all-or-nothing, matching the
  existing single-key validation's error message).
- `flow/manifesto.md`'s "Approval flow" section updated to call the batch form instead of one
  `set-config.js` call per lever.

## Acceptance Criteria

- AC1: A single CLI call can write a complete Manifesto config.yml (all 13 canonical levers) in
  one invocation, with the same fail-closed validation the single-key form already has.
- AC2: The single-key form is kept as-is (used by the ceremony escape hatch and other one-lever
  writers) — this is additive, not a replacement.
