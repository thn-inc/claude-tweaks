# 2707: Add a typographic-system checklist to the UI review lens

Surface: infra

**Related:** #2706, #2709

## Current State

The design-review lens has no check for typographic-system discipline: font count, a fixed type-scale ratio, or a capped weight count. No rule catches hand-picked pixel sizes, uniform line-height across headings/body, or unbounded paragraph measure (characters per line). No check for tabular figures on numeric/price/timer UI, which is what stops columns from wobbling on data updates. Competitive note: a third-party Claude Code plugin ("UX engine") designs the screen before coding and audits diffs for an "AI look" — worth knowing about as adjacent to Impeccable.

## Deliverables

- A policy row for a bounded type scale (one ratio, capped sizes/weights) and capped line length (45-75 characters).
- A check for tabular-nums usage on numeric UI.

## Acceptance Criteria

- Running the lens on a UI with unbounded font sizes or an unmeasured paragraph flags it with the specific rule violated.

## Release Note

The UX heuristics lens now checks typography: a bounded type scale, readable line length, and tabular figures on numeric UI.

## Technical Approach

Add the checks as rows in `/claude-tweaks:visual-review`'s UX heuristics lens (`plugin/skills/visual-review/ux-heuristics-lens.md`, the plugin-owned UI checklist page mode Step 4 applies and `/claude-tweaks:review` uses for UI-affecting diffs), in its existing Heuristic | What it flags | Example violation shape. `design-wrapper/modes/` is not the home: it routes to Impeccable and project-local critics and owns no checklist. Rows: (1) type-scale discipline — font sizes not derived from one ratio, or font/weight counts over a cap; (2) line length — paragraph measure outside 45-75 characters; (3) tabular figures — numeric/price/timer UI without tabular-nums. Each finding names the rule violated, per the lens's own Reporting section.

### Key Files

- `plugin/skills/visual-review/ux-heuristics-lens.md` — new checklist rows for type scale, line length, and tabular figures

## Gotchas

- #2706 and #2709 edit the same file (`ux-heuristics-lens.md`); consider landing them together to avoid repeated churn on one table.
- The competitor ("UX engine") mention in Current State is informational only. Shaping dropped the original "note in Impeccable's own docs" deliverable: Impeccable is a third-party plugin this repo does not edit. Evaluating the tool would be a separate record.
