# 2709: Add classic friction-reduction UX laws to the review lens

Surface: infra

**Related:** #2655, #2706, #2707

## Current State

The design-review lens has no checks tied to the classic conversion/friction heuristics: choice count (Hick's Law), tap-target/CTA affordance (Fitts's Law), navigation familiarity (Jacob's Law), or chunked identifiers like phone numbers and codes (Miller's Law). No check for a journey's peak/end moments (Peak-End Rule), spatial grouping of related controls (Proximity), or a single visually distinct emphasis element (Von Restorff Effect).

Update (shaping, 2026-09-30): #2655 already shipped `plugin/skills/visual-review/ux-heuristics-lens.md`, whose rows cover all seven heuristics this record names (Reduce choices per screen, Use large targets, Favor familiar patterns, Chunk content, End flows memorably, Group related info, Highlight the primary action). What is missing is the record's second deliverable: naming each law, so violations are self-documenting. The record is rescoped to that delta.

## Deliverables

1. Add the law's name to each of the seven existing `ux-heuristics-lens.md` rows that already cover it: Reduce choices per screen → Hick's law; Use large targets → Fitts's law; Favor familiar patterns → Jakob's law; Chunk content → Miller's law; End flows memorably → peak-end rule; Group related info → law of common region / proximity; Highlight the primary action → Von Restorff effect.
2. Extend the Chunk content row's example to cover unchunked numeric identifiers (e.g. a 16-digit code rendered as one unbroken run).
3. Add one sentence to the lens's "Reporting a finding" section: a finding cites its row's law by name when the row has one, so violations are self-documenting.

## Acceptance Criteria

1. Each of the seven rows listed in Deliverable 1 names its law.
2. The Chunk content row's example covers an unchunked numeric identifier.
3. The checklist still has 20 rows — no duplicate row is added for a law an existing row already covers.
4. "Reporting a finding" asks a finding to cite the row's law by name.
5. `npm test` passes.
