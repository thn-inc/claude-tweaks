# 2695: Compare Hallmark skill against Impeccable for design-wrapper

Surface: infra

## Current State

`design-wrapper` routes all design-quality work to Impeccable; no comparison against alternative "anti-slop" design skills exists. A described skill, Hallmark, similar to Impeccable/Taste, strips AI-slop gradients/fonts and has a "study" command to pull styling from a reference screenshot or website and apply it to a build.

## Deliverables

- Trial Hallmark's study command (reference-screenshot styling) against a sample build alongside Impeccable's own asset/finish-review passes.
- Decide whether Hallmark's reference-matching complements Impeccable or is redundant with it.

## Acceptance Criteria

- A short comparison note (overlap/gaps vs. Impeccable) checked into `design-wrapper`'s docs.
