# 2689: Add a /visual-plan-style skill for richer implementation plans

Surface: infra

## Current State

claude-tweaks' `/specify` and `/visualize` skills produce text-based specs and standalone diagrams, not a unified visual plan. A described "/visual-plan" skill for Claude Code/Codex generates rich, visual implementation plans alongside the text.

## Deliverables

- Evaluate folding visual-plan-style diagramming into `/specify` or `/writing-plans` output, rather than only a post-hoc `/visualize` call.
- Prototype on one in-flight record to see whether it improves review speed over the current text-only plan.

## Acceptance Criteria

- A sample plan renders both the text spec and an accompanying visual-plan artifact.
- A decision is recorded on whether this becomes a standing step in `/specify` or stays opt-in via `/visualize`.

## Release Note

Added richer diagrams to implementation plans as they are written.

## Technical Approach

This is an evaluate-then-prototype record: first judge whether `/visualize`'s existing diagram-suggestion capability (already enabled in this repo's own CLAUDE.md — "diagram-suggestions: enabled") already covers most of the described value before building anything new. Prototype by running `/specify` on one real in-flight record, then generating a `/visualize`-style diagram for the same record's plan, and comparing review speed/clarity against the text-only version. The Acceptance Criteria's "sample plan renders both" is the concrete prototype output; the Deliverables' fold-in-or-stay-opt-in decision is the record's actual verdict.

### Key Files

- `plugin/skills/specify/` — where a standing visual-plan step would be added, if adopted
- `plugin/skills/visualize/` — the existing diagram capability to compare against and potentially reuse

## Gotchas

- `/visualize` already exists and diagram-suggestions are already enabled project-wide — verify this isn't substantially already-solved before prototyping a parallel mechanism.
- Keep the prototype scoped to one record; this is a feasibility/value judgment, not a commitment to ship a standing feature regardless of outcome.
