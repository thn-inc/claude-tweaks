# 1143: hooks.js subcommands execute --help as a real argument — add a help guard

Surface: backend

Origin: reflect full from #1071
Defer-reason: tangential

## Current State

Every `bin/hooks.js` subcommand treats `--help` as an ordinary argument and runs for real. Observed 2026-08-20: `hooks.js record-worktree --help` resolved the newest non-terminal run dir (a *sibling session's* `/backlog grant` standalone run), stamped `run-state.json` with `worktree: ".../flow-spec-1071/--help"` and the probing session's id, and required hand-repair of the sibling's state. A prior session recorded the same hazard as user memory ("a --help probe on any bin/hooks.js subcommand just runs it for real"), and it still recurred — the fix belongs in the tool, not in operator memory. A bridging Don't now sits in `docs/donts.md`; it carries this record as its removal condition.

## Deliverables

- [ ] `bin/hooks.js` intercepts `--help`/`-h` anywhere in a subcommand's argument list before dispatching: print a one-line usage for that subcommand (or the general usage) and exit 0 with no side effects.
- [ ] Usage lines exist for at least the state-mutating verbs (`record-worktree`, `record-pr`, `close-run`, `resolve-run-dir`, `spec-status`).
- [ ] A test pinning that `record-worktree --help` performs no `run-state.json` write and exits 0 with usage output.
- [ ] Remove the bridging `--help` Don't from `docs/donts.md` (its stated removal condition is this record shipping).

## Acceptance Criteria

1. `node bin/hooks.js record-worktree --help` writes nothing to any run dir and prints usage (pinned by test).
2. Every documented subcommand honors `--help` the same way (pinned by a table-driven test over the verb list).
3. The bridging Don't is gone from `docs/donts.md`; `npm test` passes.

## Technical Approach

One early check in `hooks.js`'s dispatch: if argv (after the verb) contains `--help`/`-h`, print the verb's usage string and return before any lib call. Keep it dumb — no per-verb flag parsing changes.

### Key Files

- `plugin/bin/hooks.js` — early help intercept in the dispatcher
- `tests/hooks-help-guard.test.js` — new pin (no-write + usage per verb)
- `docs/donts.md` — remove the bridging Don't

## Gotchas

- Evidence: sibling run dir `2026-08-20T154937-backlog-standalone`'s `run-state.json` briefly carried `worktree: ".../flow-spec-1071/--help"` and the probing session's id — the exact cross-session corruption `record-worktree`'s own `--run` flag exists to prevent.
- Cost: one sibling-state repair plus diagnosis time; the standing memory did not prevent recurrence.
