# 2968: Dream scan stages transcript command text without path redaction

Origin: /claude-tweaks:release v6.135.0 pre-bump whole-branch review (finding staged/review-12.md, override approved at the release gate)

Defer-reason: needs-human-decision

## Current State

`plugin/bin/lib/dream/scan.js:160` builds each finding with `command: typeof command === 'string' ? truncate(command, MAX_COMMAND_CHARS) : null` — no `redactPaths()` call — while the next line redacts `errorExcerpt: truncate(redactPaths(errorText.trim()), MAX_ERROR_CHARS)`. `composeProposalMarkdown` (scan.js:212) writes `item.command` verbatim into `{run-dir}/staged/dream-proposal-N.md`.

`plugin/skills/harness-health/dream-pass.md:33-35` states that quoted excerpts have "absolute paths ... redacted to `<path>` before they reach a staged proposal" — false for the command field.

Exposure is local: staged files are gitignored under `.claude-tweaks/pipelines/*/*` and readable only by the account that owns the source transcripts; the leak path is a human copying proposal evidence into a committed doc (CLAUDE.md, a skill, a memory). Found by the v6.135.0 pre-bump whole-branch review (lens 3b, both reproduction agents, direct-verified, high) and shipped in v6.135.0 under an explicit release-gate override. Introduced by #2691.

Related, unconfirmed (single agent): `PATH_TOKEN_RE` (scan.js:35) redacts only tokens with two or more slashes — credentials and bearer tokens in error text pass through untouched.

## Deliverables

- [ ] `plugin/bin/lib/dream/scan.js` passes the `command` field through `redactPaths` before truncation, matching `errorExcerpt`'s order
- [ ] A test in `tests/bin-lib/dream/scan.test.js` pins that a command containing an absolute path is staged with `<path>` — and fails with the fix reverted
- [ ] Decide whether secret-shaped tokens (bearer tokens, `KEY=value` exports) are also redacted; either implement it with a test, or narrow `dream-pass.md`'s claim to paths only

## Acceptance Criteria

- A staged dream proposal never contains an absolute path from the transcript in either its Command or its Error line
- `dream-pass.md`'s redaction statement is exactly true for every field `composeProposalMarkdown` writes
- `npm test` passes

## Release Note

Dream-pass proposals redact absolute paths in the quoted command, not just the error text.
