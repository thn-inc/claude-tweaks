## Current State

`tests/helpers-git-template.test.js` (815 lines) tests the template helper `tests/helpers/git-template.js` itself (`fromTemplate`, `fromTemplateSet`, `rewriteTemplatePaths`, `assertNoTemplatePaths`, `disableReceiveAutoGc`, the maintenance-off tests) with cheap builders. On top of that, #5297, #5769, #5770, #5772 and #5324 each added per-fixture tests to it: a `... a second call starts no git process` test for every fixture builder they moved onto templates, and content tests such as `a prune-remote squashed copy holds the squash commit on main over preSquash`.

For those tests the file requires twelve fixture modules: `./helpers/pre-tool-use`, `./helpers/git-fixtures`, `./bin-lib/verify/cli-helpers`, `./helpers/reconcile-fixtures`, `./bin-lib/issues/claims-git-cas-fixtures`, `./bin-lib/pre-review-catchup/fixtures`, `./bin-lib/reconcile/prune-remote-fixtures`, `./helpers/learned-skills-capture`, `./helpers/learned-skills-land`, `./bin-lib/staged-patch/stack-check-fixtures`, `./bin-lib/reconcile/archive-merged-helpers` and `./helpers/statusline-fixtures`.

Each per-fixture test starts with a warm-up call that builds the fixture's template in this file's own process, because no other test here uses it. That build is the cost. A full `node tools/run-tests.js --full` with git trace2 per test file on main at e1c0beb1b (2026-11-17) counted 1,368 git processes for this file (commit 119, rev-list 105, add 103, init 100; 868 started by the test process, 493 by other git processes); the profile counted 145 tests in the file, up from 25 at the 2026-11-16 baseline. PR #5778 (for #5769) reported that the spawn tests it added cost about 800 of the 1,208 processes it saved.

Templates are cached per process, so each one is already built only once here. A table-driven test in this same file would build the same templates and save nothing. The test files that use a builder build its template anyway, so the same warm-call test placed there costs no build.

Nothing but convention says where a new builder's warm-call test goes.

## Deliverables

1. Every test in `tests/helpers-git-template.test.js` whose first step builds a fixture module's template (the warm-call tests and the fixture content tests) moves, under its current name and with its assertions unchanged, to a test file whose own tests already build that template with the same arguments. Where only this file uses a builder variant, the test goes to the test file that uses the builder's other variants and the PR body names the build it adds.

2. The warm-call check itself (one warm-up call, a second call under `GIT_TRACE2_EVENT=<empty dir>`, the directory left empty) is one shared helper under `tests/helpers/`, called by every moved warm-call test, so its text exists once.

3. `tests/helpers-git-template.test.js` keeps every test of the helper itself, including `a copy starts no git process`, and requires none of the twelve fixture modules except where a kept test needs one; each such exception is listed in the PR body with its reason.

4. The header comment of `tests/helpers/git-template.js` says where a builder's warm-call test belongs: in a test file that already uses the builder.

5. The PR body carries a table of every moved test and the file it moved to, and git process counts before and after for every touched test file.
