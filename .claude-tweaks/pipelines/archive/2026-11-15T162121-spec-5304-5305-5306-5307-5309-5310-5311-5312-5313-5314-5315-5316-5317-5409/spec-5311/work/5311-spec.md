## Build Deviations (architecture alignment, Beneficial — spec updated to match the build)

1. **Only real issue numbers are live-checked.** A body dependency outside 1..GRAPHQL_INT_MAX (e.g. `Blocked by #0`) is filtered out of the unresolved set in both module and fence, so it never reaches `gh issue view` and stays with the malformed-blocker pass; without this, the fail-closed rule would reclassify a malformed blocker as `blocked` with a spurious Warning every pull.
2. **A fail-closed dependency verdict is never written to the queue-order cache.** After a failed view or a missing/malformed verified-open-deps file (with an unresolved dependency), the write-back is skipped — module `state.depUnreadable`, fence `DEP_UNREADABLE` — the same rule #5309 applies to a failed native read, so a later cache hit cannot replay the hold without its Warning.
3. **The MCP agent contract fails closed too.** `plugin/skills/dispatch/mcp-transport.md` now has the agent list a dependency whose `issue_read` fails, and states that a missing or malformed file fails closed; `plugin/skills/dispatch/queue-pull-notes.md` states the posture.
