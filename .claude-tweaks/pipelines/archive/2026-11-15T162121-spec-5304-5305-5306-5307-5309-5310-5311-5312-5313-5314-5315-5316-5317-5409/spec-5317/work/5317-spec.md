# 5317: Quote the named-target path in the target-missing Close proposal's staged gh command (queue-pull script and module)

Verified-as-of: 057d958fddb47954989772268e200c7808d7b884

Origin: spec #5227 review (3b)

Defer-reason: pre-existing-outside-diff

## Current State

`plugin/skills/dispatch/queue-pull-script.md:460` writes the target-missing Close proposal's command as `echo "gh issue comment ${NUM} --body \"Closing: the named target ${TPATH} no longer exists at ${INTEGRATION_REF} …\""`, under the proposal's `**Commands:**` heading. `TPATH` comes from `namedTarget` (`plugin/bin/lib/issues/named-target.js`), which reads the `**Doc:**` value of a `by:docs-health` record body. That value only has to match `BOLD_HEADER_RE` (`([^|]+?)`, `plugin/bin/lib/issues/grouping.js`), so it can hold `"`, `$(…)` or a backtick. A path absent from the integration ref passes the target-missing probe whatever it contains, so it lands unescaped inside the double-quoted `--body` of a command the Review Console runs on approval.

`plugin/bin/lib/dispatch/queue-pull.js:722` reproduces the line byte for byte, because #5227's module reproduces the script's behaviour, defects included (its parity suite turns red on a module-only fix). Found by #5227's review, lens 3b, and confirmed by the tiebreak (refs #5227).

## Deliverables

- [ ] The script and `queue-pull.js` both compose the proposal so that the path reaches `gh` as data, either shell-quoted (single quotes, embedded `'` escaped) or passed through a `--body-file` the proposal stages beside it. The two stay identical.

- [ ] A parity fixture in `tests/bin-lib/dispatch/queue-pull.test.js` whose `by:docs-health` record names a missing `**Doc:**` path containing `"`, `$(` and a backtick.

## Acceptance Criteria

1. For a missing named target whose path contains `"`, `$(id)` and a backtick, the staged command, run by bash, posts a comment whose text holds the path verbatim and runs nothing else, on both the script and the module.

2. The #5227 parity suite stays green with the new fixture: the script and the module stage byte-identical proposals.
