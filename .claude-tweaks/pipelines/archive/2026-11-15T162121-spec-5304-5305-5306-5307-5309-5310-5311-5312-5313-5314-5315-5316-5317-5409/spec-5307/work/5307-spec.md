# 5307: Queue pull silently reads a non-array MCP queue or dep-freshness file as empty

## Current State

`aliasMcpTimestamps` coerces a non-array value (a wrapper object such as `{items: [...]}`) in the files-transport queue file or dep-freshness file to `[]` with no Warning. The result is an empty queue, or a dependency dropped from the cache freshness signal, so a stale cache is reused.

Blocked by #5230 — fix this in `plugin/bin/lib/dispatch/queue-pull.js` once /claude-tweaks:dispatch runs the queue-pull CLI. Until then the module reproduces the fence on purpose (#5227's parity contract), so a module-only fix would break parity; if the fence (`plugin/skills/dispatch/queue-pull-script.md`) has not been removed by #5231 when this lands, fix both and keep the parity row.

## Deliverables

- [ ] A non-array queue or dep-freshness file is a failed read with a Warning line, following the transport's fail-closed or fail-open posture for that file, never a silent `[]`.

- [ ] A test covers a wrapper-object file for each of the two inputs.
