# 3475: Make the SessionStart unfinished-runs and staged-proposals banners say never to run their command

Origin: wrap-up reflect from #3419 (run ledger row 3)

Defer-reason: tangential

## Current State

docs/hooks.md now states that every SessionStart inform-tier line names its relay and, when it carries a runnable command, says never to run it yourself (#3419). Two existing banners in plugin/bin/lib/hooks/session-start.js carry a runnable command and name a relay but omit the never-run clause: the unfinished-runs banner (the `node "${pluginRoot}/bin/hooks.js" close-run --run <dir>` line, session-start.js:146-148, which warns only that a listed run may be live) and the standalone staged-proposals banner (`/claude-tweaks:tidy --approve <dir>`, session-start.js:171-172). An autonomous run that receives either line may execute the command itself.

## Deliverables

- [ ] Add a never-run-it-yourself clause to the unfinished-runs banner's trailing instruction in `plugin/bin/lib/hooks/session-start.js`
- [ ] Add the same clause to the standalone staged-proposals banner
- [ ] Update the tests that pin each banner's exact copy

## Acceptance Criteria

- [ ] Both banners' trailing instruction tells the model to relay the line to the user and never run the command itself, and the SessionStart tests pin that copy
- [ ] `npm test` passes

## Release Note

SessionStart banners that print a runnable command now tell the model to leave it for you to run.
