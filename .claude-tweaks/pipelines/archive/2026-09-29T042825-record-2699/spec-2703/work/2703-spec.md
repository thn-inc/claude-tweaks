Surface: infra

## Current State

decomposition shape purely on `project-maturity` policy plus a confirmed rewrite-language match,
with no consideration of the target's actual blast radius.

## Deliverables

- Add a blast-radius qualifier before mandating the strangler-fig shape: skip it when the design
  doc's own `Surface:` resolves to `infra`/`backend` AND the target has no identified runtime
  consumer beyond this project's own development/CI tooling — fall through to the standard five
  heuristics in that case.

- A design doc replacing a subsystem with a real runtime consumer still triggers the strangler-fig
  shape unchanged.
