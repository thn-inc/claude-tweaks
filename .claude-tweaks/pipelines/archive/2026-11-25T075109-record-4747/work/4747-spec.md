# 4747: review: Step 3.5 debates every nearby severity mismatch, not only same-defect contradictions

Origin: reflect full from #4549/#4550/#4556 (multi-spec batch)

Defer-reason: tangential

## Current State

`plugin/skills/review/step3-debate-and-refutation.md` Step 3.5 item 1 runs `detect-overlap` (same path, ±5 lines, different lenses), and item 2 keeps every pair whose severities differ. It never checks that the two findings describe the same defect. Item 5 only warns: "Avoid running debate on every `Path:Line` where any two lenses touched".

On #4556's high-tier review of a 40-line prose recipe, `detect-overlap` returned 32 pairs and 17 severity mismatches. Only 2 were the same defect; 15 were unrelated findings that happened to be near each other. Dispatching all 17 would have meant 34 Frontier/Capable judges. The reviewer had to make an ad-hoc ruling (decisions.md, 16:03:15) to debate only the 2.

`categoriseReproduction` already scores substance similarity (`SUBSTANCE_SIMILARITY_MIN` 0.2) for reproduction pairs. Debate filtering does not use it.

## Deliverables

Filter `detect-overlap`'s contradiction pairs by the same substance score `categoriseReproduction` uses: only pairs at or above `SUBSTANCE_SIMILARITY_MIN` enter debate.

Pairs below the threshold keep their own buckets and go to Step 3.7, each logged once as a proximity coincidence.

Step 3.5 item 2 states the filter, replacing the item-5 warning's judgment call.

## Acceptance Criteria

`review-coordination.js detect-overlap` output (or a new `filter-contradictions` subcommand) marks each pair with its substance score, and a unit test shows a same-location, different-substance pair excluded from debate.

A same-defect pair (paraphrased claims about one line) still enters debate (unit test).

`step3-debate-and-refutation.md` item 2 names the substance threshold; a conformance test pins it.

## Release Note

High-effort reviews no longer dispatch debate judges for unrelated findings that only sit near each other.
