# 6100: Move /specify planning-answer read-back and outcome selection into a tested CLI

Origin: spec #6059 review (3a convention)

Defer-reason: genuinely-larger

Evidence: ref:IL-168

## Current State

`plugin/skills/specify/planning-answer.md`'s `## Read-back and outcome` section (added by #6059, refs #6059) asks the agent to check, from prose, that `ready` and `needs:decision` match the branch taken (answered, still needs:decision, kept, re-held), that the body carries exactly one `Plan:` line equal to the printed `line`, that each resolved hold comment carries `**Resolved:**`, and then to pick one of four outcome strings and four Next Actions variants.

That is the classify / count / route-a-verdict shape `docs/donts.md`'s `[IL-168]` rule says belongs in a unit-tested `plugin/bin/` CLI: today only `tests/specify-planning-answer-conformance.test.js` string pins guard it, which check the wording, not the behaviour. The hold read (`bin/planning-hold.js`) and the plan check (`bin/plan-store.js check`) are already CLIs; the read-back assertions and outcome selection are not.

## Deliverables

1. A `plugin/bin/` CLI (or a verb on `bin/planning-hold.js`) that takes the re-fetched read-back file, the branch taken (answered / re-held / kept), the expected `Plan:` line and the resolved comment ids, and prints one JSON verdict: each assertion's pass/fail and the outcome string to render.

2. `planning-answer.md`'s `## Read-back and outcome` reads that verdict instead of applying the assertions and outcome choice from prose.

3. Unit tests for every branch: answered → ready, still needs:decision, kept, re-held, and a failed assertion.

## Acceptance Criteria

1. Each read-back assertion and the outcome choice is decided by the CLI, and a unit test fails when any one is mis-decided.

2. `planning-answer.md` names the CLI and no longer states the per-branch label assertions as prose rules.

3. `npm test` passes.

## Release Note

Answering a planning hold checks its result with a tested command rather than by reading instructions.
