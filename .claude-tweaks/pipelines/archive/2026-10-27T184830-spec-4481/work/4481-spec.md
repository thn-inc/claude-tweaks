# 4481: Write gate reads a case compound that starts a pipeline as if its cd persisted

Origin: /claude-tweaks:release v6.156.3 release-gate review (run 2026-10-27T161535-release-standalone)

Defer-reason: pre-existing-outside-diff

## Current State

Found by the v6.156.3 whole-branch release review (lenses 3b and 3c, both confirmed by independent tiebreak), refs #4303.

In `plugin/bin/lib/hooks/git-command.js`, `endCommand` keeps the start cwd for a pipeline holding a case compound only when `L.pipeStart !== null` (line 2426). When the case is the pipeline's **first** element, `pipeStart` is still null at the arm's `;;`, `caseSeen` is reset at line 2610, and at the later `|` line 2428 sets `pipeStart` to the arm's post-`cd` cwd. The pipeline then ends under that cwd alone.

Bash runs the whole case in a pipeline subshell, so the arm's `cd` is lost and a later write lands in the starting cwd. Probes of `fileWriteTargets(cmd, '/r')`:

- `case x in a) cd /wt;; esac | cat; echo x > f` → `/wt/f` only (bash writes `/r/f`); v6.156.2 reads it the same way.
- `case x in a|x) cd M;; esac | cat; echo hi > f` → `/r/M/f` only; 08983fb06 (mid-#4303) reported `/r/f` by accident.
- `cat | case x in a) cd /wt;; esac; echo x > f` → both `/r/f` and `/wt/f` (the covered later-element shape).

The policy-schema-coverage.md paragraph promises a pipeline holding a case compound "ends under both its start and the cwd the arm left, each failing closed".

A related, rarer shape: `emptyParens` (line 2104) sets `atCmd` after the empty array assignment `a=()`, so `a=() case x | cd /tmp; echo hi > f.js` reads the `|` as a pattern separator and reports `/tmp/f.js` where bash writes `./f.js` (`case: command not found`). v6.156.2 reads it the same way; the comment at line 2060 ("bash accepts no other empty `( )`") is wrong.

## Deliverables

1. A case compound that is the first element of a pipeline ends under both the pipeline's start and the cwd the arm left, as the later-element shape already does.
2. An empty array assignment (`x=()`) no longer puts the next word in command position as a reserved word, and the line-2060 comment is corrected.
3. Pin each shape in `tests/hooks-gate-coverage.test.js` with a bash 3.2 and 5 verdict comment.

## Acceptance Criteria

- `fileWriteTargets('case x in a) cd /wt;; esac | cat; echo x > f', '/r')` includes `/r/f`.
- `fileWriteTargets('case x in a|x) cd M;; esac | cat; echo hi > f', '/r')` includes `/r/f`.
- `fileWriteTargets('a=() case x | cd /tmp; echo hi > f.js', '/r')` includes `/r/f.js`.
- Each new test fails with its fix reverted.
- The scanner suites pass.

## Release Note

The worktree-always guard now blocks a write into the main checkout that follows a piped case statement whose arm changes directory.
