# 2983: Read the direction contract from Impeccable's surface brief

Surface: infra

## Overview

Read Impeccable's direction contract from where 4.2.2+ writes it — under a `## Direction contract` heading in the surface brief, read through the engine's `surface-brief read <target>` verb — instead of from the opening comment of the built artifact. Impeccable 4.4.0's `reference/new-work.md` now forbids the old location outright: "Never copy the direction contract into implementation source or any browser-delivered artifact. This includes HTML or framework comments … Reviewers and documenters receive the contract from the surface brief." So on current Impeccable, `review` mode's seed capture, its finish-reviewer gate and `/demo`'s contract section all find "no contract" every time.

The structural rules stay the same: this repo still never defines, validates or paraphrases the contract; it finds it, splits it on the five block labels (THESIS, OWN-WORLD, STORY, FIRST VIEWPORT, FORM), copies the seed key out of `FORM` as an opaque token, and hands both to a human. Only the location and the read mechanism change.

**Complexity:** Low
**Estimated tasks:** 4

## Non-Goals

- What the finish-reviewer is given or returns (the finish-reviewer sub-issue); this sub-issue only changes where the contract text comes from.
- Judging or validating the contract's content.
- Keeping the artifact-opening-comment location as a fallback: it served only installs before 4.2.2, which this migration no longer supports.
