# 1995: Subagent boundary: dispatch task prompts and review lens prompts cite composed bundles; the Subagent Contract forbids `_shared/` paths in dispatch input
Surface: backend

## Overview

Close the subagent boundary: have the orchestrator compose the bundle a dispatched agent needs *before* dispatch, and change `plugin/skills/dispatch/task-prompt.md`'s two call templates and `plugin/skills/review/step3-lens-dispatch.md`'s lens prompts to cite `{run}/context/{step}.md` paths in the dispatch prompt itself, never a `_shared/…` path. `plugin/skills/_shared/subagent-output-contract.md`'s input discipline section gains the sentence "cite the run's composed bundle, never a `_shared/` path", plus the fallback rule. Dispatch's second-call group agent (which legitimately runs whole skills inside a subagent, per #296's two-call isolation) still reads SKILL.md bodies directly — it is not switched — but reads composed bundles for everything those skills themselves cite.

**Complexity:** Medium
**Estimated tasks:** 5

## Non-Goals

- Building the enforcement gate that denies a subagent's `_shared/` reads — that is the sibling U9 record, explicitly gated on this record's own measurement first.
- Switching `dispatch/task-prompt.md`'s second-call group agent's own SKILL.md reads — those are sanctioned by #296's two-call isolation design and stay as direct reads; only the shared-contract citations *inside* the skills that agent runs switch to composed bundles.
- Editing `plugin/skills/dispatch/task-prompt.md`'s prose beyond the two call templates named here, or `review/step3-lens-dispatch.md`'s prose beyond its lens prompts.
- Resolving #1863 (design-wrapper critic prompts inline ~70 KB per critic) — same boundary, explicitly filed as a separate record; not folded in here.

## Gotchas

- Agents only see what's in their prompt — a reference to a sibling file never reaches them (the Subagent Contract's own founding premise). This is exactly why the switch matters: a dispatch prompt citing `_shared/pr-first-merge.md` sends the agent to read that whole file with both branches; citing the composed bundle path sends it to read only the resolved branch.
- #1912 and #1868 both touch `subagent-output-contract.md` — rebase this record's one-sentence addition onto whichever lands first, the same rebase discipline U2 already established for its own overlapping records.
- #1863 (design-wrapper critic prompts, ~70 KB inline per critic) is the same class of boundary violation but is filed and worked separately — do not fold its fix into this record even though the fix pattern is identical; the file it touches (`design-wrapper` critic prompts) is out of this record's Key Files.
- The measurement in this record's last Deliverable is the explicit input the sibling U9 record's go/no-go decision consumes — report the before/after numbers precisely enough (not just "reads dropped") that U9 can decide whether its own enforcement gate is still needed.
