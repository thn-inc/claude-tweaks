# 1870: release.js's install/update message should also show the /plugin slash-command form

## Current State

`plugin/bin/release.js`'s live-release success output (`bin/release.js` lines ~122-128) prints only the CLI form of the install/update commands:

```
Install/update this release from the CLI:
  claude plugin marketplace add {marketplace-repo}
  claude plugin install claude-tweaks@{marketplace-name}
```

README.md already documents the equivalent `/plugin` slash-command form (interactive Claude Code sessions use this, not a shell) verbatim:

```
/plugin marketplace add thomasholknielsen/claude-tweaks-marketplace
/plugin install claude-tweaks@claude-tweaks-marketplace
```

A user running the release from inside an interactive Claude Code session has no shell to paste the CLI form into and has to go look up the `/plugin` syntax separately.

## Deliverables

- Extend the live-release success message in `plugin/bin/release.js` to print both forms — the existing CLI block, plus a second block with the `/plugin marketplace add`/`/plugin install` equivalents, using the same already-computed `MARKETPLACE_REPO`/`marketplaceName` values.
- Cover the new output in `tests/bin-lib/release/` (or wherever the existing CLI-message assertion lives) so both blocks are pinned.

## Acceptance Criteria

- A live (non-dry-run) `node plugin/bin/release.js <minor|patch> "<summary>"` run prints both the CLI install/update block and the `/plugin` slash-command block, each with the correct marketplace repo and plugin@marketplace-name values.
- `--dry-run` behavior is unchanged (this message only ever printed on a live run).
