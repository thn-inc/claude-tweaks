# 1119: transcript-judge: promote #701's skip-before-dispatch check into the shared contract

# Reflect — staged finding 1

**Category:** tangential

## Current State

`_shared/transcript-judge.md` is the consumer-agnostic dispatch harness shared by `/feedback`
(consumer key `feedback`) and `/reflect`'s standalone singleton dispatch (consumer key `reflect`,
#857) — the file's own framing states "everything else here is consumer-invariant and moved
verbatim." #701 added a "Skip check (before dispatch)" step — backed by
`isTranscriptUnchanged()` in the already-shared `bin/lib/transcript-judge/watermark.js` — but
wrote its prose only into `plugin/skills/feedback/session-evaluation.md` (in scope for #701,
which was `/feedback`-specific by design). `/reflect`'s standalone dispatch still reads
`readWatermark`/`formatOffsetClause` from the shared contract but has no analogous "skip the
dispatch entirely when the transcript hasn't grown" step, so it still pays for a full Task-agent
judge dispatch even when nothing has changed since its last watermark — the same waste #701 fixed
for `/feedback`.

## Deliverables

- Move (or add a consumer-invariant twin of) the Skip check procedure from
  `feedback/session-evaluation.md` into `_shared/transcript-judge.md`, alongside the existing
  offset-clause mechanic, so every current and future consumer gets it without duplicating prose.
- Update `reflect/SKILL.md`'s Step 2 standalone-singleton dispatch description to reference the
  shared Skip check before its dispatch, mirroring how it already references the shared offset
  clause.
- Keep `feedback/session-evaluation.md`'s consumer-specific pieces (the `--full` bypass flag, the
  watermark payload's `sessionId`/`findingsFiled`/`issueUrls` fields) where they are — those are
  feedback-owned, not consumer-invariant.

## Acceptance Criteria

- `_shared/transcript-judge.md` documents one Skip check procedure, cited (not restated) by both
  `feedback/session-evaluation.md` and `reflect/SKILL.md`.
- A standalone `/reflect` run against an unchanged transcript (same watermark, no growth) skips
  its Task-agent dispatch, the same way a bare `/feedback` invocation does after #701.
- Existing `feedback`-specific tests (`tests/feedback-watermark-prose.test.js`,
  `tests/bin-lib/transcript-judge/watermark.test.js`) and `tests/transcript-judge-prose.test.js`
  still pass; a new test pins the shared Skip check's presence in `_shared/transcript-judge.md`
  and its citation from `reflect/SKILL.md`.
