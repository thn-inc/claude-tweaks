# 4521: Classify the agent-noun isolation refusal as a guard-refusal turn in the timing classifier

Origin: ledger resolve gate (#3819 ledger item 1)

Defer-reason: tangential

## Current State

#3819 widened the friction-event matcher (`plugin/bin/lib/hooks/harness-refusal.js`) to count the refusal a dispatched agent receives ("This agent is isolated in the worktree ... Refusing to run it"). The timing turn classifier is a separate consumer with its own copy of the pattern: `plugin/bin/lib/timing/turn-class.js` line 26 defines `GUARD_REFUSAL_RE` with the literal `This session is isolated in the worktree`, so a turn whose tool result carries the agent-noun refusal is classified by its tool instead of `guard-refusal`. Surfaced by plan review of #3819 and left out because it is a different feature (turn timing), not a friction event.

- [ ] Add a case to the turn-class tests showing an error result carrying the agent-noun refusal classifies as `guard-refusal`.
