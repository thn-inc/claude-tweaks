# 2485: wrap-up-engine.js verify: acceptance-labeling check ignores the Oversight-floor 'not required' skip

Origin: wrap-up of #2319

Defer-reason: tangential

## Current State

`bin/lib/wrap-up/engine-verify.js`'s `acceptance-labeling` check (registered ~line 450) unconditionally expects a `demo:pending` label on every resolved issue number, reporting `fail: #{n}: missing demo:pending label` when it's absent. It has no knowledge of `verification-brief.md`'s Oversight-floor gate, which legitimately skips Steps 1-4 (no `demo:pending` bootstrap) for a record whose `risk`/`size` facets don't clear the resolved `risk-floor`/`size-floor` (e.g. `risk:low` x `size:low` against the default `risk-floor: high`/`size-floor: high`) — an explicitly documented 'not required' outcome, not an error state, per that file's own text ('The record closes with no `demo:*` label and no ceremony ... It stays demoable later on request').

Observed live on run `2026-09-14T194928-record-2319` (record #2319, `risk:low` x `size:low`): `exceedsOversightFloor` correctly returned `{exceeds: false}`, Steps 1-4 were correctly skipped, and `wrap-up-engine.js verify` then reported `acceptance-labeling: fail — #2319: missing demo:pending label` — a false positive on the exact path the gate exists to support.

## Deliverables

Teach the `acceptance-labeling` verify check to recognize the Oversight-floor skip as a passing (or explicitly-skipped) state rather than a failure — e.g. by re-running (or reading a recorded result of) `exceedsOversightFloor` for each resolved issue's `risk`/`size` facets before asserting the label must be present, and reporting `skip: "below oversight floor — demo:pending not required"` when it returns `exceeds: false`.

## Acceptance Criteria

A record whose facets fail to clear the resolved risk/size floor no longer fails `wrap-up-engine.js verify`'s `acceptance-labeling` check for lacking `demo:pending`. A record that does clear the floor and still lacks the label continues to fail exactly as before. A test in `tests/bin-lib/wrap-up/` pins both branches.
