# 5049: Split docs/plugin-structure.md rows over 4000 characters so concurrent PRs stop conflicting

Origin: reflect full from #4815

Defer-reason: tangential

## Current State

`docs/plugin-structure.md` keeps each module-family row as one markdown line, and 17 of its lines exceed 4000 characters (`awk 'length>4000' docs/plugin-structure.md | wc -l` printed 17 on 2026-11-03; the `plugin/bin/lib/dispatch/` row alone is about 8.7 KB).

Git merges by line, so two PRs that each append a clause to the same row always conflict. #4815's catch-up merge of origin/main conflicted in that one row (hand-merged), and the friction events recorded against the same worktree show #4809's close-out update (PR #4917) conflicting in the same file.

## Deliverables

- [ ] Re-flow each `docs/plugin-structure.md` row longer than 4000 characters so each module entry sits on its own line (a nested bullet or a continuation line), keeping every existing fact.
- [ ] Update the tests that locate a row by its first line (for example `tests/ai-design-tells-lens-rows.test.js` and `tests/build-dispatch-subfile-table-completeness.test.js`) so they still find the entries.

## Acceptance Criteria

- [ ] `npm test` passes with no assertion weakened.
