# 6282: Pass Key Files from the remaining record-proposal producers so a run's follow-ups can be grouped by file

Surface: infra

**Related:** #5512
Risk-flags: none

## Overview

Make every remaining staged-record-proposal producer pass `keyFiles` to `specShapedBody`, so the records a run files carry a `### Key Files` section. The console-time bundler (sibling sub-issue, part of the same decomposition) groups a run's follow-up proposals by shared Key Files; a proposal with no Key Files can only ever be a singleton, so the bundler bundles little until the producers pass them. A Key Files list also lets `/build`'s micro-plan gate (condition 3) and `/dispatch`'s file-overlap grouping read the record.

#5512 (open, ready) owns `/review`'s Defer bullet and staged follow-up in `plugin/skills/review/step3-routing.md`; this record never touches that file. `plugin/skills/wrap-up/leftover-routing.md` already passes `keyFiles` (#2975). This record covers the remaining producers named in #5512's own Gotchas list, plus `plugin/skills/wrap-up/claude-md-curation.md`'s over-budget queue write (found by a repo-wide `specShapedBody` sweep at specify time).

**Complexity:** Low
**Estimated tasks:** 4

## Non-Goals

- `plugin/skills/review/step3-routing.md` (`/review`'s Defer and staged follow-up) — owned by #5512.
- Can't-tell filings composed by `plugin/bin/lib/console/finding-filing.js` — they are not bundler input (the bundler sub-issue's Non-Goals) and keep their own path.
- Any change to `specShapedBody` itself (`plugin/bin/lib/issues/record-payload.js`), to the bundler, or to grouping.
- Inventing file paths: a producer with no file in hand passes no `keyFiles`, and its record stays a singleton.
- `plugin/skills/release/disposition.md` (lines 58, 65): its Defer path composes "per `review/step3-routing.md`'s Defer bullet", so it inherits #5512's change and needs no edit here. The other `specShapedBody` mentions in `plugin/skills` (`_shared/autonomy-ceiling.md`, `_shared/deferral-gate.md`, `flow/materialize.md`, `wrap-up/review-console.md` line 123) are references, not producers (classified at specify time).
