# 1261: Materiality floor: _shared/materiality-floor.md contract, rolling digest issue, tidy digest sweep

Surface: backend

## Overview

Create the materiality floor's contract, container, and lifecycle: a new `_shared/materiality-floor.md` shared contract that routes legitimately-deferred, below-floor findings into a single rolling digest issue instead of individual first-class issues; the /tidy digest sweep that keeps the digest from becoming a graveyard (cluster promotion + expiry); and the two coherence edits the floor requires (`_shared/deferral-gate.md`'s "Bundle of small items" bullet and CLAUDE.md's "No implicit deferrals" rule). Nothing routes to the digest yet — the nine exhaust channels migrate in the follow-up sub-issue (#1262) that is blocked by this one.

Context (measured 2026-08-22; methodology in parent #1260's Overview): 512 issues opened vs 385 closed over 7 days, net +127/week, with 245 `size:low` + 194 `size:medium` vs 8 `size:high` among the week's filings. The floor attacks the birth rate at the container level. It never decides whether to fix — only which container a legitimately-deferred item lands in.

**Complexity:** Medium
**Estimated tasks:** 7

## Non-Goals

- No adopter migration — review/wrap-up/health-sweeps/visual-review/reflect keep filing exactly as today until #1262 lands. This sub-issue only creates the contract, the container lifecycle, and the coherence edits.
- No change to `_shared/deferral-gate.md`'s fix-now criteria or the closed `Defer-reason:` vocabulary — the floor applies after the gate, never instead of it. Severity remains a non-reason for skipping a fix.
- No record-schema change: claims, labels, dispatch, fast-lane, `ready` all stay per-issue.
- No change to `/capture`'s human-typed path — human input is intent, not exhaust, and never routes to the digest.
- No new `auto-decision-log` status word — digest routings log with the existing `AUTO` status (see Deliverables); `_shared/auto-decision-log.md` and `bin/lib/log-decision/append.js`'s `STATUSES` are untouched.

## Deliverables

- [ ] `plugin/skills/_shared/materiality-floor.md` — the contract, stating: (1) **position**: applied after `_shared/deferral-gate.md` — an item first attempts fix-now; only an item with a valid `Defer-reason:` reaches the floor; (2) **the floor**: route to digest only when the item would be filed `size:low` AND `priority:low` AND `risk:low` (per `_shared/work-record.md`'s scoring axes, judged at filing time; an unscored or ambiguous axis counts as NOT low, so the item files as an ordinary issue — the floor fails toward filing); (3) **overrides**: `Defer-reason: tangential` always clears the floor (ideas are intent, not residue); human-typed `/capture` input is out of the contract's scope entirely; (4) **entry format**: `- [{area}] {one-line finding} — {file refs} — Defer-reason: {value} — {provenance}` where `{provenance}` is the pipeline run-id when a run directory resolves, else the invoking skill's name — the entry itself is the durable audit trail, so a no-run-dir routing is never unlogged; (5) **container, `work-backend: github-issues`**: one pinned rolling issue labeled `digest`, one comment per run aggregating that run's below-floor items (one URL per run), lazily bootstrapped by the first writer — list open `digest`-labeled issues first, create only when none exists (label bootstrapped per `_shared/label-bootstrap.md`); a creation race leaving two open digest issues is repaired by the tidy sweep (merge the newer's comments into the older, close the newer); all writes via `_shared/github-write-transport.md`; routing appends are append-only — the tidy sweep's promotion/expiry marker edits are the one sanctioned exception; (6) **container, `work-backend: local-files`**: `specs/digest.md`, entries appended in place (single-writer backend); promotion marks the entry line with a trailing `→ {id}`, expiry moves entry lines to an `## Archived {YYYY-MM-DD}` section at the bottom of the same file — no rollover needed for a file; (7) **audit line**: when a run directory resolves, routing additionally logs `AUTO {time} — materiality-floor: {item} routed below floor ({defer-reason}) → digest. Reversibility: high (entry remains promotable or re-filable from the digest at any time).` per `_shared/auto-decision-log.md` — the existing `AUTO` status, no new status word; bookkeeping, not decision-worthy: no Review Console row per entry; (8) **expiry is not skipped work**: an expired entry already passed the deferral gate (fix-now was attempted and refused for a stated reason) and sat un-promoted for 90 days — archival is a logged retention decision reachable only through that gate, which is what distinguishes it from the silent skipping CLAUDE.md forbids; the contract states this reconciliation explicitly.
