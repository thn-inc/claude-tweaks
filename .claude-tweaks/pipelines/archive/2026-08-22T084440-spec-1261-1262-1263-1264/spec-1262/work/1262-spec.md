# 1262: Materiality floor adopters: route below-floor deferred findings from the nine exhaust channels to the digest

Surface: backend

## Overview

Migrate the nine exhaust channels to cite `_shared/materiality-floor.md` at their record-filing points, so a finding that fails fix-now, carries a valid `Defer-reason:`, and sits below the floor (`size:low` AND `priority:low` AND `risk:low`, with `tangential` always clearing) lands as one digest entry instead of a first-class issue. At-floor and above-floor findings file exactly as today. This is the sub-issue that actually changes the birth rate; the contract, container lifecycle, and coherence edits ship first in #1261, which blocks this one.

**Complexity:** Medium
**Estimated tasks:** 6

## Non-Goals

- No change to the contract itself — the floor definition, entry format, and container live in `_shared/materiality-floor.md` and are cited, never restated, per this repo's cross-reference convention.
- No change to `/capture`'s human-typed path or to `/specify` — neither is an exhaust channel (`/capture` human input is intent; `/specify` shapes and decomposes, it does not file findings).
- No change to `/feedback` — its filer is a consumer who legitimately lacks maintainer context (same carve-out #619 made).
- No change to the four health sweeps' existing dedup logic — an item matching an existing issue still updates that issue; dedup runs before the floor.

## Technical Approach

One mechanical pattern applied per filing branch, at the point each file today says "file a record" (or "stage a record proposal") for a deferred finding: insert the floor consultation as a citation ("route per `_shared/materiality-floor.md` — below-floor items become digest entries") rather than new procedure prose. Gate-cited adopters keep their deferral-gate citation untouched; the floor citation composes after it. Where a filing step is shared between staged (`staged/`) and direct-create paths, the citation covers both — a below-floor item is never staged either; it goes to digest at the same decision point. Before starting, re-read `_shared/materiality-floor.md` as shipped by #1261 for the exact entry-format and audit-line text to reference.

## Gotchas

- `code-health/SKILL.md` has ~360 bytes of ceiling headroom — measure `wc -c` before writing; if the citation cannot be net-neutral, slim adjacent prose in the same commit and re-measure. Before cutting any sentence, grep `tests/` for it — whole-file conformance tests pin prose repo-wide, and a slimmed sentence that a fixture pins fails the suite, not just the byte budget. Do not skip the citation to dodge the ceiling.
- For the four sweeps, the floor consultation must sit AFTER the existing dedup/existing-issue check — routing a duplicate to the digest would hide it from the existing issue's thread. The other six files have no dedup step; their citation sits directly after the deferral-gate outcome.
- `Defer-reason: tangential` items always file as issues regardless of scores — adopters must not shortcut to "all low scores → digest" without the override.
- The exact insertion anchors are discovered by grep at execution time — the Key Files list names files and branch intents, not line numbers; locating each filing sentence is the implementer's first task.
- Whole-file conformance tests pin prose repo-wide — run the full `npm test` before merging, not just the new suite.
