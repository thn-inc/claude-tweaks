# 4219: Explicit-list dispatch drops the first-named record when it caps to dispatch-batch-size

Origin: dispatch firing 2026-10-24T154159-dispatch-standalone (records #4026,#4028,#4032,#4029)

Defer-reason: tangential

## Current State

`selectGroupsForExplicitList` (`plugin/bin/lib/issues/grouping.js:572`) walks Step 2's `groups` array in pool order and pushes every group holding a requested number in that order. The order the records were named in is discarded, and `dispatch/SKILL.md` Step 3 says ranking never runs for the explicit-list form, so priority is discarded too.

Step 3 then caps `selectedGroups` at `dispatch-batch-size`, so which named record is left out is decided by pool order. Observed 2026-10-24: `/claude-tweaks:dispatch #4026,#4028,#4032,#4029` at batch size 3 selected #4032, #4029, #4028 and left out #4026, the first record named and the only `priority:high` one. The left-out record was not named as deferred-by-cap in the firing's report.

## Deliverables

- `selectGroupsForExplicitList` returns `selectedGroups` ordered by the earliest position any member holds in `requestedNumbers`; ties keep pool order.

- Dispatch's explicit-list cap truncates that ordered list, and every requested record left out by the cap is reported as deferred by `dispatch-batch-size`.

- `dispatch/SKILL.md`'s explicit-list paragraph states the named-order rule.

- A unit test in `tests/bin-lib/issues/grouping.test.js` pins the order with a pool order that differs from the requested order.

## Acceptance Criteria

- [ ] `selectGroupsForExplicitList([4026,4028,4032,4029], [[4032],[4029],[4028],[4026]])` returns `selectedGroups` `[[4026],[4028],[4032],[4029]]`.

- [ ] A bundle containing requested #B and #D, where the request is `[A,B,C,D]`, sorts at #B's position.

- [ ] With `dispatch-batch-size: 3`, the four-record list above dispatches #4026, #4028 and #4032, and the firing's report names #4029 as deferred by the cap.

- [ ] The new ordering test fails against the current implementation (proven by running it against `git show HEAD:plugin/bin/lib/issues/grouping.js`).
