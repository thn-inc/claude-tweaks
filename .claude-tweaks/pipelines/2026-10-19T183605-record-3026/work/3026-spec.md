# 3026: reconcile: the 18 s budget starves `reap` (dispatched last), even under an explicit `--checks` subset

Surface: infra

## Current State

On a large repo, `reconcile` never reaches `reap`, even when a caller names it explicitly with `--checks`:

- `plugin/bin/lib/reconcile/budget.js:8` sets `DEFAULT_BUDGET_MS = 18000`. `plugin/bin/lib/reconcile/index.js:242` calls `require('./budget').createBudget()` with no argument for every caller: the SessionStart hot path, the detached background pass, and the `hooks.js reconcile` CLI. The CLI forwards `checks: checksList.length ? checksList : undefined` (`plugin/bin/hooks.js:1318`) but passes no budget.
- `reap` is dispatched last on purpose, because it removes the worktrees that release/archive/archive-branches derive branches from. Once the deadline passes, the per-block over-budget guard skips every remaining check. The budget clock starts before the shared `git fetch`, and that fetch becomes a full `--prune` all-refs fetch whenever `remote-prune` is requested.
- Observed on a repo with about 26 worktrees, 74 live run dirs, 92 local branches, and 71 remote branches. Unscoped `reconcile --json` skips `archive-branches,remote-prune,reap` as `budget-exceeded`. `--checks reap,archive-branches,remote-prune` still skips `remote-prune,reap`. Only `--checks reap` on its own fits within the budget.
- At drain termination (`plugin/skills/dispatch/SKILL.md:174`), dispatch runs an unscoped `reconcile` specifically to reap this firing's merged-PR worktrees, so on a large repo that reap never happens. `tests/dispatch-drain-close-run-reconcile.test.js:37` pins the unscoped wording.
- `createBudget(ms = DEFAULT_BUDGET_MS, …)` (`plugin/bin/lib/reconcile/budget.js:14`) already accepts an override. An `undefined` argument falls back to the default, and `Infinity` never expires.

## Deliverables

1. `reconcile()` (`plugin/bin/lib/reconcile/index.js`) accepts `opts.budgetMs` and passes it to `createBudget(opts.budgetMs)`. Update the opts doc comment to list it.
2. The `hooks.js reconcile` CLI (`plugin/bin/hooks.js`) passes `budgetMs: Infinity` when `--checks` names an explicit subset, and `undefined` otherwise. Unscoped CLI runs, the SessionStart hook, and background passes keep the 18 s default.
3. Dispatch's drain-termination call (`plugin/skills/dispatch/SKILL.md`, the second `reconcile` at loop termination) becomes `reconcile --checks release,archive,reap`, with the same generous timeout as Step 1's call. Step 1's first reconcile stays unscoped.
4. Tests:
   - `tests/reconcile.test.js` gains a case showing `opts.budgetMs` reaches `createBudget` and an unbounded explicit subset is never budget-skipped.
   - `tests/reconcile.test.js` gains a case showing the CLI passes `Infinity` for `--checks` and `undefined` when unscoped.
   - `tests/dispatch-drain-close-run-reconcile.test.js` pins the new scoped termination call.

## Acceptance Criteria

- `reconcile({ checks: [...], budgetMs: Infinity })` never reports a `budget-exceeded` skip, and `createBudget` receives `Infinity`.
- `reconcile({})` with no `budgetMs` still uses the 18 s default, and the existing exhausted-budget test still passes unchanged.
- `hooks.js reconcile --checks reap --json` calls `reconcile` with `budgetMs: Infinity` and `checks: ['reap']`. `hooks.js reconcile --json` calls it with `budgetMs: undefined`.
- The SessionStart hook and the background reconcile pass still run under the default budget, with no change to their call sites.
- The drain-termination section of `plugin/skills/dispatch/SKILL.md` runs `reconcile --checks release,archive,reap` and names the same generous timeout as Step 1. Step 1's own call (`SKILL.md:106`) is unchanged and stays unscoped.
- `node --test tests/reconcile.test.js tests/dispatch-drain-close-run-reconcile.test.js tests/bin-lib/reconcile/budget.test.js` passes.

## Release Note

Fixed end-of-drain cleanup so it reliably removes merged worktrees on large repositories instead of running out of time first.

## Technical Approach

This change threads an optional budget override through to the code that creates the budget. It deliberately doesn't reorder checks or raise the global ceiling. The reporter considered and rejected two alternatives. Running `reap` first breaks release/archive/archive-branches, which derive branches from the worktrees reap removes. Using `--checks reap` alone at drain termination reaps before release/archive can join on the worktree. The ceiling exists for the SessionStart hot path, and a caller that names an explicit subset is asking for exactly those checks to run, so an explicit `--checks` is the signal to lift it. Scoping dispatch's termination call to `release,archive,reap` also avoids the `--prune` fetch, `archive-branches`, and `remote-prune` work, which that step doesn't need. The original request below carries the reporter's complete proposed diff.

### Key Files

- `plugin/bin/lib/reconcile/index.js` — `opts.budgetMs` passed to `createBudget`; doc comment updated
- `plugin/bin/hooks.js` — the `reconcile` CLI passes `budgetMs: Infinity` for an explicit `--checks` subset
- `plugin/skills/dispatch/SKILL.md` — drain-termination reconcile scoped to `--checks release,archive,reap`, with a generous timeout
- `tests/reconcile.test.js` — new budget-override and CLI-forwarding tests
- `tests/dispatch-drain-close-run-reconcile.test.js` — pin updated for the scoped termination call

## Gotchas

- An unbounded explicit subset now runs as long as its own per-call timeouts allow. Every scripted caller of `reconcile --checks …` (dispatch included) must keep an explicit, generous Bash timeout (150000 ms or more, per #1543), or the harness timeout becomes the new silent failure.
- Grep for other `reconcile --checks` call sites in `plugin/skills/**` and `plugin/bin/**` before building. Each one that relied on the ceiling to bound its runtime now gets an unbounded run.
- The reporter didn't measure exact per-check timings, because a live reconcile mutates refs and the claims registry. Verify the fix with the unit tests, not a live timing run.
- Line numbers in the original request (`hooks.js:1326-1331`) have drifted: the `checks:` forwarding line is now `plugin/bin/hooks.js:1318`. Anchor edits on content, not line numbers.

**Kind:** Defect

**Expected vs. actual:**
Expected: checks the caller explicitly names run; dispatch's termination reconcile reaps this firing's merged-PR worktrees.
Actual: step 2 skips `archive-branches,remote-prune,reap` as `budget-exceeded`; step 3 still skips `remote-prune,reap`; only step 4 (no fetch, nothing ahead of `reap`) fits.

**Root cause:** `bin/lib/reconcile/budget.js:8` sets `DEFAULT_BUDGET_MS = 18000`, and `bin/lib/reconcile/index.js:242` creates it unconditionally (`createBudget()`) for every caller — the SessionStart hot path, the detached background pass, and the `hooks.js reconcile` CLI (`hooks.js:1326-1331`, which forwards `--checks` but no budget). `index.js:249` dispatches `mirror, red-tip, console, release, archive, archive-branches, remote-prune, reap`; `reap` is deliberately last (`index.js:326-337`) because it removes the worktrees release/archive/archive-branches derive branches from. `overBudget()` (`index.js:250-255`) runs before each block and skips everything from there on once the deadline passes, and the budget starts before the shared `git fetch` (`index.js:285`), which becomes a full `--prune` all-refs fetch whenever `remote-prune` is requested. On a repo of this size the fetch plus per-run/per-branch `gh` calls exceed 18 s before `reap` is reached. Fix: (1) add `opts.budgetMs` to `reconcile()`; the CLI passes `Infinity` when `--checks` is explicit (a caller naming a subset wants those checks run; the ceiling exists for the SessionStart hot path); unscoped CLI, hook and background passes keep the default. (2) Scope dispatch's termination reconcile to `--checks release,archive,reap` — the three checks it exists for, in their required order, without the `--prune` fetch, archive-branches or remote-prune. Rejected alternatives: reordering `reap` first breaks release/archive/archive-branches (the ordering comment documents this hazard); `--checks reap` alone reaps before release/archive can join on the worktree.

- **Beneficial — step label.** Deliverable 3 / AC5.1-AC5.2 call the queue-pull reconcile (`SKILL.md:106`) "Step 1"; it sits under `### Step 2:`. The drain bullet and its pin test now say Step 2, and AC5.2 is asserted on the Step 2 slice.
