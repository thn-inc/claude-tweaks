## Gotchas

- The archive-path rule exists in only two of the three templates. Folding it into the contract makes `wrap-up/summary-template.md` cite it too. The rule is conditional (it applies only once the run dir is archived), so it is harmless where it never fires. Still, for wrap-up this is new text in effect, not a pure move. Say so in the commit.
- `ROLE_PATTERNS` holds six roles. `unlabelled` is `roleOf`'s fallback, not an entry. The set-equality assertion must add `unlabelled` explicitly or it can never pass. The prose lists roles in a different order from `ROLE_PATTERNS`, so compare as sets, not sequences.
- `TIERS` derives from `PROFILES` keys, so the test must `require` derive.js rather than hard-code `fast/standard/capable/frontier`. A hard-coded copy reintroduces the drift this record removes.
- `#3375 AC10.1` carries an absence assertion (`rendered verbatim below the Guard denials line`). Move it to the contract with its presence twin, and keep a per-template absence check so a template cannot silently regain the stale placement.
- `docs/journeys/attribute-agent-cost-to-dispatches-3375.md` describes the Dispatches output as a user would see it. It is a journey, not a restatement of the render rules, and needs no edit. The `#1929 AC5` journey pins stay as they are.
- `tests/console-resolve-conformance.test.js` pins the `Needs a human` paragraph's `console-residue.js` wording in both flow templates. Repointing the archive back-reference (Deliverable 3) must leave those pinned phrases intact.
