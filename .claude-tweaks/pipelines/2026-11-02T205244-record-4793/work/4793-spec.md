# 4793: Look up native blocked-by links from another repository by owner and name, not by number alone

Origin: SDD ruling deferred at Review Console (#4553)

Defer-reason: pre-existing-outside-diff

## Current State

`plugin/bin/lib/issues/record-dependencies.js` (`buildNativeDependencyQuery`, with the node projection at its `blockedBy(first:25){ nodes{ number state } }` selection) returns each native blocker as a number only. A blocker linked natively from another repository is therefore looked up by number in this repository.

This was harmless while the numbers only fed ordering, but #4553's `--blocker-landing` makes it load-bearing: a cross-repository native blocker can read as another repository's issue of the same number, causing a false stop or a false `landed`. The file is outside #4553's diff and `buildNativeDependencyQuery` is deliberately unchanged for its dispatch and wrap-up consumers, so the fix was deferred (#4553 final review, Minor 4).

## Deliverables

Project each native blocker's `repository { nameWithOwner }` and carry it with the number, so `--blocker-landing` and the other consumers can skip or separately resolve a blocker that is not in this repository.

Decide the verdict for a cross-repository blocker in `plugin/bin/lib/preflight-records/blocker-landing.js` (undetermined with a stated `via`, never a same-number lookup here) and pin it in the blocker-landing suite.

## Acceptance Criteria

A blocker-landing test with a native blocker whose repository differs from the run's repository does not query this repository's issue of the same number; reverting the repository check turns it red.

`buildNativeDependencyQuery`'s existing dispatch and wrap-up consumer tests still pass unchanged.

## Release Note

A cross-repository native blocker no longer causes a false stop or a false landed verdict in the blocker-landing check.

## Technical Approach

### Key Files

- `plugin/bin/lib/issues/record-dependencies.js` — project the blocker repository
- `plugin/bin/lib/preflight-records/blocker-landing.js` — handle a cross-repository blocker
