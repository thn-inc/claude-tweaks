# 3740: archive-run guard does not cover the dispatch bundle Auto-merge gate's log lines

Origin: SDD ruling ratified at wrap-up for #3668 (Minor 4 of the whole-branch review), refs #3297

Defer-reason: genuinely-larger

## Current State

#3668 made the `archive-run` verb (`plugin/bin/hooks.js`) and reconcile's clean-status sweep refuse a terminal run that has no `console.json` when its `decisions.md` carries the wrap-up auto-merge short-circuit's canonical line (`consoleReplacedByAutoMergeShortCircuit` in `plugin/bin/lib/reconcile/archive-merged.js`: `(?:Fast-lane|Manifesto-authorized) auto-merge: issue #N, assess-agent-autonomy verdict auto-merge`) and `staged/` holds pending items.

`plugin/skills/dispatch/settle-and-merge.md`'s bundle Auto-merge gate also skips the Review Console (pr-first: it merges inside the Task call, then archives through wrap-up cleanup Section B; local-merge: the dispatching session logs `Auto-merge: group [...]`), but its log lines do not match that regex. A bundle fast-lane run whose `staged/` (or `spec-*/staged/`) holds pending proposals can therefore still be archived out of sight by `archive-run`, the loss #3668 closed for the wrap-up short-circuit.

A real-input probe over `pipelines/archive` found 5 historical bundle gate runs, none with pending staged items, so no loss is observed yet.

## Deliverables

1. Extend the detector (or add a sibling beside it) so the dispatch bundle Auto-merge gate's `decisions.md` line(s) from `dispatch/settle-and-merge.md` also count as a console replaced by an auto-merge, keeping the `Review Console: terminal decision` exemption.
2. Pin the dispatch gate's log-line template(s) against the detector with a prose-code twin test: extract the live templates from `dispatch/settle-and-merge.md`, fill the placeholders, run each through the detector, and assert the exact template count, the way `tests/bin-lib/reconcile/archive-merged.test.js` does for the wrap-up templates.
3. Add an `archive-run` verb test in `tests/archive-run-verb.test.js` for a bundle run with a pending staged item.

## Acceptance Criteria

- `archive-run` on a terminal run with no `console.json`, a dispatch bundle gate line in `decisions.md`, and a non-dotfile under `staged/` or `spec-*/staged/` does not archive and names the pending items.
- The same run with nothing pending still archives, unchanged.
- A reworded dispatch log template fails the new twin test.

## Release Note

Cleaning up a finished bundle run no longer hides staged proposals nobody approved when the run never showed its review console.

## Technical Approach

### Key Files

- `plugin/bin/lib/reconcile/archive-merged.js` — extend or add a sibling detector for the bundle gate line
- `plugin/skills/dispatch/settle-and-merge.md` — read: source of the bundle gate log templates to pin
- `tests/bin-lib/reconcile/archive-merged.test.js` — twin-pin test for the bundle templates
- `tests/archive-run-verb.test.js` — bundle run with a pending staged item
