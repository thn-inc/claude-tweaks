# 3498: Consolidate isPathContained and path-guard isAncestorOrSelf into one lexical containment primitive

Origin: reflect full from #3417

Defer-reason: tangential

## Current State

Two lexical containment primitives now coexist under `plugin/bin/`. `shared-primitives.js`'s `isPathContained(candidate, root, { orEqual })` is a bare `candidate.startsWith(root + path.sep)`; `plugin/bin/lib/path-guard`'s `isAncestorOrSelf(ancestor, candidate, { pathImpl })` (added by #3417) uses `path.relative`, admits equality, tests the `..` path segment (so a child named `..foo` is contained), and takes a `pathImpl` so win32 compares case-insensitively and across drives.

`isPathContained` still has six production callers outside `shared-primitives.js`: `skill-load-report.js`, `load-delta.js`, `lib/init/release-bootstrap.js`, `lib/reconcile/reap-merged.js`, `lib/hooks/pre-tool-use.js` and `lib/hooks/worktree-reap.js`. #3417 migrated `timing/transcript.js` and `installed-plugins.js` to the path-guard form and left these alone because the spec scoped three call sites. `.claude/skills/pre-tool-use-gate-exemptions/SKILL.md` and `docs/donts.md` [IL-161] now point authors at different helpers for the same question.

## Deliverables

- Decide the single lexical containment primitive. Either `isPathContained` delegates to `path-guard`'s `isAncestorOrSelf` (keeping its `orEqual` option as a thin wrapper), or its callers migrate and it is removed.

- Migrate the remaining `isPathContained` callers, each with its existing suite unmodified, and record any caller whose behavior intentionally changes (a `..foo` child, win32 case-insensitivity) the way #3417 recorded its two.

- Update `.claude/skills/pre-tool-use-gate-exemptions/SKILL.md`'s containment bullet and `docs/donts.md` [IL-161] to name the one surviving helper.

## Acceptance Criteria

- [ ] `grep -rn "startsWith(.*path.sep)" plugin/bin` shows no hand-rolled containment test, and `isPathContained` and `isAncestorOrSelf` no longer both exist as independent implementations.

- [ ] Every migrated caller's existing test suite passes unmodified, and a characterization case pins each intended behavior change.

- [ ] `docs/donts.md` [IL-161] and the `pre-tool-use-gate-exemptions` skill name the same helper.

## Release Note

Internal hardening: plugin path-containment checks share one implementation.
