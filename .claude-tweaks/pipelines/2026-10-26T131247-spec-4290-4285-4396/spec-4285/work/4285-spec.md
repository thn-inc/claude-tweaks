## Current State

On Windows a test's fake `git`/`gh`/`node` on PATH never resolves:

- **`#!/bin/sh` stubs** (6 files). libuv tries only `name`, `.com` and `.exe`, so the real binary runs instead.
- **Symlink-only PATH** (release-preflight, `integration-model.test.js:30`). A link with no `.exe` gives ENOENT.

A `.cmd` shim fails too: libuv never tries `.cmd`, and Node refuses one without a shell (EINVAL). The precedent is a per-file `PATH_STUB_SKIP`, first in `pr-state.test.js:14` (#3506) and then in `reap-merged`/`reconcile` (#4228, PR #4272).
