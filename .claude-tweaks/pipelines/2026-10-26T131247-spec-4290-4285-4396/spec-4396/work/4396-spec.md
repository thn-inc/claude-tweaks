# 4396: Windows: residue artifacts probe reports subject and failed paths with backslashes beside its / evidence paths

Origin: SDD ruling 2 ratified at #4288's Review Console

Defer-reason: genuinely-larger

## Current State

#4288 made the artifacts probe's display IDs `/`-joined on every OS (`plugin/bin/lib/residue/probes/artifacts.js`'s `evidence` text). The same probe still builds two values with `path.join`, so on win32 they carry backslashes: a finding's `subject` (`path.join(rel, entry.name)`, near line 195) and a `failed` entry (`path.join(rel, entry.name)`, near line 187). A win32 residue line therefore shows a backslash subject next to a `/` evidence path.

#4288 left this alone on purpose (SDD ruling 2): `subject` is one of the three identity fields `plugin/bin/lib/residue/finding.js` fingerprints (`createFingerprint('residue', ['kind', 'scope', 'subject'])`), so switching it to `/` changes every win32 artifact finding's `id`. A sweep of `plugin/` at #4288 found no code that stores residue finding ids across runs, but no one has confirmed that, so the ruling kept the change out of a display-ID class fix.

## Deliverables

1. Establish whether anything persists or compares a residue finding `id` across runs: an ack or dismiss store, the wrap-up pack (`plugin/bin/lib/wrap-up/pack.js`'s `residue` probe), console or ledger files, or a test fixture pinning an id. Record the answer in the PR.

2. Emit `subject` and the `failed` entry `/`-joined (a `/` template or `toPosix`), keeping the fs paths the probe reads native, per the windows-checkout-test-parity skill's display-ID rule.

3. If step 1 found a persisted id, migrate it: accept both the old and new id for one release, with a recorded removal condition. Otherwise, say in the PR that no migration is needed.

## Acceptance Criteria

- [ ] A test that passes a win32-shaped relative root pins `subject` and the `failed` entry with `/` separators.

- [ ] The PR states, with the grep it ran, whether any consumer persists residue finding ids, and either ships the migration or says none is needed.

- [ ] The `tests/bin-lib/residue/` suites pass on ubuntu, and a `windows-regression.yml` dispatch on the branch shows no newly failing residue test file.

## Release Note

On Windows, the close-time residue report names stale artifact directories with `/` separators, matching the rest of the line.
