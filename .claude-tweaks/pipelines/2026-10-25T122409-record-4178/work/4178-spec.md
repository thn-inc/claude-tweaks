## Deliverables

1. Find the call path that committed `[reconcile] archive run …` into a linked worktree: check every caller of the archive-run commit (`archive-merged.js:1379` and any other `commitGit` site with that subject) for a `root` taken from cwd or the run dir's checkout rather than `mainCheckoutRoot`.
2. Route that path's commit to the main checkout, or refuse to commit when the resolved root is a linked worktree, logging the skip so the next pass in the main checkout archives it.
3. A test that runs the archival with cwd inside a linked worktree and asserts the worktree branch gains no commit.

## Acceptance Criteria

- Archival run from a session whose cwd is a linked worktree leaves that worktree's branch HEAD unchanged (test asserts `git rev-parse HEAD` before == after).
- The same archival either lands on the main checkout's branch or is skipped with a logged reason; it is never silently dropped.
- The new test fails against the pre-fix code.
