**Decision (plan review, Deliverable 2, 2026-11-16).** Reading A. The revert command a user is told to run is printed by `plugin/bin/console-resolve.js` (line 687), and that printed command is the defect: `git apply` honours `core.autocrlf` even outside a repository, so the revert restores CRLF. `plugin/bin/console-resolve.js` joins the Key Files, and the printed command becomes `git -c core.autocrlf=false apply -R --unidiff-zero {patch}`. The test's revert helper runs the same command the CLI prints, read from one constant, so the two cannot drift.
