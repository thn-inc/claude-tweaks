## Current State

`tools/upstream-drift/manifest.yml` pins `impeccable-plugin` at 4.0.2, and `plugin/skills/design-wrapper/impeccable-plugin.md` carries the matching `<!-- upstream-pin: impeccable-plugin@4.0.2 -->`. The maintainer machine's plugin cache holds 3.0.6, 4.2.2, 4.3.1 and 4.4.0 (enabled at user scope: 4.4.0) and no 4.0.2, so `checkVersion` reports `breach` and three tests in `tests/impeccable-plugin-contract.test.js` fail on every local `npm test`: "the installed plugin matches the pinned version", "gatherSignals() executes cleanly and returns the documented shape" and "the CLI entrypoint accepts no flags". CI has no Impeccable install, so the same tests skip there as `absent`.

Every local run since the pin fell behind reports these 3 failures, which each pipeline run has to re-diagnose as environmental (the #2827/#2828 run logged them as its ledger item 1). Related: #2531 provisions sandbox plugin caches at whatever the pin is; this record moves the pin itself forward to the version maintainers run, so the two are complementary.
