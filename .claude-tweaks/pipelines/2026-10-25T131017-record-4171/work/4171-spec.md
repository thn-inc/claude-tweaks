# 4171: Surface can't-tell tiebreak findings on the fast-lane auto-merge path, which renders no Review Console

Origin: build final whole-branch review of #3949 (declined to judge: pre-existing, outside the spec)

Defer-reason: genuinely-larger

## Current State

The wrap-up auto-merge short-circuit (`plugin/skills/wrap-up/auto-merge-short-circuit.md`, and the manifesto-authorized variant) merges without rendering a Review Console and writes no `console.json`; its FYI omits the Low-confidence and Contested sections.

#3949 made every can't-tell tiebreak finding a console item (`tiebreak:{id}` in `plugin/bin/lib/console/resolve.js`, filed at `unattended` by `plugin/bin/console-filings.js`). On the short-circuit path no console runs, so a can't-tell finding with no staged file is never filed, and `plugin/bin/lib/reconcile/archive-merged.js` archives the run (console state `none`, nothing in `staged/`). The finding then survives only in an archived `decisions.md`. Legacy coordination items had the same exposure before #3949.

## Deliverables

- [ ] The auto-merge short-circuit resolves the run's finding items the same way the console does: it runs `console-filings.js` (dedup against `--state all`) and files each can't-tell finding through the queue-write path, or refuses the short-circuit while a can't-tell finding exists.
- [ ] The short-circuit's FYI lists the Low-confidence / Contested findings and the "Dropped by tiebreak" block.

## Acceptance Criteria

1. A fast-lane run whose decisions.md holds a tiebreak `console` verdict and no staged file never archives with that finding unfiled: either a record exists for it (fingerprint-deduplicated) or the run is refused archival with a named reason.
2. The short-circuit's FYI names every can't-tell finding.
3. `npm test` passes.

## Release Note

Can't-tell review findings are no longer lost when a run merges through the fast-lane auto-merge path.

## Technical Approach

### Key Files

- `plugin/skills/wrap-up/auto-merge-short-circuit.md` — resolve finding items before merging
- `plugin/bin/lib/reconcile/archive-merged.js` — guard the none-console archive path
