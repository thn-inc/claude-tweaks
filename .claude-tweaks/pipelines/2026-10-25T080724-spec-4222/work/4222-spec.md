# 4222: Windows: #3064 stale-worktree test expects a native path where git prints forward slashes

**Related:** #3064, #4177, #2767

## Current State

`tests/bin-lib/verify/cli.test.js:3425` ("--baseline: a stale ct-verify-base-* scratch worktree from an earlier interrupted run is named on stderr, and left alone (#3064)") is the one remaining Windows failure in that file: windows-regression run 40169646104 on `main` `6a41ebe3a` reports 192 tests, 187 pass, 1 fail, 4 skipped.

`plugin/bin/verify.js:437` names each stale worktree by the path `git worktree list --porcelain` reports. Git for Windows prints that path with forward slashes, so the message reads `D:/a/_temp/ct-verify-base-OKntAA/wt`. The test builds its expected string from `path.join(staleParent, 'wt')`, the native `D:\a\_temp\…\wt`, so `stderr.includes(...)` is false on win32 only. The production message is correct: git accepts that spelling in the `git worktree remove --force` command the message prints.
