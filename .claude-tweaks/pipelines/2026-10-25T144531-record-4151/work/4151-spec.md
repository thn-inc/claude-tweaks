# 4151: release Step 0 run-dir adoption guard is an inline node -e in prose and adopts when it crashes

Verified-as-of: 1813941ecfe019b89307ea75526f2c863ffb5e1e

Origin: /claude-tweaks:release v6.153.0 release-gate review (staged/review-3.md, run 2026-10-24T152958-release-standalone)

Defer-reason: pre-existing-outside-diff

## Current State

`plugin/skills/release/SKILL.md:59` refuses a terminal or `createdBy: release-standalone` run directory with a ~600-char `node -e` that `require`s `bin/lib/hooks/run-integrity.js#NON_TERMINAL` by path and hard-codes the `createdBy` literal. That is a second adoption decider outside `hooks.js resolve-run-dir`, whose step 2 still skips only `interrupted` (`plugin/bin/lib/hooks/run-dir-resolve.js:93`), so no other `--spec-slug` caller gets the #3898 guard. The probe exits 1 both for "not refused" and for any crash (unreadable or corrupt `run-state.json`, failed require) under `2>/dev/null`, so a guard crash silently adopts a prior release directory, which is exactly the #3898 bug. Observed in the v6.153.0 release run: an installed build predating #3898 adopted `2026-10-21T194624-release-standalone`.

## Deliverables

1. Move the terminal-status and `createdBy` refusal into `resolve-run-dir`'s step 2 (`run-dir-resolve.js`), so every caller gets it.
2. Treat an unreadable or unparseable `run-state.json` as "refuse adoption", never "adopt".
3. Replace the `node -e` in `release/SKILL.md` Step 0 with the CLI call alone.
4. Tests for refuse-terminal, refuse-release-standalone, refuse-on-corrupt-state.

## Acceptance Criteria

- `resolve-run-dir --spec-slug release` never returns a terminal or `release-standalone` directory, and never returns one whose `run-state.json` cannot be parsed.
- `release/SKILL.md` contains no inline `node -e` adoption probe.
- `tests/release-run-dir-lifecycle-conformance.test.js` is updated to the new contract.
- `npm test` passes.

## Release Note

A release run can no longer adopt a previous release's run directory when that directory's state file is unreadable.

## Technical Approach

### Key Files

- `plugin/bin/lib/hooks/run-dir-resolve.js` — adoption refusal in step 2
- `plugin/skills/release/SKILL.md` — drop the inline guard
- `tests/release-run-dir-lifecycle-conformance.test.js` — contract update
