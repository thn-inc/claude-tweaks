# 4794: Host-qualify the origin-derived repo slug so a GHE origin's reconcile and claim-store gh calls reach the origin's host

Origin: ledger resolve gate (wrap-up of #4505)

Defer-reason: genuinely-larger

## Current State

#4505 put every `gh` spawn in `plugin/bin` behind `ghOptions` (`plugin/bin/lib/repo-resolve.js`), which injects `GH_HOST` for a GitHub Enterprise origin. Decision Q2 (Reading A) left one class unchanged: a bare `--repo owner/repo` slug derived from origin (not typed by the user) means github.com, because the slug carries no host.

`repoSlugOf` (`plugin/bin/lib/hooks/git-exec.js:207`) drops the host. Its callers in `plugin/bin/lib/reconcile/` (`archive-merged.js`, `release-merged.js`, `reap-merged.js`, `post-merge.js`, `pr-state.js`) pass that bare slug to `gh --repo` and to `repos/${slug}/…` API paths, and `plugin/bin/lib/issues/claim-store.js`'s `openPrListArgs` (`--repo ${owner}/${repo}`) does the same. On a GHE origin those calls therefore still go to github.com. The slug also feeds slug comparisons across the reconcile family, so host-qualifying it touches unrelated systems (ledger row 2 of `docs/plans/2026-10-31-gh-host-seam-ledger.md`).

## Deliverables

- [ ] Make the origin-derived slug carry its host off github.com (`repoSlug`-style `host/owner/repo`), or add a host-aware sibling of `repoSlugOf`, and move the reconcile callers and `claim-store.js` onto it.

- [ ] Keep every slug comparison and every `repos/…` API path consistent with the new spelling, so a github.com origin stays byte-identical.

- [ ] Extend `tests/gh-host-seam-behavior.test.js` with a GHE-origin case per migrated caller.

## Acceptance Criteria

- [ ] With a `*.ghe.com` origin and no `GH_HOST` exported, a reconcile pass and `stale-claim-pr.js` send every `gh` call to the origin's host (asserted through a recording runner, not by reading the source).

- [ ] With a github.com origin, the argv and env of every migrated call are byte-identical to today's.

- [ ] `node --test tests/gh-host-seam-behavior.test.js tests/gh-host-seam-conformance.test.js` passes.

## Release Note

Reconcile and claim-store `gh` calls now reach the right host when your origin is a GitHub Enterprise server.

## Technical Approach

### Key Files

- `plugin/bin/lib/hooks/git-exec.js` — host-qualify or replace `repoSlugOf`
- `plugin/bin/lib/issues/claim-store.js` — `openPrListArgs` and its callers
- `plugin/bin/lib/reconcile/release-merged.js` — migrate to the host-aware slug
- `plugin/bin/lib/reconcile/post-merge.js` — migrate to the host-aware slug
- `plugin/bin/lib/reconcile/pr-state.js` — migrate to the host-aware slug
- `tests/gh-host-seam-behavior.test.js` — GHE-origin cases per migrated caller
