## Current State

`plugin/bin/check-artifact-overwrite.js` (`bin/lib/flow/artifact-overwrite-check.js`) is the multi-spec HARD-GATE run before the consolidated Review Console. It clears a later commit's deletions on another spec's journey/story file only by two tests: same-spec self-edit (`git blame` to the same `refs #N`) or list reflow (every deleted line a `- ` entry). A content-preserving markup conversion passes neither.

In run 2026-10-16T173115-spec-2702-2727-2776, review lens 3a found this run's three journeys used numbered-list steps instead of the canonical `### N.` step headers (`_shared/diataxis-genre-templates.md`). The fix commit `80e3dad2d` (refs #2776) converted all three. The gate flagged the #2702 and #2727 journeys as overwrites, even though both files are identical once step markup is normalized. Clearing it took a manual normalization script and a human HARD-GATE ruling.
