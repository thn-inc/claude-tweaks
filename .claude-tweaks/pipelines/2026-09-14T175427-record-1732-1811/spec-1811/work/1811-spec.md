Why they stick, from the sweep's own code (`archive-merged.js` `archiveMerged`, the `decideArchive` lead-in around the `#1684` comment): the merged-PR archive path needs a branch, resolved from a live worktree entry or `fallbackBranch` (`run-state.json`'s `pr.branch`, or a `decisions.md` PR-early lifecycle line). Every one of these runs predates #1672's `pr.branch` stamp, their worktrees were reaped, and their head branches were deleted after merge, so no branch resolves. The `#1962` by-number probe that follows covers only a *stamped* worktree that is gone (`no-branch`) and only a CLOSED-unmerged PR; a run with no worktree stamp at all (`no-worktree`: 872, 605, 1378-816) never reaches it, and a MERGED PR is explicitly left to "the merged path below", which is the branchless dead end. The `#1673` shipped-unclosed intercept (`isAbandonedInterrupted` + `checkRunIntegrity`) should have caught 1315/1292/1179, but with no derivable branch `checkRunIntegrity` cannot answer `shipped-unclosed`, so they fall through too. 1378-816 has no `run-state.json`, so `iterRunDirsWithState` treats it as non-terminal forever and nothing archives it. Meanwhile `trackStuckSkip` escalates each directory independently, producing seven near-identical records for one cause.

## Technical Approach

Work inside `archive-merged.js`'s existing gate order: the by-number probe already exists for the CLOSED case, so lift it out of the `stampedWorktree &&` guard and add a `MERGED` arm that reuses the merged path's reachability check (`git merge-base --is-ancestor <mergeCommit> <integration-branch>`), falling back to `local-behind-merge` when the local mirror hasn't caught up. For the no-`run-state.json` shape, add a small predicate beside `isOrphanedMint` that parses the slug's record numbers and checks their state through the same `gh` seam the by-number probe uses, so the test can inject it. For escalation, keep `cache.js`'s consecutive-count machinery and change only `escalate-residue.js`'s filing side: search for an open record carrying the `structurally-stuck` marker, append paths as a comment when found, create once when not. Do the manual archival first, as its own commit, so the seven records can close independently of the code change.

## Gotchas

- `archive-run` commits the whole staged index when a tracked `work/` subtree moves — check `git status` is clean before each manual archival, and push `main` from a worktree afterwards under `worktree-always`.
- Archiving `2026-08-26T195025-record-605` must not touch the live `record-605` run or its claim; they are different directories with the same record number.
- `iterRunDirsWithState` skips `status: clean`, so the no-`run-state.json` predicate must write a terminal state into the archived copy or the directory re-enters the scan from `archive/` lookups that read state.
- A MERGED PR whose merge commit is not yet reachable locally is `local-behind-merge`, not stuck — do not archive on the GitHub state alone.
- The consolidated escalation changes the shape of the auto-filed record that `/claude-tweaks:tidy`'s Step 4.8 and `/help` read as `by:*`-less residue; keep the fingerprint marker so dedup still works.
