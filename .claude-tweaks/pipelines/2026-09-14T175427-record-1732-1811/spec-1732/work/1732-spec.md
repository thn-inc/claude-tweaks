# 1732: archive-merged.js: consolidate 4 bolted-on lifecycle-detection mechanisms

Surface: infra
Blocked by #1734: `isStaleDir(dir, ttlMs, now)` is the primitive the classifier is written against

## Current State
`plugin/bin/lib/reconcile/archive-merged.js` is 1061 lines (up from ~500 when the merged-PR archival was its only job) and `archiveMerged()`'s main loop now runs five independent lifecycle detectors as consecutive early-return branches, each a top-level function with its own TTL constant and its own evidence read:

| Detector | Evidence | TTL |
|---|---|---|
| `isOrphanedMint(dir)` | dir mtime | `ORPHAN_MINT_TTL_MS` (24h) |
| `isAbandonedInterrupted(runDir, state, sessionId)` | `run-state.json` status + `events.jsonl` last own event | `STALE_INTERRUPTED_TTL_MS` (= 24h) |
| `isAdHocStandaloneSuperseded(dir, state, worktrees)` | dir mtime + worktree gone | `ADHOC_SUPERSEDED_TTL_MS` (30d) |
| `isStructurallyStuck(dir, reason)` | dir mtime, gated on a skip reason in `STRUCTURALLY_STUCK_REASONS` | `STRUCTURALLY_STUCK_TTL_MS` (7d) |
| `decideArchive(prState, consoleState)` | PR merged + console state | none (pure) |

Three of the five repeat the same `fs.statSync(dir).mtimeMs` / catch-to-false / `(now - mtimeMs) > TTL` stanza (#1734 extracts that primitive as `isStaleDir`); the fourth reads `events.jsonl` twice (#1737). The loop body interleaves each detector's decision with its own archive action (`archiveOrphanedMint`, `archiveRunDir`, the stuck-skip `trackStuckSkip`), `dryRun` short-circuits, and `skipped`/`archived` bookkeeping, so a fix to the staleness logic (ctime instead of mtime, clock-skew tolerance, a shared "is this dir mine" exemption) lands in three or four places or not at all. `iterCleanRunDirs()`'s second loop (#1733) copies the merged-PR branch once more.

## Deliverables

## Technical Approach
Consolidate the *decision*, not the *actions*: the archive actions genuinely differ per kind (`archiveOrphanedMint` handles the no-run-state twin, `archiveRunDir` moves work files and reverts on failure, structurally-stuck only tracks a skip), so the table keeps them separate and the classifier is the only thing that knows about time. Land after #1734 so the classifier is written against `isStaleDir` from the start rather than carrying a fourth copy of the stanza for one commit. #1737's single-read change slots into the `abandoned-interrupted` evidence read and can land before or after; #1733's iterator generalization touches the same loop and must be sequenced (either order), never built in parallel with this record.

## Gotchas
- `isAbandonedInterrupted` has a call-site companion gate (`checkRunIntegrity`'s `shipped-unclosed` evidence) that is not part of the predicate; the classifier must keep that gate at the call site, not fold it into the kind, or the `explicit: true` archival path loses its justification.
- `isAdHocStandaloneMint` (a shape check, no TTL) is deliberately exempt from the orphan sweep per the comment above it; it is an input to the classifier, not a kind.
- The merged-PR path depends on `prState` from the reconcile cache and `consoleState` from `readConsoleState`; the classifier takes both as inputs so it stays I/O-free apart from the stat and the events read.
- Size is `high` for the review surface, not the diff: the main loop's comments carry the rationale for each branch (`explicit: true`, the invisible-run trap, the never-sweep-a-live-ad-hoc-session note) and every one must survive the move into the table.
