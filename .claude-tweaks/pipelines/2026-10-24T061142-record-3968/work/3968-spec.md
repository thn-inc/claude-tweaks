# 3968: Init template cites a repo-relative plugin path in the Integration model paragraph

Origin: reflect light from #3859

Defer-reason: tangential

## Current State

`plugin/skills/init/claude-md-template.md`'s `## claude-tweaks Pipeline` section (added by #3859, PR #3966) opens its **Integration model** paragraph with the path `plugin/skills/_shared/integration-model.md`. That path is valid inside this repo, where the paragraph was copied from CLAUDE.md, but the template is what `/init` writes into consumer projects, and a consumer project has no `plugin/skills/` tree: the plugin is installed under the Claude Code plugin cache. Every other plugin file the same section cites is plugin-relative (`_shared/pr-first-merge.md`, `specify/SKILL.md`, `frontend-detection.md` in the design-wrapper skill's directory), so this one reference is the odd one out and points a consumer's agent at a file that does not exist.

`checkConformance` (`plugin/bin/lib/init/claude-md-conformance.js`) compares the section body byte-for-byte after `.trim()`, so the template and this repo's CLAUDE.md must change together.

## Deliverables

- In `plugin/skills/init/claude-md-template.md` and in CLAUDE.md's `## claude-tweaks Pipeline` section, change the Integration model paragraph's citation from `plugin/skills/_shared/integration-model.md` to the plugin-relative `_shared/integration-model.md`, keeping the two sections byte-identical.
- Confirm the live conformance test added by #3859 (`tests/bin-lib/init/claude-md-conformance.test.js`) still passes, and grep the repo for any other consumer-facing template text that cites a `plugin/skills/` path.

## Acceptance Criteria

- `grep -n 'plugin/skills/' plugin/skills/init/claude-md-template.md` finds no citation of a plugin file in text written into consumer projects.
- `node --test tests/bin-lib/init/claude-md-conformance.test.js` passes, so CLAUDE.md and the template still agree.

## Release Note

No user-visible change beyond the generated CLAUDE.md citing a path that resolves for the consumer.
