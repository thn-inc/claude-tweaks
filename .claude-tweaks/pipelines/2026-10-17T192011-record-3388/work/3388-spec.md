# 3388: engine-verify tests: probe checks registered via registerCheck leak into every later runVerify call

Origin: reflect light from #3373

Defer-reason: tangential

## Current State

`tests/bin-lib/wrap-up/engine-verify.test.js` has three probe tests that call `registerCheck` (`plugin/bin/lib/wrap-up/engine-verify.js`, module-level `CHECKS` array): `__test-exitcode-probe__` (always `fail`, ~line 381), `__test-throwing-check__` (~line 1750), and `__test-null-guard-probe__` (~line 1814). None unregister their check, so every `runVerify` call after them in the same file carries that check permanently, and any later test that needs `exitCode === 0` must be placed before the forced-fail probe. Three comment blocks in the file (~lines 137, 195, 336) already exist only to explain why a test sits before the probe. During #3373 the implementer had to reason about this ordering to place the AC1 exit-0 test, and a future test appended at the end of the file that asserts a clean exit fails for a reason unrelated to its own subject.

## Deliverables

Make check registration in `engine-verify.js` removable for tests: `registerCheck` returns an unregister function (or add an exported `unregisterCheck(name)`) that removes the entry from `CHECKS`. The production registration path stays unchanged.

Update the three probe tests to unregister their check in a `finally` block, so the registry is restored after each probe.

Delete the ordering-workaround comments that only exist because the probes leaked, keeping any comment that carries other rationale.

## Acceptance Criteria

After each of the three probe tests runs, `runVerify`'s returned rows no longer include that probe's check name.

A new test appended at the end of `engine-verify.test.js` that builds a clean fixture asserts `exitCode === 0` and passes.

`node --test tests/bin-lib/wrap-up/engine-verify.test.js` passes with the tests in any order relative to the probes.

## Release Note

Internal test-suite hardening: wrap-up verify's probe tests no longer leak checks into later tests.
