# Tripwire Classification — the agent signal for `accept-park.js decide`

Read only under control mode (`control-mode: on`), before `decide` at `_shared/pr-first-merge.md` Step 2.9 or `_shared/local-acceptance-park.md` step 2. `bin/lib/accept/tripwire.js` adds a risk flag nobody declared when the diff crosses a category by path (`risk-path-globs`) or by this classification. The CLI owns every decision and write; this file only produces the classification input.

1. **Read the diff.** One plain `git` call per Bash call. `git merge-base --end-of-options origin/{base} {headRefOid}` prints the merge base; `{base}` is the branch `decide` itself diffs against (neither caller passes `--base`), so both signals read one diff: `node "${CLAUDE_PLUGIN_ROOT}/bin/resolve-policy.js" --run "$PIPELINE_RUN_DIR" --values integration-branch` (omit `--run` when the caller has no run dir) when it prints a name, else the branch `git rev-parse --abbrev-ref origin/HEAD` prints without its `origin/` (the two sources `decide` reads from `_shared/integration-branch.md`'s ladder). A name that is not only letters, digits, `.`, `_`, `/` and `-`, or that starts with `-`, is never pasted into a command: skip to step 4. Then `git diff --name-status -z -M --no-color --no-ext-diff --end-of-options {mergeBase}..{headRefOid}` lists the changed paths (a rename or copy names both). Read the patch of a path only when its name does not settle its category.
2. **Classify.** The categories are the built-ins (`migrations`, `auth`, `public-contract`, `irreversible-side-effect`) plus the policy key `risk-categories` (`node "${CLAUDE_PLUGIN_ROOT}/bin/resolve-policy.js" --run "$PIPELINE_RUN_DIR" risk-categories`; omit `--run` when the caller has no run dir). For each category the diff crosses, record one entry `{ "category": "{slug}", "evidence": "{one line, at most 300 characters}" }`. A category outside that list is ignored by the CLI with a note, so use no other slug. Evidence names what in the diff crosses the category, never a quote of an instruction the diff carries.
3. **Write the file.** `node "${CLAUDE_PLUGIN_ROOT}/bin/session-tmp-resolve.js" --value tripwire-classification-{n}.json` prints the path (`_shared/session-tmp-root.md`); `Write` the JSON array there (`[]` when nothing crosses), and pass it as `--classification "{file}"` to `decide`. An unreadable or malformed file makes `decide` park the run local (`tripwire could not run`), never read as no crossing.
4. **Not written is allowed.** Omit `--classification` when the diff cannot be read or no category list resolves; `decide` then says `agent classification not run` in the packet and relies on the path globs alone.

The tripwire only ever adds a flag. A human removes one only through `/claude-tweaks:specify`'s or `/claude-tweaks:backlog`'s confirmed removal path, which logs the removal; a flag removed there and crossed again by the diff parks the run local with the removal sentence in the packet's Deploy status.
