# Step 3 Tier Variants and Single-Read Degrade — /claude-tweaks:review

Read from `step3-lens-dispatch.md` only when the resolved `review-effort` tier is `low`, `xhigh` or `max` (its tier-variants pointer); when a lens falls back to single-read coverage — a reproduction-pair partner dies on a session limit, or a lens agent is unavailable or times out (its partner-death pointer, Foreground note, and hung single-read agent rule); or when its Step 3-start no-`Agent` probe finds none. `review-summary-template.md`'s Coverage caveat and Independence slots, `step3-routing.md`'s low-tier source, `dispatch/task-prompt.md`'s item 7, `flow/context-handoff.md`, and `assess-agent-autonomy/merge-check.md`'s Independence floor cite it for those same cases. A `medium` or `high` review whose lens agents all return never reads it.

## `low` tier

**No executable content (`low` only).** At `low`, 3b and 3c are not dispatched when the diff ships nothing executable: every changed file is markdown or plain text, no changed line sits inside a fenced code block, and no changed line gives the reader a command to run (`node -e …`, a `git`, `gh`, or other shell invocation). A single such line keeps both lenses in scope, and so does any changed source, test, script, or config file. Log `SKIP {HH:MM:SS} — Step 3 lenses 3b, 3c (skipped): diff ships no executable content ({N} prose files) → acceptance criteria checked directly. Reversibility: n/a.` The line is executable content, not file type: #2684's markdown shipped a `node -e` snippet and lens 3c found a real bug in it, while #2685, a prose-only ADR, had nothing for either lens to read.

**Low-tier single-read dispatch (`low` only).** At `low`, the reproduction mechanism does not run at all — dispatch **one** agent per in-scope lens (3b, 3c), not a pair. This is not "reproduction with N=1" (Mode 1 in `_shared/multi-agent-coordination.md` is N=2 always when it runs); it is the tier's economy trade, halving the cheapest tier's fixed cost. Every finding a single-read agent returns enters as `unconfirmed` and goes to the tiebreak (`step3-tiebreak.md`). Log `STAGED {HH:MM:SS} — Single-read (low tier): lens "{lens}" finding {path}:{line} unconfirmed; handed to the tiebreak. Reversibility: high.` The correlated-misread protection a pair provides is deliberately traded away here; a review that warrants that protection warrants `medium` or above (Step 2.5's ambiguity rule already never defaults to `low`).

## `xhigh` and `max` tiers

At `xhigh` and `max`, append the resolver's `effortLine` output to each dispatched lens's prompt, after the Output Format block (do not modify the CALIBRATION block itself — it stays byte-identical across all tiers, per `step3-lens-dispatch.md`'s "Per-lens Calibration + Output template" section): resolve the lens's profile per the composed review-dispatch bundle's (or, standalone, `_shared/subagent-dispatch-core.md`'s) Model Selection dispatch procedure and append the returned `effortLine` verbatim — shape `[Effort: {level} — apply {level}-level reasoning depth to this task.]`. This is still a best-effort prompt-level nudge, not a verified change to the dispatched agent's actual reasoning depth — `step3-lens-dispatch.md`'s lens-scope table is the load-bearing mechanism — but it is now the resolver's own honest statement of effort rather than a hand-written sentence, so it never drifts from what the resolver actually returned.

## Reproduction-pair partner death

> **Reproduction-pair partner dies or is unavailable.** When one agent in a reproduction pair terminates early on a session/usage limit (the `Agent terminated early due to an API error: You've hit your session limit` signature), retry that one agent once; unavailable or timed-out lens agents (`step3-lens-dispatch.md`'s Foreground note) get no retry. If the retry fails the same way, treat the surviving partner (with none, the reviewer's own read) as a Low-tier single read for that lens only — its findings enter `unconfirmed` until Step 3.7's tiebreak settles them, never `confirmed` on one read alone. Log `STAGED {HH:MM:SS} — Reproduction: lens "{lens}" {session limit twice | unavailable | timed out}; single-read coverage. Reversibility: high.` to `decisions.md`, plus the low-tier per-finding `unconfirmed` line for each of its findings, and carry a one-line coverage-caveat into the Step 7 summary and the PR verdict comment naming the affected lens.
