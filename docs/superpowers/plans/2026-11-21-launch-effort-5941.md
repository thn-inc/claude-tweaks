# Launch Effort (#5941) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Under a new policy value `model-effort: profile`, the effort the profile resolver returns is set on the agent launch itself (the Agent tool's `effort` parameter), and this repository opts in with Standard and Capable at `medium`.

**Architecture:** `resolve()` gains one output field, `launchEffort` — the final resolved `effort` under `profile`, `null` under `inherit` (the default). The contract's Dispatching paragraph and every skill that restates the launch instruction tell the dispatcher to copy it into the Agent tool's `effort` parameter, with three exemptions. `dispatch-prompt.js`'s envelope and dispatch's first-call log line carry the value so a run's `decisions.md` shows what each first call ran at.

**Tech Stack:** Node 18+ CommonJS, `node --test`, markdown skill prose.

**Spec:** `.claude-tweaks/pipelines/2026-11-21T171056-spec-5941-5942/spec-5941/work/5941-spec.md` (record #5941)

## Global Constraints

- Policy key name: `model-effort`. Values exactly `inherit`, `profile`. Default `inherit`. Read from `.claude-tweaks/policy.yml` only, through `parsePolicyModelConfig`, like the other model keys; a run's `config.yml` is never read for it.
- `launchEffort` is `null` or one of `low`, `medium`, `high`, `xhigh`, `max` (`EFFORT_SCALE`), nothing else.
- A `model-effort` value other than `inherit`/`profile` makes `resolve()` throw `unknown model-effort "{value}"` — no fallback to `inherit`.
- Under both values, `model`, `effort`, `source` and `effortLine` are exactly what they are today. `effortLine` is not removed.
- `PROFILES` (the shipped table) does not change (`tests/bin-lib/model-profiles/table-pinning.test.js`).
- `plugin/skills/dispatch/task-prompt.md` is 45,859 B against the 52,500 B rail: one sentence per Task call, no more. `plugin/skills/_shared/policy-schema.md` is 51,537 B: it gets a key-only row (`| \`model-effort\` |`) and the full row goes in `plugin/skills/_shared/policy-schema-model-profiles.md`.

Task 4's edit to that file must be byte-neutral or smaller overall.

- Read `.claude/skills/policy-key-addition/SKILL.md` before Task 1 and `.claude/skills/skill-prose-conformance-tests/SKILL.md` before Task 4.

## Review Focus

1. `model-effort: profile   # note` (trailing spaces and a comment) must resolve as `profile`, as the other flat model keys do — Task 1 test `model-effort tolerates a trailing comment`.
2. A capable request under `model-effort: profile` clamped by the diff ceiling (`--diff-facts` tiny diff) must report `launchEffort` equal to the clamped `effort` (`high`, the standard row), not the pre-clamp value — Task 1 test `launchEffort follows the diff ceiling`.
3. A session-failure step-down to `fast` (failedModels holds `sonnet` and `opus`) must yield `launchEffort: null`, since Fast has no effort — Task 1 test `launchEffort is null after a step-down to fast`.
4. `--stance max-rigor` lifts `high` to `xhigh`; `launchEffort` must be `xhigh` (the platform accepts it on sonnet and opus — probe, Task 6) — Task 1 test `launchEffort follows max-rigor`.
5. `model-effort: Profile` (wrong case) must throw, not resolve — Task 1 test `model-effort is case-sensitive and closed`.

```js
const EFFORT_LINE = (e) => `[Effort: ${e} — apply ${e}-level reasoning depth to this task.]`;
test('unset key leaves the four existing fields byte-identical', () => {
  const before = { fast: ['haiku', null, ''], standard: ['sonnet', 'high'], capable: ['opus', 'high'], frontier: ['fable', 'high'] };
  for (const [p, [model, effort]] of Object.entries(before)) {
    for (const policy of [{}, { 'model-effort': 'inherit' }]) {
      assert.deepStrictEqual(resolve(p, { policy }), { model, effort, source: 'default', effortLine: effort ? EFFORT_LINE(effort) : '', launchEffort: null });
    }
  }
});
test('profile binds launchEffort to the resolved effort', () => {
  const policy = { 'model-effort': 'profile' };
  for (const p of ['standard', 'capable', 'frontier']) assert.strictEqual(resolve(p, { policy }).launchEffort, 'high');
  assert.strictEqual(resolve('fast', { policy }).launchEffort, null);
});
test('launchEffort follows a policy row and a stance', () => {
  const policy = { 'model-effort': 'profile', 'model-profiles': { capable: { effort: 'medium' } } };
  assert.deepStrictEqual([resolve('capable', { policy }).effort, resolve('capable', { policy }).launchEffort], ['medium', 'medium']);
  const econ = resolve('capable', { policy, stance: 'economy' });
  assert.deepStrictEqual([econ.effort, econ.launchEffort], ['low', 'low']);
});
test('launchEffort follows the ceiling', () => {
  const r = resolve('capable', { policy: { 'model-effort': 'profile', 'model-ceiling': 'standard' } });
  assert.strictEqual(r.model, 'sonnet'); assert.strictEqual(r.launchEffort, r.effort);
});
test('a fast row with an effort yields that effort', () => {
  assert.strictEqual(resolve('fast', { policy: { 'model-effort': 'profile', 'model-profiles': { fast: { effort: 'medium' } } } }).launchEffort, 'medium');
});
```
