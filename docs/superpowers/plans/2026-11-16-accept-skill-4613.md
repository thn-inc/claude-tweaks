  - `refreshPacket(body: string, source: null | { ref: string, text: string, devBaseUrl?: string, recordingUrl?: string }) -> { body: string, refreshed: string[], unverified: string[] }` — stored ref is the `ref: {value}` token in the Deploy status section. `source === null`, or no stored ref → body unchanged, `unverified = REFRESHABLE_FIELDS`. Equal refs → unchanged, both lists empty. Different refs → replace the Deploy status section body with `source.text` (keeping a `ref: {source.ref}` line), rewrite the origin (scheme+host+port) of every http(s) URL inside the Test guide section to `devBaseUrl` when given, replace the Recording section's link when `recordingUrl` is given; every byte outside those sections is unchanged.
  - `verdictLabelEdits(labels: string[], verdict: 'approved'|'changes-requested'|'skip', { batch?: boolean }) -> { add: string[], remove: string[] }` — approved adds `accept:approved` (+ `accept:approved-batch` when `batch`); changes-requested adds `accept:changes-requested`; `remove` = the present members of: every verdict `demo:pending`, `accept:pending`; approved `demo:changes-requested`, `accept:changes-requested`, `demo:approved` (twin), and when not batch `demo:approved-batch`, `accept:approved-batch`; changes-requested `demo:approved`, `accept:approved`, `demo:approved-batch`, `accept:approved-batch`, `demo:changes-requested` (twin). `skip` → both empty.

Prints one JSON line; exit 0 ok, 1 unreadable input, failed `gh` read or unwritable `--out`, 2 malformed invocation. `--labels-json` holds `gh issue view --json labels` output (`{labels:[{name}]}`) or a bare name array. Follows the `run(argv, deps)` seam of `.claude/skills/gh-api-module-pattern/cli-wrapper-contract.md` (read it first).
